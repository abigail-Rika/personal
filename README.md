# 个人空间

这是纪文越的个人知识管理空间，由 personal agent 协助维护。

## 目录说明

| 目录 | 用途 | 示例 |
|------|------|------|
| `work/roadmap/` | 周计划、月计划 | `2026-W09.md` |
| `work/projects/` | 项目跟踪 | `项目名.md` |
| `work/todos.md` | 待办事项清单 | — |
| `reviews/daily/` | 日复盘 | `2026-02-28.md` |
| `reviews/weekly/` | 周复盘 | `2026-W09.md` |
| `reviews/monthly/` | 月复盘 | `2026-02.md` |
| `knowledge/tech/` | 技术知识笔记 | 按主题命名 |
| `knowledge/product/` | 产品知识笔记 | 按主题命名 |
| `knowledge/reading/` | 阅读笔记 | 按书名/文章命名 |
| `diary/` | 每日日记 | `2026-03-02.md` |
| `thoughts/` | 想法与思考 | `2026-02-28-主题.md` |
| `skills/` | 个人技能档案 | `skill-map.md` |

## 使用方式

在 Cursor 中直接和 AI 对话，说你想记录的内容即可。AI 会自动判断归类并写入对应文件。

> 这个目录已加入 .gitignore，不会被提交到远程仓库。
