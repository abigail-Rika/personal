# 个人空间

文悦的个人知识管理空间，由 AI 助理协助维护。

## 目录结构

```
personal/
├── 知识沉淀/                 # 个人知识库（活跃）
│   ├── 沉淀规范.md           # 知识沉淀流程规范
│   ├── 知识索引.md           # 知识库索引
│   ├── 各角色目录/           # AI工程 / 产品设计 / 增长策略
│   ├── 技术文章/             # 技术学习
│   ├── 技能评估/             # 技能地图 + 评估记录
│   └── 阅读笔记/             # 阅读笔记
├── 灵感库/                   # 碎片干货库：收集→消化→沉淀
├── 生活/                     # 生活记录（活跃）
│   ├── 旅行/                 # 旅行计划与记录
│   └── 复盘/                 # 日/周复盘
├── 归档/                     # 历史内容（只读）
│   ├── 工作-海豚/            # 海豚AI学工作内容
│   ├── 聊天记录/             # 历史聊天记录
│   ├── 业务rules/            # 前公司业务 context 规则
│   └── 工具/                 # 工具与脚本
├── CLAUDE.md                # AI 助理行为规范
└── README.md                # 本文件
```

## 使用方式

直接和 AI 对话，说你想记录的内容即可。AI 会自动判断归类并写入对应文件。

刷到的干货/灵感丢给 AI，会消化成笔记进 `灵感库/`。

副业相关的内容在独立的 `Abigail` 空间（`~/Abigail`）。

## 隐私说明

- `归档/聊天记录/` 含个人聊天记录，注意不要外泄
- `归档/` 下是历史存档，只读，不修改不删除
