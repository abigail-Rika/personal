# 产品设计 · 待验证问题

- [ ] **弹窗触发时机对转化率的影响差异有多大？**（2026-03-31）
  - 背景：异形弹窗支持「进入时弹」和「退出时弹」两种时机，直觉上进入时弹效果更好（注意力集中），但缺乏数据支撑
  - 验证方式：同一落地页配置两组 AB（进入弹窗 vs 退出弹窗 vs 无弹窗），对比转化率
  - 关联：`经验/2026-03-31-异形弹窗方案演变.md`

- [ ] **展示频率对转化率和用户体验的平衡点在哪？**（2026-03-31）
  - 背景：每次都弹可能提升短期转化但伤体验，N天1次可能太保守
  - 验证方式：AB 测试不同频率下的转化率 + 页面跳出率变化
