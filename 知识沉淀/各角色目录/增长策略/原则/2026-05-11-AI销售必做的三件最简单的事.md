# AI 销售必做的三件最简单的事

> AI 销售的最低及格线不是"比销售聪明"，是"做销售因为资源约束做不到的最基础的三件事"。任何 AI 销售方案如果做不到这三条，直接打回——再聪明的话术都救不回来。

## 规则 1：用户主动伸手 → 立即接（接价格手）

### 硬规则

用户在微信主动问以下任一类问题，AI **必须在 60 秒内**给出实质性回答（不是反问、不是导引）：

| 用户问 | 必须立刻给的回答 |
|---|---|
| 价格相关：「多少钱」「有优惠吗」「便宜点」「贵不贵」 | 直接报当前价格区间 + 当前优惠 + 适配卡型推荐 |
| 时长相关：「多久能学完」「需要多长时间」 | 具体周期数字 + 每天投入参考 |
| 退款相关：「不满意能退吗」「中途能退吗」 | 退款规则原文 + 自己一句话总结 |
| 适配相关：「适合 X 年级吗」「我家孩子能跟得上吗」 | 基于已知信息直接判定 + 给出理由 |

### 反例（真实案例 Case 1）

晨晨妈妈加微当天 22 分钟内追了 4 次价格：
```
12:03「后续是不是还要收费？」
12:13「正式课还要收费？」
12:20「有优惠吗」
12:25「优惠多少？」
```

销售把报价拖到 **第三天的 45 分钟通话末尾**。等真报价时，妈妈已经从"主动问优惠"变成"好贵呀"。

### 为什么人做不到、AI 能做到

- 人销售：被培训"先建立信任再报价"+ 价格表复杂、要算优惠
- AI：调价格表 + 优惠规则就是 100ms 的事，没有"先建立信任"的心智负担

## 规则 2：用户连续不回 N 条 → 自动降频/止损（不骚扰）

### 硬规则

| 情况 | AI 必须做的动作 |
|---|---|
| 用户连续 2 条不回 | 不再发主动促销内容，等下一个用户触发点 |
| 用户连续 5 条不回（含图文促销） | 当前节奏完全停止，进入"长冷却"状态（至少 7 天无主动推送） |
| 长冷却期内被动触发（用户回了 1 条） | 接住该条，但不立即恢复原节奏 |
| 任何时段 | 同一段促销模板对同一用户不能推送超过 2 次 |
| 凌晨 23:00 ~ 次日 8:00 | 禁止发任何主动消息 |

### 反例（真实案例 Case 1 + Case 2 都中）

**Case 1**：晨晨妈妈 4-07 起再没回过任何信息，销售在接下来 8 天发了 60+ 条，包括：
- 04-12 一天发 34 条
- 04-15 凌晨 02:48 发"您睡了吗？我还在公司等您"

**Case 2**：三年级宝贝妈妈从加微到结束 13 天只回过 1 条，销售还发了 46+ 条模板促销。

两份独立 case 给出同一结果：**用户死信号亮了一周以上，销售还在按节奏发模板**。

### 为什么人做不到、AI 能做到

- 人销售：KPI 按"触达频次"考核 + 多个用户混在一起难以维护"该不该再发"的状态
- AI：每个用户独立计数 + 状态机判定一个 `if` 的事

## 规则 3：识别"决策权不在当前对话人"→ 为真实决策人生成素材

### 硬规则

当 AI 在通话或微信中识别到以下任一信号，**必须立即生成针对真实决策人的内容包**：

| 信号 | 真实决策人 | 必须生成的素材 |
|---|---|---|
| 「问问爸爸」「让爸爸看看」「爸爸做主」 | 爸爸 | 一份"给爸爸的 1 分钟版本"（强调投入产出、对比线下班、ROI 角度），格式适合微信转发 |
| 「给爷爷奶奶看看」 | 老人 | 一份"给老人的 30 秒版本"（强调安全、可控、不耽误孩子） |
| 「我得跟孩子商量」 | 孩子 | 一份"给孩子的预告片"（强调好玩、能拿奖励） |

素材形式：一张可以直接转发的卡片图 / 一段 30 秒以内的语音 / 一段可复制的纯文本。

### 反例（真实案例 Case 1 + Case 2 都中）

**Case 1**：45 分钟长聊结束时，妈妈明说「你晚上问问子爸爸」。销售后续发的 60+ 条都是给妈妈看的（情感长文 + 促销倒计时），**0 份针对爸爸**。

**Case 2**：通话中段妈妈说「幺六爸爸吧，让他他们管哈」。销售后续 46+ 条全是发给妈妈的模板，**0 份针对爸爸**。

### 为什么人做不到、AI 能做到

- 人销售：维护"妈妈版/爸爸版"两套话术成本高 + 不容易记住"这个用户决策权在哪"
- AI：识别+生成两种素材就是一次 LLM 调用的事

## 评审清单

任何 AI 销售方案的 PRD / 状态机设计 / 对话脚本评审，先对这三条：

- [ ] 方案里有没有"用户主动问 X 时的立刻响应分支"？响应时间预算 ≤ 60 秒？
- [ ] 方案里有没有"连续 N 条不回的自动降频/止损规则"？时间窗有没有定义？
- [ ] 方案里有没有"决策权识别 + 真实决策人素材生成"？识别信号词清单有没有？

三条任何一条没有，方案直接回炉。不要被"AI 学情诊断多智能"、"AI 共情多到位"这些花活转移注意力——**这三条之外的事都是 nice-to-have，这三条是 must-have**。

## 什么时候需要回溯经验

- 评审 AI 销售对话脚本时
- AI 销售方案被质疑"为什么 AI 能做销售做不到的事"
- 设计 AI 销售状态机/工作流时
- 需要给老板讲清楚"AI 销售的差异化在哪"
