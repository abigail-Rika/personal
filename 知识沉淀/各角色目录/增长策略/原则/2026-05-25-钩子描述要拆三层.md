# 钩子描述要拆三层（流量入口 / 首接话术 / 兑现物）

## 准则

任何关于"钩子"的描述、对照表、PRD 章节，都必须把以下三层显式分开：

| 层 | 回答什么问题 | 例子 |
|---|---|---|
| **L1. 流量入口钩子** | 用户是因为什么进来的？ | 抖音 19 元物理盒 / APP 首页 banner / AI 外呼 0 元弹窗 / 召回 SOP / 退费场景 |
| **L2. 首接话术钩子** | 销售/AI 第一句话给的承诺/动作是什么？ | "了解一下学习情况"（A 学情挖掘）/ "今晚八点见面会"（H 邀约）/ "前两天领了免费课包"（G 激活）|
| **L3. 钩子兑现物** | 用户答应后拿到的具体东西是什么？ | 9 元体验课 / 0 元送课 / 学情诊断报告 / 1对1 老师 / 资料库 / 学习计划 |

三层互相独立——同一个 L1 入口下可以有多个 L2 话术，同一个 L2 话术下可以挂不同的 L3 兑现物。把它们捏成一句"多样"，就等于把整张分类表压缩成 0 维。

## 反模式

| 错误说法 | 问题 | 正确说法 |
|---|---|---|
| 「CC 真实通话钩子类型多样——首通直转 / 加微首诊 / SOP 群发」 | "首通直转 / 加微首诊 / SOP 群发"是话术 + 流程的混合，不是钩子类型 | 拆 L2 → A 学情挖掘 / B 班主任承接 / C 免费送课 / ...（12 类）|
| 「斑马 0 转体的钩子是 9 元体验课」 | 9 元是 L3 兑现物，不是 L2 话术——"为什么用户愿意花 9 元"才是 L2 | L1=投放落地页；L2=人工电话开场 + 体验承诺；L3=9 元体验课 |
| 「AI 外呼的钩子效果不行」 | 没区分是 L1 入口（弹窗触达就弱）还是 L2 话术（弹窗后销售开场无吸引力）还是 L3 兑现物（0 元送课吃完就走） | 拆开看：L1 接通率 / L2 5 分钟有效对话率 / L3 兑现后留存率 |

## 为什么这条要立成原则

2026-05-25 写 v1 方案 §3.4.2.1 综述表时，CC 真实 case 那行写"多样——首通直转 / 加微首诊 / SOP 群发"，看起来信息很全，实际是把三层揉一起 → 用户立刻指出「钩子类型多样，我可以再给你几个 case，你帮我按照钩子类型展开分类下嘛」——一句话就把这条"多样"消解为"你还没分类完"。

后来按 L2 拆出 12 类钩子，立刻得到 3 条强结论（硬钩子 0 成单 / 软钩子 7/7 成单 / A 钩子成败差异在执行深度）——**这些结论在"多样"的笼统描述下完全看不见**。

L1/L2/L3 各自有自己的对照基线和优化抓手：
- L1 优化看接通率、入口质量
- L2 优化看 5 分钟有效对话率、信息完整度、追问深度
- L3 优化看兑现后留存、向上转化

混在一起谈"钩子优化"就会变成"什么都想做、什么都没抓手"。

## 检查清单（产出钩子相关内容时自检）

写完任何关于钩子的段落/表格/PRD，对照过三遍：

1. 我描述的是 L1、L2 还是 L3？标题里点明
2. 如果是对照表，三层至少各占一列（最少 L1 + L2 必须分）
3. "多样 / 灵活 / 视情况" 之类的描述出现 → 倒回去拆
4. 同一行混了 L1 和 L2 → 拆成两行
5. 软硬属性、成单率、追问深度这些"分析维度"应该挂在 L2 上，不是 L1 也不是 L3

## 什么时候需要回溯经验

- 团队对"钩子是什么"的理解不一致 → 回到 `2026-05-25-AI销售钩子分类-v2case库15用户跑通.md` 看 12 类钩子是怎么从"多样"里拆出来的
- PRD review 时被人问"你这个钩子的对照基线是什么"→ 先回这里确认是问哪一层
