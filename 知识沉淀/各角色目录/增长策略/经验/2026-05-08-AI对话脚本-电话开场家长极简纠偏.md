# AI 销售对话脚本：电话开场写得太"礼貌完整"，被 PM 指出陌生电话里家长真实回复极简

日期: 2026-05-08
角色: 增长策略

## 背景

AI 销售 0 转体验课 PRD 配套对话 demo，三个 case（A 新客有数据 / B 断课非限购 / C 新客无数据）的电话开场（阶段①）。我已经按之前沉淀的「悬浮病症检查清单」改过一轮，按"家长太配合"的纠正方向，给每个 case 加了"经典疑问追问"——比如 Case A 让家长说"你怎么有我电话"、Case B 让家长说"你们怎么还有我电话"——以为这样就够"真实"了。

## 经过

PM 看完直接说：「家长可能说不了那么多话，所以你可以去掉家长的经典疑问，把疑问放在一种阻塞情况里。」

这一句把我之前的"补救"全部推翻了：

我之前以为加上"经典疑问"=家长更真实，但 PM 的视角是——**陌生外呼电话里，家长真实状态是想尽快挂掉**，不会主动追问"你怎么有我电话""你们怎么还有我电话"等长句。这些反应是有可能发生（小概率），但写在主流程里就成了"AI 自言自语处理疑问"，反而比之前更悬浮。

按 PM 思路重写后，三个 case 的阶段①变成：

- **主流程**：家长全程只说 1-2 个字（"嗯""行你加吧""行吧"），AI 一气呵成把"身份 + 信息来源 + 钩子"说完，电话压缩到 25-35 秒
- **阻塞分支**：单独一张表格列 4-5 种典型反应（"你怎么有我电话""不需要""孩子不学了""你是真人吗"），每条配应对话术

主流程展示"理想顺利情况"——节奏紧、不啰嗦；阻塞分支展示"AI 应急能力"——证明 AI 不是只会念稿。两层分开，研发后续做应急话术库可直接用阻塞分支表。

## 关键收获

1. **「家长不够真实」≠「让家长多说话」**。我之前的纠偏方向反了——加"经典疑问"等于让家长更配合（只是配合的内容换成了"配合追问"）。真实的"不配合"是**字数少、想挂电话**。陌生外呼场景下，家长真实回复字数 ≈ 1-3 字，比 demo 里短一个数量级。

2. **场景的"真实约束"决定脚本写法**。同样是销售对话：
   - 微信/IM 场景：家长可以慢慢敲、可以敷衍、可以追问
   - 陌生电话场景：家长想尽快收尾，主流程只能写"理想极简配合"，疑问要单独抽离

3. **"主流程 + 阻塞分支"是更优雅的脚本结构**。把"理想路径"和"应急能力"拆成两层，比把所有反应混在主流程里更接近研发实际需要——AI 应急话术库本来就是独立模块。

4. **悬浮病症清单的"病症 2 用户太配合"需要场景化细化**：
   - 微信场景的解法 = 加敷衍/打断/转话题
   - 电话场景的解法 = 主流程极简 + 阻塞分支单列
