# ROI / CPL 模型搭建口径锁定清单

## 适用场景

任何要算 **ROI 弹性 / CPL / 单 leads 成本 / 析出率影响 / 用户池摊薄** 的项目论证。
**先按本清单锁定口径，再写公式**。
口径错了，每一步看起来合理，最终结论会严重失真。

## 5 步口径锁定法

### Step 1 · 锁分子 + 分母同口径 ⚠️ 最易出错

写下你要算的核心比率，**逐字检查分子和分母是否在同一口径下**：

- [ ] 时间周期一致？（日 / 周 / 月，不要混用）
- [ ] 用户池一致？（如果分子包含 A+B 两类用户，分母必须也包含 A+B）
- [ ] 渠道范围一致？（如果只算"直投渠道"，分母不能用全站数据）

> 经典坑：把"AI 可触达池（含新投放未析出 + 断课非限购）"当分子，但分母只用"新投放 leads"——会高估成本摊薄空间。

### Step 2 · 用户池从"名义"拆到"真实可影响"

不要直接用月报上的总用户数当作 AI 可影响的池子。**至少 2 次拆解**：

```
名义池（月度总活跃 N）
  → 扣 [已经析出的 L0]          ← AI 销售真正能多带来的，只有"未析出"部分
  → × [活跃系数]（一般 30% 左右） ← 月度池 ≠ 当周可触达
  = 真实可触达池
```

- [ ] 已经从总池里扣掉了 L0（当期已析出的 leads）？
- [ ] 如果按周/日触达估算，乘了活跃系数？
- [ ] 活跃系数有数据来源还是拍的？拍的请注明 `(占位)`。

### Step 3 · 识别"漏斗中间指标"，不要假装它是财务指标 ⚠️

加微率、触达率、首诊率、加好友率——**这些不是 leads 析出率**。

- [ ] 你模型里出现的"析出率/转化率"，分母是真实用户池还是某个漏斗中间值？
- [ ] 如果指标名带 `xx 率`，明确写出 `分子 / 分母` 的具体口径，不要套用 PRD 旧漏斗里的命名。
- [ ] 影响"单 leads 成本"必须看**端到端定义 leads 的那个动作**（如体验课购买），不是中间漏斗。

> 经典坑：PRD 旧漏斗里 `14% = 7140 / 51000`，实际是"用户池 → 加微"的整体转化率，被随手叫"AI 析出率"塞进 CPL 模型——会得出错误的成本摊薄结论。

### Step 4 · 检查是否已有 ROI 计算器，做好分工

- [ ] 团队是否已有商分 ROI 计算器 / 直投 ROI 模型？
- [ ] 如果有，**不要重复造**——AI 只需要算清楚 "AI 行为 → 单 leads 成本变化" 这一段，把新成本输入已有计算器即可。
- [ ] 模型分工说清楚：你算前置变量（如新 CPL），计算器算后置 ROI。

### Step 5 · 写出"成败 framing"决定论据强度

ROI 类立项有两种 framing，选错了会让论据强度大打折扣：

| Framing | 适用 | 论据强度 |
|---------|------|---------|
| **能否打正**（ROI > 1） | 基线 ROI 离 1 很近 / 基线稳定 | 依赖基线数值，弱 |
| **提升乘数稳不稳** | 基线 ROI 离 1 很远 / 基线波动大 | 数学结论、不依赖基线，强 ⭐ |

- [ ] 如果你的项目是"分母改善型"（leads 摊薄 / 流量优化 / 渠道扩量），优先用"提升乘数稳不稳" framing
- [ ] 论证目标写明：是要打正还是要稳定提升 X%？

> 详见洞察：`各角色目录/增长策略/洞察/2026-05-08-ROI项目论证framing-提升乘数稳vs能否打正.md`

## 反模式速查

| 反模式 | 表现 | 修复 |
|--------|------|------|
| 分子分母不同期 | 分子用月度可触达池，分母用周度 leads | 全部统一到一个时间窗 |
| 把月池当当期池 | 用 5.9w 月活当作"AI 这周能影响的人数" | 扣 L0、乘活跃系数 |
| 漏斗中间率假冒析出率 | 加微率 14% 被叫做"析出率"放进 CPL | 重命名为"加微率"，析出率单独建模 |
| 重复造 ROI 计算器 | 自己从头写一遍 ROI 公式 | 只算"AI 行为 → 新 CPL"，套用现有计算器 |
| 占位数没标记 | 拍的系数和真实数据混在一起 | 拍的数字一律标 `(占位)` |

## 模板：占位数据卡

写 PRD/分析时，把锁定的口径列成一个小卡片放进 PRD：

```
口径锁定（YYYY-MM-DD）
------------------------------
时间周期    : 3 月（自然月）
分母用户池  : 直投渠道总活跃 5.3w + 含断课非限购 5.9w
已析出 L0   : 新投放 7154 + 召回 1542 = 8696
未析出池    : 50304
活跃系数    : 30% (占位，待数据验证)
真实可触达池: 50304 × 30% ≈ 15091
当期单 leads 成本: 154 元
杠杆比      : 15091 / 8696 ≈ 1.73
```
