# 外部系统写入需要明确授权

## 原则

**不要在用户没有明确指定目标系统时，默认往外部系统写入数据。** 优先用最轻量的方式满足需求。

## 判断逻辑

```
用户说"记一下 / 放到 todos / 帮我记着"
  ↓
用户是否明确指定了目标系统？（"写到 Notion""加到日历"）
  ├── 是 → 执行对应系统的写入
  └── 否 → 用对话内工具（TodoWrite）轻量记录
```

## 为什么

1. **写入外部系统有副作用**：创建了真实数据，用户可能还得手动清理
2. **轻量需求不需要重型方案**：用户只是想"记着这几件事"，不是"帮我建立完整的项目管理"
3. **Token 和时间成本**：搜索数据库 schema → 查 API → 调工具，多了好几轮交互，用户等得烦

## 泛化

这条原则不只适用于 Notion，适用于所有有副作用的外部系统操作：
- 发邮件 / 消息
- 创建日历事件
- 提交代码 / 创建 PR
- 修改线上配置

**核心问：这个操作有没有副作用？有 → 需要明确授权。**
