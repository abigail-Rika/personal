# 工具结果为空时必须交叉验证

## 原则

**一个工具返回空结果 ≠ 事实为空。用第二种方式验证后再下结论。**

已知 Glob 工具对以下场景不可靠：
- 包含中文字符的路径（如 `历史聊天/`、`知识沉淀/`）
- 深层嵌套的目录结构
- 特殊字符或空格路径

## 操作 Checklist

1. Glob/Grep 返回 0 结果时，不要直接说"没有/是空的"
2. 改用 `Shell` 执行 `ls` 或 `find` 命令确认
3. 确认后再向用户报告结论
4. 如果两种方式都返回空，才可以判定为空

## 什么时候需要回溯经验

当搜索类操作返回空结果、准备向用户报告"没找到"之前。
