# CLI 程序不走系统代理，需显式设置

## 什么时候需要回溯经验

- 命令行工具报网络错误、超时、403 region，但浏览器 / 系统代理明明开着
- 怀疑是地区限制，但不确定是不是代理出口问题

## 原则

1. macOS 的系统代理设置（scutil / 系统偏好设置）只对走系统网络栈的 GUI 程序生效；Rust/reqwest、Python requests、curl 等 CLI 默认不读它，需显式设 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY`。
2. 判断「地区 403」前，先用 `curl ipinfo.io` 之类确认本机实际出口 IP，别急着归因到地区限制。
3. 排查网络问题时，先排除「代理有没有真的作用到这个程序」这一层。
