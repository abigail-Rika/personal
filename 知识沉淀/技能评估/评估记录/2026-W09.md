## 技能矩阵

### 1. Prompt 工程

| 子技能 | 等级 | 观察依据 |
|--------|------|----------|
| Skill 结构设计 | ★★☆☆☆ | 在 personal 空间创建了 prd-writer 和 prd-review 两个 skill，结构参考了团队规范。能跑通，但更多是在已有模板上填充，尚未从零设计过 |
| 行为指令编写 | ★★☆☆☆ | prd-review 的角色定位写得不错（"产品 Leader 视角"），说明有场景意识。但整体还是靠直觉写，缺少对 prompt 技巧的系统认知 |
| 示例与测试 | ★☆☆☆☆ | prd-writer 有示例，但没有形成"测试 → 对比 → 迭代"的习惯 |
| 高级技巧 | ☆☆☆☆☆ | 尚未接触 chain-of-thought、self-verification、few-shot 优化等 |

**当前水平：入门期**
能在现有框架下创建可用的 skill，说明理解了 skill 的"是什么"和"怎么用"。但在 prompt 本身的设计技巧上，还在直觉驱动阶段。

### 2. AI 工具使用与集成

| 子技能 | 等级 | 观察依据 |
|--------|------|----------|
| Cursor 日常使用 | ★★★☆☆ | 高频使用 Cursor 处理日常工作（待办、日记、复盘、PRD），交互自然流畅 |
| 任务委托意识 | ★★★★☆ | 很擅长识别"这件事可以交给 AI"——记录待办、搭建提醒、评审 PRD、组织信息，委托范围广且合理 |
| 自动化搭建 | ★★☆☆☆ | 刚开始探索（工作日报提醒是第一个），对 launchd/脚本等基础设施有了初步认知 |
| MCP / 外部工具 | ★☆☆☆☆ | 团队配置了 Tableau MCP，但个人尚未主动跑通数据分析流程 |

**当前水平：中级（使用层）**
一个优秀的 AI 工具使用者——使用频率高、场景判断准、委托边界清晰。

### 3. 个人知识体系

| 子技能 | 等级 | 观察依据 |
|--------|------|----------|
| 信息架构设计 | ★★★☆☆ | personal 空间的目录分层清晰（work/diary/reviews/knowledge/skills），并且会主动审视和优化命名（plans → roadmap） |
| 知识沉淀习惯 | ★★☆☆☆ | 有日记和复盘的框架，但 knowledge/ 目录尚空，沉淀还没真正跑起来 |
| 流程标准化 | ★★☆☆☆ | prd-writer → prd-review 的流水线意识很好，但其他工作流还没有类似的标准化设计 |

**当前水平：起步期，但方向感很好**
对"信息应该怎么组织"有天然的敏感度，这个素质在后续搭建更复杂的 AI 工作流时会很有用。

## 建议的学习路径

1. 做一次 prompt 对比实验（chain-of-thought）
2. 了解一个 prompt 框架（CO-STAR）
3. 跑通 Tableau 数据分析端到端流程
4. 独立设计一个新 skill（不参考现有模板）
5. 给 knowledge/ 目录注入第一批内容
