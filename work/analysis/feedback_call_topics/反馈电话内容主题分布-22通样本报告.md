## 二、主题分类方法

- **每通电话**按句子排序后切段（每 8 句为一个 segment，约 30-60 秒）
- **每段**用关键词权重打分，最高分主题作为该段标签
- **主题字典**基于 4 case 人工标注 + `反馈环节分析.md` 信号词，关单/顾虑类整体 ×1.5 加权
- **时长汇总**：所有同主题 segment 的时长加和

> 局限：关键词法的精度估计在 80-85%，T9_其他（5.8%）含未能分类清楚的段落。完全用 LLM 标注可以把精度推到 95%+，但 22 通的趋势判断已经足够稳定。

## 三、整体主题占比（22 通 / 651 分钟）

| # | 主题 | 时长 | 占比 | 命中 case 数 |
|:-:|:-|-:|-:|-:|
| 1 | **学情复盘** | 162.4 min | **24.9%** | 22/22 |
| 2 | **产品方案介绍** | 140.9 min | **21.6%** | 20/22 |
| 3 | **问题诊断与目标** | 133.0 min | **20.4%** | 19/22 |
| 4 | **关单推销** | 63.3 min | **9.7%** | 15/22 |
| 5 | **顾虑承接** | 53.8 min | **8.3%** | 18/22 |
| 6 | **长期服务路径** | 43.3 min | **6.6%** | 17/22 |
| 7 | 其他/未分类 | 37.6 min | 5.8% | 18/22 |
| 8 | **开场寒暄** | 17.1 min | **2.6%** | 20/22 |

**核心结构（5 句话讲完）**：
- 反馈电话 **66.9% 时间都在「学情 + 产品 + 诊断」三件事上**（24.9% + 21.6% + 20.4%）；
- **关单 + 顾虑 + 长期路径合计只占 24.6%**——很多反馈电话其实没充分完成"收口"环节；
- 学情复盘是命中率最高的主题（22/22 通全部出现），是反馈电话的基线动作；
- 产品方案介绍和问题诊断各占 20%+，这两块是档案最能预埋的；
- 开场寒暄只占 2.6%，几乎没有"暖场过度"问题。

## 四、按时长分桶 — 反馈电话不是一种东西

### 短电话（5 通 / <10 min / 平均 4.7 min）

| 主题 | 占比 |
|:-|-:|
| 学情复盘 | **49.8%** |
| 产品方案介绍 | 19.0% |
| 顾虑承接 | 9.3% |
| 其他 | 8.4% |
| 开场寒暄 | 7.6% |
| 问题诊断与目标 | 5.9% |
| **关单推销** | **0%** |
| **长期服务路径** | **0%** |

**判读**：短电话本质是「学情复盘 + 简短产品介绍」就结束了——**没有关单、没有长期路径**，是"半成品反馈"。占样本 23%。如果说反馈率 33.95% 是表面数字，那扣掉这部分"半反馈"，**真正完成反馈结构的电话占比要再砍 20-25%**。

### 中电话（4 通 / 10-30 min / 平均 19.4 min）

| 主题 | 占比 |
|:-|-:|
| **产品方案介绍** | **32.0%** |
| 学情复盘 | 23.4% |
| 问题诊断与目标 | 13.3% |
| 顾虑承接 | 8.5% |
| 开场寒暄 | 6.2% |
| 长期服务路径 | 6.1% |
| 关单推销 | 5.9% |
| 其他 | 4.6% |

**判读**：中电话 = 「讲海豚产品」主导。学情复盘只占 23%，**产品方案占了 32%**——这类电话像销售在"主动推销产品"，但顾虑/关单都还没真正展开。

### 长电话（9 通 / 30-45 min / 平均 37.6 min）

| 主题 | 占比 |
|:-|-:|
| 学情复盘 | 22.9% |
| 产品方案介绍 | 20.7% |
| 问题诊断与目标 | 20.6% |
| **关单推销** | **11.8%** |
| 长期服务路径 | 8.1% |
| 其他 | 7.1% |
| 顾虑承接 | 6.7% |
| 开场寒暄 | 2.0% |

**判读**：长电话是"完整结构"——学情/产品/诊断三足鼎立各占 ~20%，**关单升到 11.8%**，长期路径 8.1%——开始有真正的「问题 → 证据 → 方案 → 收口」链路。

### 超长电话（4 通 / ≥45 min / 平均 52.9 min）

| 主题 | 占比 |
|:-|-:|
| 学情复盘 | 25.9% |
| 问题诊断与目标 | 24.3% |
| 产品方案介绍 | 19.7% |
| **顾虑承接** | **10.5%** |
| 关单推销 | 8.8% |
| 长期服务路径 | 5.3% |
| 开场寒暄 | 1.8% |
| 其他 | 3.7% |

**判读**：超长电话 ≠ 关单更多，而是**顾虑承接显著上升（10.5% vs 长电话的 6.7%）**——电话变长不是因为讲了更多产品，而是**反复回应家长追问**。这类电话往往是"家长有意向但有具体顾虑"的拉锯。

### 跨桶关键判断

| 维度 | 短 | 中 | 长 | 超长 |
|:-|-:|-:|-:|-:|
| 学情复盘 | 49.8% | 23.4% | 22.9% | 25.9% |
| 产品方案介绍 | 19.0% | **32.0%** | 20.7% | 19.7% |
| 问题诊断与目标 | 5.9% | 13.3% | 20.6% | **24.3%** |
| 关单推销 | 0% | 5.9% | **11.8%** | 8.8% |
| 顾虑承接 | 9.3% | 8.5% | 6.7% | **10.5%** |
| 长期服务路径 | 0% | 6.1% | **8.1%** | 5.3% |

**含义**：
1. **关单环节集中在长电话（30-45min）**：超长电话反而关单占比下降——说明长电话谈崩了的多，又回到讲产品/顾虑
2. **问题诊断随时长稳步上升**：5.9% → 13.3% → 20.6% → 24.3%——电话越长，销售越愿意做诊断
3. **学情复盘是基线动作**（除中电话），但短电话里几乎只剩学情
4. **长期服务路径在长电话里才出现**——短/中电话完全不讲后续怎么持续被服务

| 主题 | type25（19通/平均33.6min） | type69（3通/平均4.1min） |
|:-|-:|-:|

| 关单推销 | 9.9% | **0%** |
| 顾虑承接 | 8.3% | 7.3% |

**判读**：type25 和 type69 是**两种完全不同的电话**——

## 六、对档案产品决策 D 的更新含义

### 6.1 档案预埋后可释放的电话时间（基于 22 通真值）

| 反馈电话主题 | 22 通占比 | 档案预埋潜力 | 释放潜力（粗算） |
|:-|-:|:-|-:|
| 产品方案介绍 | **21.6%** | ✅ 模块 3/4/5 大部分可预埋（错题本、资料库、学习计划标准化） | ~15% |
| 问题诊断与目标 | **20.4%** | ✅ 模块 2 + 3 把诊断变成"档案验证" | ~10% |
| 长期服务路径 | **6.6%** | ✅ 模块 5 + 路径示意全量预埋 | ~5% |
| 学情复盘 | **24.9%** | △ 模块 4 让起点更高，解读不可替代 | ~5% |
| 关单推销 | 9.7% | ✗ 不可被档案替代 | 0 |
| 顾虑承接 | 8.3% | △ 模块 2"问题已被看见"减少部分追问 | ~2% |
| 开场寒暄 + 其他 | 8.4% | ✗ | 0 |

**结论**：档案如果完整落地，**理论上可释放反馈电话约 35-40% 时间**（相比 4 case 估算的 ~40% 略低，但更可信）。

释放出来的时间应该流向：**顾虑承接 + 关单收口** —— 这两块在 22 通里合计只占 18%，明显不够（top 老师标杆 case1 关单单独就 16.7%）。

### 6.2 短/中电话是档案最该优先服务的群体

| 电话类型 | 现状 | 档案能干什么 |
|:-|:-|:-|
| 短电话（4.7 min，占 23%） | 学情讲一下就挂，没收口 | **最大空白**——档案能让家长进电话前已经看过孩子学情 + 看过产品基础认知，让短电话也能直接进入"收口" |
| 中电话（19.4 min，占 18%） | 销售在硬讲产品（32%） | 档案预埋产品介绍后，电话可以从"讲产品"变"基于档案讨论产品和孩子的匹配" |
| 长电话（37.6 min，占 41%） | 结构基本完整 | 档案让"诊断"环节从问出来变成验证档案 → 释放时间给关单和顾虑承接 |
| 超长电话（52.9 min，占 18%） | 顾虑承接拖长（10.5%） | 档案前置「问题已被看见」可减少顾虑（参考反馈环节分析第三章 2 节判断） |

### 6.3 一个反直觉的发现

**反馈电话里讲得最多的不是产品，也不是关单——而是「学情 + 诊断」**（合计 45.3%）。

之前 `反馈环节分析.md` 第六章把反馈电话「四件事」定为：①学情数据复盘 ②孩子问题诊断 ③产品功能匹配 ④长期使用路径——按 22 通真值，①②③ 占比 67%，**④长期路径只占 6.6%**，是最被忽略的一件事。

档案如果只能选一件事强化，**应该是长期路径**（最弱、最容易补，且对反馈转化率影响大）。

## 七、22 通 vs 4 case 对比

| 主题 | 22 通真值 | 4 case 标杆 | 偏差 | 原因 |
|:-|-:|-:|-:|:-|
| 学情复盘 | 24.9% | 18.9% | +6.0pp | 真值学情更多 |
| 产品方案介绍 | 21.6% | 31.3% | -9.7pp | 4 case 选的是"完整收口"电话，产品讲得更充分 |
| 问题诊断与目标 | 20.4% | 9.1% | **+11.3pp** | 真值诊断比 4 case 印象更普遍 |
| 关单推销 | 9.7% | 17.5% | -7.8pp | 4 case 是 top 老师 → 收口更扎实 |
| 顾虑承接 | 8.3% | 16.5% | -8.2pp | 4 case 含 case3（顾虑 34%）拉高均值 |
| 长期服务路径 | 6.6% | 2.9% | +3.7pp | 22 通有更多"提一句"的 case |
| 开场寒暄 | 2.6% | 2.8% | -0.2pp | 一致 |

**主要洞察**：
- **4 case 系统性高估了"收口环节"占比**（关单+顾虑 4case 是 34%，真值是 18%）——因为 4 case 是为反馈赋能项目精挑的"完成度高"案例
- **真值里诊断动作比 4 case 多 2 倍**——但这是被诊断关键词权重抬高的结果，需要 LLM 校核才能确认
- **学情复盘 + 问题诊断**是反馈电话的真正主体（合计 45%）——档案要服务好这两块

## 八、样本局限与下一步

### 局限
1. **样本量 22 通**：足够看主题相对位置，**不足以做销售老师 × 转化率的二维拆解**（每个分组只剩 2-3 通）
2. **关键词法精度 80-85%**：T9_其他 5.8% 是分类未达阈值的内容
3. **未关联转化结果**：所有 22 通都没补查转化字段（要补需要 Chrome API 拉 team-students/v2）
4. **type69 样本只 3 通**：占比结论参考性有限
5. **短电话定义**：22 通里有 5 通 <10min，可能是 type25 但电话本身没真正进入反馈

### 下一步可选动作

1. **加 LLM 校核**（投入大）：对 22 通转写各跑一次 Claude 章节标注，把精度推到 95%+，T9_其他降到 <1%。预计 ~22 次 API 调用。
2. **补转化标签 → 看「转化 vs 未转化」主题差异**（投入中）：先用 Chrome API 拉这 22 个 user_id 的 transformStatus，对比已转化 vs 未转化的反馈电话主题占比。**这能直接回答档案应该补强哪个主题最有 ROI**。
3. **扩样到 100 通**（投入大）：现有口径下扩样，对短/中/长电话各保证 30 通样本，能稳定看分桶趋势。
4. **当前 22 通结论已够给档案 D 决策提供方向性参考，停在这里也可以。**
