## 一、背景

### 1.1 业务背景

**转介绍业务**

正价用户分享落地页（周周分享新用户购课落地页）是转介绍链路的核心承载页面，当前页面转化率近半年均值约 **23%**，存在提升空间。

当前落地页「弹窗」模块仅有**挽留弹窗**（用户尝试离开时触发），且仅在 APP 端内生效。转介绍落地页承载在 H5 上，挽留弹窗对 H5 不生效，意味着用户在 H5 上从进入到离开，全程没有任何弹窗干预。

**市场投放业务**

投放流量进入落地页购买，当前页面转化率 5.51%，存在提升空间。当前供量压力大，需要增加其他手段留住用户。

### 1.2 问题与机会

**现象**：用户从微信/分享链接进入 H5 落地页后，需要自行浏览整个页面才能了解核心卖点，部分用户在浏览过程中流失，未触达购买决策。

**判断**：在用户进入页面的前几秒，注意力最集中，是影响转化决策的黄金窗口。如果能在这个窗口用一个视觉冲击力强的弹窗，快速传递核心卖点和行动号召，有机会提升转化率。

**依据**：竞品转介绍实践表明，在落地页增加进入弹窗后，落地页转化率可提升 **1-2pp**。

**对用户的影响**：弹窗会打断用户的自然浏览，但通过以下设计降低负面感受：
- 弹窗有关闭按钮，用户可随时关闭
- 展示频率可配置（不是每次都弹）
- 弹窗内容与落地页一致，不构成认知冲突

**适用范围**：售卖落地页目前转介绍、投放等业务方都在用，该弹窗可适配多方业务。

## 二、目标测算

### 2.1 关注指标

- **核心指标**：落地页购买转化率（购买人数 / 页面UV）
- **过程指标**：弹窗展示率、弹窗主按钮点击率、弹窗关闭率

### 2.2 目标设定

以转介绍场景为主要估算场景（有竞品相同场景做参考）

| 场景 | 预期 | 假设 |
|------|------|------|
| 保守 | 转化率提升 0.5pp（23% → 23.5%） | 弹窗对部分用户有促进作用，但整体提升有限 |
| 激进 | 转化率提升 1-2pp（23% → 24-25%） | 参考竞品实践的提升幅度 |

投放场景不好估算提升：一方面量级较大，且可能会有头条穿山甲流量，影响归因；另外没有类似的场景去对比。

### 2.3 成本与 ROI

- **开发成本**：约 3 人日（复用现有挽留弹窗组件框架）
- **运营成本**：设计师出一张弹窗图，成本极低
- **试错代价**：配置化，效果不好随时关闭，无沉没成本
- **ROI 判断**：3 天开发换取持续可用的配置化能力，即使首版效果一般，后续可通过换图、换文案持续迭代，ROI 合理

> 这是一次快速验证，具体提升幅度需要通过实验确认。如果效果好，可作为落地页标配能力长期使用。

## 三、现状

当前「弹窗」模块只有**挽留弹窗**一种类型，且 H5 端内不生效（无法获取到微信生态的退出动作）。

H5 落地页当前没有任何弹窗能力，用户进入后直接看到页面内容。

---

## 四、设计思路

### 4.1 方案定位

将现有「挽留弹窗」升级为通用的「异形弹窗」组件，通过**触发时机**配置覆盖「进入弹窗」和「挽留弹窗」两种场景，不再拆分两个组件。

定位为**短期实验 + 长期能力沉淀**：首轮验证有无弹窗的效果差异，后续可持续迭代弹窗素材和配置。

**三个核心判断**：

1. **有效性**：竞品已验证同类弹窗对落地页转化有 1-2pp 正向提升；用户进入页面前几秒注意力最集中，弹窗在这个窗口传递核心卖点和行动号召，逻辑合理。
2. **成本可控**：复用现有挽留弹窗组件框架，开发约 3 天；运营只需出一张图、填几个配置项；实验简单，用配置即可控制。
3. **无副作用**：弹窗有明确的关闭入口，不强制用户操作；展示频率可配（避免反复骚扰）；弹窗内容与落地页一致，不会造成认知冲突。

### 4.2 AB 测试设计

各业务方按需配置 AB 测试后，回收数据对比。

## 五、需求详情

### demo

附件：`落地页弹窗原型Demo.html`（浏览器打开，展示弹窗样式和交互效果）

### 5.1 组件位置

```
页面配置后台 → 左侧组件栏 →「弹窗」分类
  └── 异形弹窗（升级现有挽留弹窗）  ← 本次需求
```

### 5.2 配置栏

选中「异形弹窗」后，右侧展示配置栏：

```
┌─ 配置栏 - 异形弹窗 ────────────┐
│                                │
│  * 触发时机：                   │
│    ○ App内退出落地页            │
│    ◉ 首次进入页面               │
│    ○ 下单页点击返回             │
│                                │
│  * 背景图：[图片上传]            │
│    支持 PNG/JPG/GIF，≤1MB       │
│                                │
│  * 热区设置：[设置]              │
│    热区 0   购买                │
│    热区 1   关闭                │
│                                │
│  * 展示频率：                   │
│    ◉ 每次                      │
│    ○ 每天首次                   │
│    ○ N 天 1 次                  │
│      每 [7] 天展示 1 次         │
│                                │
└────────────────────────────────┘
```

### 5.3 配置项说明

| # | 配置项 | 类型 | 默认值 | 说明 |
|---|--------|------|--------|------|
| 1 | 触发时机 | 单选 | 首次进入页面 | App内退出落地页：用户在 APP 内尝试离开时触发（原挽留弹窗）；首次进入页面：用户进入页面后触发（原前置弹窗）；下单页点击返回：用户在下单页返回时触发 |
| 2 | 背景图 | 图片上传 | 无 | 必填。设计师出图，运营上传。支持静态图（PNG/JPG）和动图（GIF），≤1MB。图片只包含视觉内容区，不含按钮 |
| 3 | 热区设置 | 按钮 | / | 点击「设置」弹出热区配置窗口。配置栏回显已设置的热区列表 |
| 4 | 展示频率 | 单选 | 每次 | 每次：每次触发都展示；每天首次：同一用户每天第一次触发时展示；N天1次：同一用户每 N 天展示 1 次 |

### 5.4 热区配置窗口

点击「设置」按钮后弹出热区编辑弹窗：

| 区域 | 说明 |
|------|------|
| 预览区（左侧） | 展示上传的背景图（与手机预览一致），已添加的热区以彩色矩形叠加显示。拖拽可移动热区位置，拖拽右下角可调整大小 |
| 配置区（右侧） | 表格形式，三列：标题、热区类型、操作 |

**配置区说明**：
- **添加热区**：右上角蓝色按钮，点击增加一个热区，最多 3 个
- 每个热区包含：
  - **标题**：热区 0、热区 1、热区 2...（自动编号，带 info 图标提示"在左侧图片上拖拽调整位置和大小"）
  - **热区类型**（下拉选择）：
    - 购买：拉起购买浮层（对应落地页底部购买按钮的操作）
    - 关闭：关闭该弹窗
  - **操作**：删除按钮

### 5.5 弹窗交互

- **关闭按钮**：固定在弹窗右上角（半透明圆形 ✕ 图标），点击关闭弹窗
- **遮罩点击**：点击半透明遮罩区域关闭弹窗
- **热区点击**：根据热区类型执行对应操作（购买 / 关闭）

### 5.6 展示频率实现说明

| 频率 | 判断依据 | 存储方式 |
|------|---------|---------|
| 每次 | 不判断，每次触发都展示 | 无需存储 |
| 每天首次 | 当天是否已展示过 | localStorage，key 含日期，每日自动失效 |
| N天1次 | 距上次展示是否已过 N 天 | localStorage，记录上次展示时间戳 |
