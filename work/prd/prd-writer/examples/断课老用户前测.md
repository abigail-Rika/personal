# 示例：断课老用户增加前测 PRD

> 本示例对应 Confluence 文档：https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=1023450265

## 输入

产品同学需要撰写「断课老用户增加前测」的产品需求，从需求分析到交付研发。

## 执行过程

1. 基于 PRD 模板搭建文档结构
2. 按六大部分依次填充：背景、目标测算、现状、设计思路、需求详情、数据需求
3. 背景部分：梳理周活数据、断课用户漏斗、析出率/转化率问题
4. 现状部分：梳理站内召回点位、用户调研结论（断课原因、召回动机）
5. 设计部分：问题设计（欢迎语+3题）、竞品参考（叫叫、洋葱、keep）、AB 实验设计
6. 需求详情：展示规则、流程、问题配置、落地页、实验分组
7. 数据需求：埋点表、keyfrom

## 输出

详见 Confluence 完整文档。核心结构如下：

| 章节 | 本案例关键内容 |
|------|----------------|
| 一、背景 | 周活 3.4w，断课老用户析出率<3%，转化率 5%；广告曝光率 41% vs 97% |
| 二、目标测算 | 保守：广告曝光率 80%，正式会员 +31/周；激进：+56/周 |
| 三、现状 | 召回点位梳理、用户调研（断课原因：价格 25.7%、科目不全 14.3% 等） |
| 四、设计思路 | 欢迎语+2~3 题、CC 挖需话术、竞品结构、AB 实验 3 组 |
| 五、需求详情 | 展示人群、冷启动逻辑、欢迎页→问题流程→落地页、luban 配置 |
| 六、数据需求 | 欢迎页/问题/落地页埋点、recallTest-1/2/3 keyfrom |

## 备注

- 该文档是「从 1 稿需求分析到 9 稿交付研发」的完整模板
- AB 实验设计需考虑 cc 人效，流量占比从 33% 调整为 2/2/6
- 问题文案支持 luban 配置，便于后续迭代
