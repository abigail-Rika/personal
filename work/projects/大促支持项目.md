# 大促支持项目

## 项目一：落地页组件优化

**背景问题**：原有流程需用户先选礼品再提交预约，分两步操作，流程繁琐（预约率 80%+，仍有 20% 的流失）。

**功能点**：
- 将预约和礼物选择整合到同一页面，保留提交按钮（避免误操作导致数据虚高）
- 用户选完礼物后点击"提交并预约"按钮，一步完成预约+礼品确认
- 展示活动规则：复用现有图片轮播、视频功能展示活动玩法，无需新增开发

**关键点**：不做"点击即预约"，保留明确提交动作，给用户充分选择空间。

## 项目二：H5 抽奖功能

**目标**：
- 让微信场景下的已下单用户参与抽奖，页面同步直播间内容，增加氛围感。
- 未下单的用户，增加「下单抽奖」的抓手，吸引用户下单。

**核心逻辑**：

| 模块 | 规则 |
|------|------|
| 用户资格识别 | h5 页面登录后判断是否已下单：有资格 → 显示等待开奖界面；无资格 → 提示下单获得抽奖资格 |
| 抽奖同步范围 | 仅同步直播间中"下单用户可参与"的福袋轮次；直播间专属奖励（如评论抽奖）不同步 |
| 参与规则 | 下单后可参加所有轮次抽奖；中奖一次后可继续参与但不会再中奖（此逻辑不会外显给用户） |
