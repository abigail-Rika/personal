# 大促支持项目

## 项目一：落地页组件优化

**背景问题**：原有流程需用户先选礼品再提交预约，分两步操作，流程繁琐（预约率 80%+，仍有 20% 的流失）。

**功能点**：
- 将预约和礼物选择整合到同一页面，保留提交按钮（避免误操作导致数据虚高）
- 用户选完礼物后点击"提交并预约"按钮，一步完成预约+礼品确认
- 展示活动规则：复用现有图片轮播、视频功能展示活动玩法，无需新增开发

**关键点**：不做"点击即预约"，保留明确提交动作，给用户充分选择空间。

## 项目二：H5 抽奖功能

### 目标
- 让微信场景下的已下单用户参与抽奖，页面同步直播间抽奖信息，增加氛围感
- 未下单的用户，增加「下单抽奖」的抓手，吸引用户下单

### 需求目的
- 建设双端（直播间 + H5）联动的抽奖系统，实现同一配置、同一奖池、同一开奖结果
- H5 侧支持大促池内全流量可访问 + 未续费获资格转化链路
- 直播间侧支持评论专属轮次（未续费可参与），该类轮次不同步到 H5
- 双端展示一致（抽奖信息一致 + UI 视觉让用户感知到 H5 和直播是同一个活动）

### 已确认的关键决策

| # | 决策项 | 结论 |
|---|--------|------|
| 1 | 系统架构 | 已有自研直播抽奖后台，H5 读取同一套配置和数据，不需要新建抽奖引擎 |
| 2 | H5 登录方式 | 手机号验证码登录 |
| 3 | 资格判定 | 本次大促期间已下单/续费 = 有资格（H5 用户均在大促池内，判断当前订单状态即可） |
| 4 | "报名"="下单" | Demo 中的"报名"和文档中的"下单"是同一个概念，未下单用户通过 CTA 跳转下单页面完成付费后获得资格 |
| 5 | 参与方式 | 下单后自动参与所有共有轮次，用户不需要每轮手动操作 |
| 6 | 中奖限制 | 整场活动只能中奖一次，但该规则不外显给用户 |
| 7 | 开奖方式 | 后台自动按配置的时间开奖，非人工触发 |
| 8 | 实时性 | 不要求用户实时在线，用户进入 H5 时加载当前状态即可（已完成轮次的结果 + 当前/未来轮次的倒计时） |
| 9 | 评论轮次 | 直播间有"仅评论"参与条件的轮次，H5 不展示，两者独立 |
| 10 | 轮次配置 | 每轮可单独配置（奖品、中奖人数、倒计时时长），H5 直接读取后台配置 |
| 11 | 发奖 | 发奖流程不在本需求范围内 |
| 12 | 九重福利 | 真实需求，当前用占位（福利1/2/3...）先行开发 |
| 13 | 直播节奏 | 一天一场直播 |
| 14 | 上线时间 | 预计五月底上线测试 |

### 后台现有配置能力（Gaffey 系统）

已有字段（截图确认）：
- 抽奖名称（建议格式：直播间名称第x轮抽奖）
- 抽奖模版：福袋抽奖
- 奖品池：商品 SKU / 商品类目 / 数量 / 发放时效（自动发放）
- 中奖人数
- 倒计时时长（下拉选择）
- 评论内容（限 20 字）
- 参与条件：仅评论 / 评论且下单
- 中奖次数：已有配置（当前设为 1 次）
- 下单成功页抽奖：使用 / 不使用 开关

**需新增字段**：「是否同步到 H5」开关（在轮次级别，让运营选择哪些轮次在 H5 展示）

### 用户流程

```
进入 H5 页面
  → 检查是否登录 → 否 → 手机号验证码登录
  → 判断是否为大促目标池用户 → 否 → Toast "您不符合抽奖资格"
  → 判断是否已下单 → 否 → 展示未下单页面样式（吸底 CTA 引导下单）
  → 是 → 展示对应页面状态（活动未开始 / 进行中 / 已结束）
```

### H5 页面结构

**抽奖主页**（单页面，不同模块）

| 模块 | 内容 | 备注 |
|------|------|------|
| 活动标题 | 海豚夏日福利嘉年华 | |
| 活动时间 | 6月6日 12:00 - 22:00 | |
| 在线人数 | 展示直播间在线人数 | H5 用户不计入 |
| 抽奖卡片区 | 只展示**正在抽奖 + 未抽奖**的轮次 | 已开奖轮次放到下方历史模块 |
| 每张卡片内容 | 轮次序号、礼品名称、礼品示意图、中奖人数、开奖倒计时 | |

| 开奖按钮 | 点击 → 开奖动画 → 动画结束后展示中奖/未中奖信息 | |
| 中奖结果展示 | 中奖："恭喜您中奖了！" + 奖品信息；未中奖："很遗憾，您未中奖" | |
| 历史开奖记录 | 过往轮次列表，每条含：轮次、礼品名称、礼品图、可点击查看中奖名单 | |
| 活动规则 | 规则说明文字 | |
| 九重福利 | 九宫格展示（当前占位） | |
| 吸底 CTA | 无资格 →「立即获得抽奖资格」；有资格 → 参与状态提示 | |

**下单引导页**（无资格用户点击 CTA 后）
- 奖品展示（自动轮播）
- 九重福利展示（占位）
- 「立即报名」按钮 → 跳转下单流程
- 返回主页

**下单成功页**（下单回调后）
- 确认获得资格 + 可参与剩余 N 轮
- 底部按钮回到抽奖主页
