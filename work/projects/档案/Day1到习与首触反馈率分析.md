# Day1 到习与首触反馈率分析

## 一、引入

本文档围绕两个问题：

> - **Day1 到习问题**：用户为什么没有 Day1 到习。
> - **首触反馈率问题**：首次销售触达后，用户为什么没有形成系统反馈关单。

两个问题在结构上是同一条上游链路的两段：

```
首触 → 加微/入门测/最小任务 → Day1 到习 → 持续完习 → 学情外显 → 反馈关单
            └─── 第二章在这一段 ───┘       └────── 第三章在这一段 ──────┘
```

- **Day1 到习失败** → 没有可反馈素材 → 首触反馈率必然低；
- **即便完习** → 互动没建立 / 服务没沉淀 → 首触反馈率仍然低。

因此 **Day1 到习率是首触反馈率的天花板**，反馈环节单独优化只能撬动小部分用户，必须把上游一起拉起来。

**数据来源**：

- `反馈环节分析.md`（春10 全量 `7,082` 人，其中无反馈记录 `4,678` 人）
- `流失分析.md`（春5-春7 流失复盘）
- `直投用户前置环节-2026春6到春10数据.md`（春6-春10 直投专属 A/B 组）

## 二、用户没有 Day1 到习的原因

`反馈环节分析.md` 把无反馈用户里的 `1,782` 人识别为「未到习」（占无反馈用户 `38.09%`），叠加 `流失分析.md` 的开课三动作模型和直投前置环节数据，根因可以归到三层。

### 1. 开课就绪状态不齐——结构性主因

D1 到习率本质由「**加微 / 首触 / 入门测**」三件套的组合决定。

**春5-7 流失复盘**：

| 开课状态组合 | 占比 | D1 到习率 |
| :- | -: | -: |
| 三者齐备 | 30.5% | **94.4%** |
| 加微 + 首触，无入门测 | 33.8% | 85.5% |
| 仅加微 | 13.1% | 48.2% |
| **三者都没有** | 11.5% | **11.5%** |

**直投春6-春8 累计复现**：

| 用户路径 | A 组（首通率 / D1到习率） | B 组（首通率 / D1到习率） |
| :- | -: | -: |
| **先加微后入门测** | **78.0% / 93.9%** | **75.2% / 93.0%** |
| 仅加微 | 80.0% / 64.3% | 76.1% / 63.0% |
| 其他用户 | 64.9% / 44.2% | 57.4% / 40.4% |

**含义**：D1 未到习首先不是用户不愿学，而是开课节点上没把「能上、知道上、解锁入口」三件事做齐。「仅加微」用户群每期约 `380-420` 人，已建联但未补入门测，是 D1 到习提升 ROI 最高的可激活池——理论上 D1 到习率可从 `64%` 提到 `93%`（**+29pp**）。

### 2. 触达后任务不闭环——沟通可落地的主要漏点

`反馈环节分析.md` 把未到习的 `1,782` 人下钻：

| 原因 | 人数 | 占无反馈用户 | 判断标准 |
| :- | -: | -: | :- |
| **有产品/任务触达但未启动** | **1,221** | **26.10%** | 原始微信/电话里已出现产品、任务或学习安排，但学习状态仍未启动 |
| 无原始触达 / 低线索 | 470 | 10.05% | 未取得有效沟通 |
| 有触达但没有任务引导 | 91 | 1.95% | 原始沟通有触达，但没有明确任务、产品价值或学习安排 |

`1,221` 人是「沟通讲到位了，但没落到'今晚 / 明天孩子具体做什么、做完怎么验'的最小任务上」。与 `反馈环节分析.md` 第六节"加微后给出当晚或次日可完成任务"的设计意图直接对应。

### 3. 启动后操作闭环阻断——把"到习"和"开始完习"区分开看

到习未完习的 `1,098` 人里，`559` 人原始沟通中大量出现：

> 「下载、登录、入口、找不到、不会操作」等信号（占无反馈用户 `11.95%`）

这部分用户其实已经被引导要去学，但卡在产品 / 入口环节，**形式上算"未完习"，但失败发生在"到习"那一步**——下载不动、登录不上、找不到入口，本质和 D1 到习失败是同一类问题。

### 4. 小结：三层原因和优化优先级

| 层 | 行动缺口 | 量级 |
| :- | :- | -: |
| 开课就绪 | 加微 / 首触 / 入门测三件套缺一 | "其他用户" + "仅加微" 占春10 直投 `~54%` |
| 任务闭环 | 触达后未给出最小可完成任务 | `1,221` 人 / `26.10%` 无反馈用户 |
| 启动入口 | 下载、登录、入口、不会操作 | `559` 人 / `11.95%` 无反馈用户 |

**优化优先级**：

1. **补"先加微后入门测"路径渗透率**——把「仅加微」用户群引导补入门测，最大可激活池；
2. **首通话术强制收一个"当晚最小任务"**——解决 `1,221` 个有触达未启动用户；
3. **产品端清掉打开学习的入口摩擦**——下载 / 登录 / 入口 / 不会操作类信号收敛。

## 三、首触反馈率低的原因

按 `流失分析.md` 口径，"首触"指首次销售触达（加微 / 首通），"首触反馈率"是首触后用户能形成系统反馈关单的比例。

把 `反馈环节分析.md` 里 `4,678` 个无反馈记录用户拆开，可以看到首触反馈率低是 **「没素材 + 没互动 + 没沉淀 + 没认知」四层叠加** 的结果。

### 1. 没素材：用户没走到可反馈的位置（占无反馈 `61.6%`）


这 `2,880` 人没有完习结果，反馈关单缺基本素材。**反馈不出来不是反馈环节本身的问题，而是上游断了**——见第二章。

### 2. 没互动：首触建联没转成"老师真的看过孩子"

`反馈环节分析.md` 第三章用户有效回复条数表是最直接证据：

| 用户有效回复条数 | 人数 | 占全量 | 销售人均发送 | 匹配反馈电话率 | 转化率 |
| :- | -: | -: | -: | -: | -: |
| **0 条** | **1,885** | **26.62%** | 5.53 | **4.93%** | 0.85% |
| 1-10 条 | 2,908 | 41.06% | 23.62 | 24.66% | 9.56% |
| 11-30 条 | 1,711 | 24.16% | 45.23 | 36.88% | 22.38% |
| 31-50 条 | 380 | 5.37% | 72.27 | 42.11% | 37.11% |
| 50 条以上 | 198 | 2.80% | 120.81 | 29.80% | 46.97% |

**全量 `26.62%` 的用户从加微到结束 0 条有效回复**，销售人均还发了 `5.53` 条。家长没有经历过"老师看过我家孩子的状态、发的东西让我想回复"的时刻，所以走不到反馈预约。

**回复条数和匹配反馈电话率呈强单调相关**，说明互动量本身就是反馈率的前置条件。

### 3. 没沉淀：服务发生过但没归集成反馈关单（最被忽视的一层）

看 2 阶段及以上完习无反馈记录的 `1,112` 人：

| 二级问题 | 人数 | 占比 | 转化率 |
| :- | -: | -: | -: |
| 沟通没成功 / 用户未接住 | 608 | 54.68% | 5.76% |
| **已有反馈雏形但未完整反馈** | **466** | **41.91%** | 3.22% |
| 2 阶段及以上完习但无学情 / 反馈解释 | 37 | 3.33% | 2.70% |

`466` 人是关键信号：**微信里已经有反馈、学情解释、产品价值连接的雏形，但系统就是没有反馈关单**。再叠加全量无反馈转化的 `78` 人，其中 `77` 人原始电话 / 微信里也已发生了服务推进或学情解释——只是没沉淀。

也就是说，首触反馈率低有相当一部分**不是"没服务"，而是"服务发生了但没结构化"**。

### 4. 没认知：反馈前家长不会主动谈产品，电话只能裸接

`反馈环节分析.md` 第三章 2 小节 `1,660` 人表：

| 反馈前状态 | 人数 | 占匹配反馈电话用户 | 转化率 |
| :- | -: | -: | -: |
| 微信无产品表达 + 电话未形成可决策承接 | 278 | 16.75% | 26.62% |
| 微信无产品表达 + 电话形成可决策承接 | 987 | 59.46% | 33.64% |
| 微信有产品表达 + 电话未形成可决策承接 | 76 | 4.58% | 34.21% |
| **微信有产品表达 + 电话形成可决策承接** | **288** | **17.35%** | **38.19%** |

**家长在反馈前 `~76%` 都没有主动提产品**（`278 + 987 = 1,265` 人），电话只能从零讲起，反馈电话本身就拿不到该有的承接位置，相当一部分首触→反馈链条到这里就断了。

### 5. 小结：四层原因和优化优先级

| 层 | 卡点 | 量级（无反馈用户中） |
| :- | :- | -: |
| 没素材（上游漏） | 未到习 / 未完习 | `2,880` 人 / `61.6%` |
| 没互动 | 全程 0 条有效回复 | `1,885` 人 ≈ 全量 `26.6%` |
| 没沉淀 | 已有反馈雏形但未关单 | `466` 人（2 阶段以上完习未反馈中占 `41.9%`） |
| 没认知 | 微信无产品表达 | 匹配反馈电话用户中 `~76%` |

**优化优先级**：

1. **先补上游**——把 D1 到习 / 完习率拉上来（见第二章），没素材的反馈率讨论是空的；
2. **互动门槛改造**——把"老师可能给我发了很多东西"改成"老师看过孩子情况"，参考 `反馈环节分析.md` 第六章"建立问题共识"的首通设计；
3. **反馈关单刚性化**——完习触发后给销售一个"必须沉淀"的关单动作，把那 `466` 个已经发生的反馈雏形归集起来；
4. **反馈前认知预热**——在加微 / 首通环节标准化产品介绍（参考 `反馈环节分析.md` 第六章 1 节），不让反馈电话裸接。

## 四、合并视角：行动优先级一张表

把两章七个原因按"上游 → 下游"的优先级排成一张表，**越靠上游越是天花板，越靠下游边际越小**：

| # | 链路位置 | 原因 | 量级 | 优化动作 | 影响 |
| -: | :- | :- | -: | :- | :- |
| 1 | 开课就绪 | 加微 / 首触 / 入门测三件套缺一 | 春10 直投 `~54%` | 「仅加微」用户引导补入门测 | D1 到习 `+29pp` |
| 2 | 触达 → 启动 | 触达后未给出"当晚最小任务" | `1,221` 人 | 首通话术强制收一个最小任务 | 直接拉 D1 完习 |
| 3 | 启动入口 | 下载 / 登录 / 入口操作障碍 | `559` 人 | 产品端清掉入口摩擦 | 拉到习 → 完习转化 |
| 4 | 触达 → 互动 | 全程 0 条有效回复 | `1,885` 人（全量 `26.6%`） | 加微后"建立问题共识"的首通设计 | 反馈率前置条件 |
| 5 | 完习 → 反馈 | 反馈雏形未关单 | `466` 人 | 完习触发的强制反馈关单动作 | 直接补反馈率 |
| 6 | 反馈前认知 | 微信无产品表达 | 匹配反馈电话用户 `~76%` | 加微 / 首通标准化产品介绍 | 提升反馈电话承接 |

## 五、家长心理路径的目标态

最终家长心理路径要从：

> `加微信 → 收提醒/介绍 → 催孩子试学 → 听反馈/产品 → 仍然不确定是否适合`

改成：

> `知道产品 → 建立问题共识 → 看到孩子学习证据 → 老师正式反馈 → 理解长期路径 → 做出更有把握的决定`

这条目标路径正好对应第四章那张表的 6 个动作——**第 1-3 项把"学进去"，第 4-6 项把"看得见 + 能决策"**。
