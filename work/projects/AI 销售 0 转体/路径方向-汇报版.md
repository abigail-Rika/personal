# AI 销售 0 转体：路径方向汇报

> 目的：在 PRD 细化前，先和领导对齐"走哪条路 / 哪几条路并行"

---

## 一、目前看到的 3 条路径

| | 形态 | 关键代价 |
|---|---|---|
| **A · 主路径**（当前 PRD 默认） | AI 外呼 → 加微 → AI 首诊 → 购买 → 转交 | 链路最长；加微率（≈24%）是天花板 |
| **B · 短信直购** | AI 外呼建联 → 短信发购买链接 → 用户自决购买 | 转化率上限 ≈ 7%（参考断课非限购 APP 自决率）；无服务入口、断了正价承接 |
| **C · 人工兜底** | AI 外呼接通 → 直接转人工 → 人工 APP 内成单 | 人工成本回来了，违背"AI 边际成本为零"的项目立意 |

> **几条路径不一定互斥**：
> - **A + B 兜底**：主路径走 A，加微失败的 76% 用户用 B 自动短信兜底，几乎零成本叠加
> - **A 走增量线 + C 走效率线**：未析出用户走 A，已析出但 CC 没空跟的走 C，两条线分开打

---

## 二、想和领导对齐的 3 个判断

1. **要不要押注 A？**
   A 是最难的，但也是项目最有想象力的方向。如果只做 B / C，本质上不是"AI 销售"，是"AI 触达 + 旧打法"——项目定位需要改写。

2. **能不能接受 C？**
   接受 C 意味着项目立意从"AI 替代销售"降级为"AI 辅助销售"——故事和 KPI 都要重写。

3. **加微率 24% 是话术问题还是结构性问题？**
   - 如果是话术能修 → A 的天花板能大幅抬升
   - 如果是结构性的（用户根本不愿意加销售微信）→ A 的瓶颈卡死，必须考虑 B 兜底

---

## 三、用到的数据基线

| 数据 | 取值 | 用途 |
|---|---|---|
| 新用户落地页 9 元自然成单率 | 15% | B 路径天花板（实际要打折——已看过没买的二次转化） |
| 断课非限购用户 APP 内主动复购率 | 7% | 任何"零沟通自决"路径的真实参考基线 |
| 兄弟业务"接通未加微"二次召回成单率 | 5% | C 路径核心参数 |
| 主路径预计析出率 | 接通 77% × 加微 24% × 购买 17% ≈ 3% | A 路径基线 |
