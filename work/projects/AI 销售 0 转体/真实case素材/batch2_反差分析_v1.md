## 2. 6 大新发现

### 发现 1（**已被 case4 修正**）：「**有效首诊接触 ≥5min**」是 1A 系路径硬门票，但**电话不是唯一形式**

| | 有效首诊接触 ≥5min | 无有效首诊接触 |
|---|---|---|
| 样本 | case3（电话 9.5min）+ case9（电话 6.8min）+ **case4（微信语音 1 小时）** = **3/3 成单** | case6/7/8/10 = **0/4 成单** |
| 路径 | 1A 标准销售（电话首通）或 **1A' 微信语音替代**（case4 新揭示）| 退化为「销售单向群发模式」或直接放弃 |

> 修正后的结论更普适：**有效首诊接触时长 ≥5min** 是 1A 系（含 1A'）路径运行的前提，不论这个"接触"发生在电话上还是微信语音上。
>
> **case4 提供的反例非常有价值**：它证明 AI 销售在电话首通失败时**完全有能力用微信语音替代**——这是一条之前 SOP 没设计过的兜底路径。
>
> AI 销售的设计含义：
> 1. 首通环节准备**两种形式的钩子**（电话钩子 + 加微即语音通话钩子）
> 2. 电话第 2 通仍失败时**自动切到微信语音通道**，不要继续硬拨电话
> 3. **"重试时机 / 通道切换" > "换话术"**——本结论仍然成立

### 发现 2（最具反思性）：4 个"未接通"里 **3 个不是用户拒绝、是号码占线**——DB 口径有 bug

每个 `duration=0` 的录音文本第一句都是：

> **"您好，您拨打的电话正在通话中，请稍后再拨。The number you have dialed is busy, please try again later."**

这是 **运营商占线播报**，不是用户拒接。但 DB 表 `tutor_call_record.status=3` 被标成"用户拒绝"——这意味着：

1. **数据治理层面**：现在"用户拒接"指标里混入了大量"号码占线"，所有基于该字段的转化漏斗分析都偏差。
2. **AI 销售产品层面**：当外呼播报为"占线"时，AI 应当**自动延后重试 + 跨日重排**，而不是当下重拨。case8 是反例：13:33:58 / 13:35:15 / 13:36:04 三通密集占线 + 18:57:14 / 18:57:29 又两通密集占线，**5 通全在同一天 5 小时内**——用户根本没被触达。
3. **应作为 §6 实操建议 / §7 AI 销售产品红线条目**：占线 ≠ 拒绝，重排时机优于重拨频次。

### 发现 3（最反直觉）：**失败 case 与成单 case 的销售开场话术完全一致**——差异不在话术

case7（失败）/ case8（失败）/ case9（成单）三位不同销售的加微首句话术**用的是同一套模板**：

> 「**[愉快]孩子妈妈您好[庆祝]，我是海豚专属规划师 [烟花]XX老师[烟花]，有 4 年线上辅导经验+3 年线下教学经验... 方便的话您先给我发一下：【孩子的小名+年级】，我来给孩子建立学习档案**」

3 个 case 的首句开场逐字几乎一致。但用户反应完全不同：

| case | 用户首次反应 | 销售下一步 |
|---|---|---|
| case9 ✅ | 「聪聪，六年级」+ 主动追问「牛牛老师怎样学习」 | 销售按 SOP 继续问"现在成绩怎么样" → 4 小时内拿到完整学情 → 12:30 立刻打电话 |
| case7 ❌ | 「四年级」（只回年级，没回小名）| 销售当下回复 1 条「妍妍妈妈下午好」，**然后整个跟进周期再没问过学情**，直接进入抢购/优惠群发 |
| case8 ❌ | **完全没回** | 销售 3 天后直接进入"周年庆活动来了"群发 |

**销售的"是否继续挖学情" 是 case 走向的真正分水岭**，而这个决策**强相关于用户在加微后第一条业务回复的丰富度**：

- 用户给到「小名+年级+追问」→ 销售有抓手 → 继续挖
- 用户只给一半信息或不回 → 销售在 24h 内放弃挖学情 → 路径退化为 SOP

> ✅ 这是 §1A 的关键候选动机：**"加微后第一条业务回复的丰富度"是销售决策树的输入特征**。AI 销售在这一步要主动追问拉满信息，而不是默认接受用户的最简回复。

### 发现 4：**销售工作模式只有两态**——「1A 标准销售」或「SOP 群发」，没有中间状态

观察 5 个未成单 case 的中后期，销售消息都呈现高度模板化、群发型特征：

- 抢购倒计时（"今天报 vs 明天报，差别有多大"）
- 限时活动（"金牌助理只剩最后 2 个名额"）
- 政策迁移焦虑（"七年级是初中最关键的爬坡期"）

这跟 case1（晨晨案）/ case2（三年级宝贝案）的销售后期跟进模式**完全一致**——case1 中 hexinwh09 在 4-11~4-13 的 48 小时内推送了 40+ 条话术，case7 凡冉冉在整个 46 天里推送了 56+ 条。

> ✅ 这意味着 §3 反向② 的"失望点"候选条目需要新增：
> 
> **「销售把'1V1 规划师'承诺降级为 SOP 群发」**——家长一开始被"个性化规划"卖点吸引（这是 §5.2/§5.3 加微钩子的核心承诺），但实际拿到的是 **同模板群发文案**。期望与实际兑现的落差很大。
>
> AI 销售的红线：**绝不主动承诺"专属 1V1 规划"，且 AI 在退化为 SOP 模式时必须显式告知用户，不冒充人类规划师**。

### 发现 5：**同一销售 huxinzz05 跟 3 个 case，3 种结果**——印证「销售技能不是核心变量」

huxinzz05 同时承接：

- case3：`zt-planPage` 直投 → 首通 9.5min + 长聊 26.8min → **¥1049 成单**
- case6：`zt-planPage-0-5` 直投 → 2 通 0 接通且无录音 → **6 小时内弃**
- case10：`vipPageConsult` VIP 咨询 → 12 秒接通秒挂 → **35s 内重拨 2 次后弃** 但 status=0 仍有效

> 同一销售、几乎同期、不同流量 → 完全不同结果。这印证：**销售技能不是 1A 路径成败的核心变量；流量质量 / 接通成功率才是**。
>
> ✅ 这是 §1A 的强力辅证：AI 销售要替代的"销售个人发挥"空间在 1A 路径里其实只有 **10-30%**，剩下 70-90% 决定于流量本身和接通环节。**这是 AI 销售可行性的有利证据**——AI 不需要复制销售的"魅力"，只要把接通环节做对、首诊环节挖深，成单可能就发生了。

### 发现 6：**1A 成单的两种节奏**——case9（当天闭环）vs case3（跨 7 天）

| | case9 当天闭环 | case3 跨 7 天闭环 |
|---|---|---|
| 进班 → 首通间隔 | 5 小时 | 3 天 |
| 首通 duration | 6.8 min | 9.5 min |
| 首通 → 成单间隔 | **8.5 小时** | 7 天（4-11 首通 → 4-18 长聊成单）|
| 关键成单通话 | 首通 6.8 min 就成单 | 第二通长聊 26.8 min 才成单 |
| 用户主动度 | **高**（用户主动追问"牛牛老师怎样学习" + 主动问"语文不好怎么学"）| 待补完 case3 6 问 |

> case9 揭示了 **1A 路径的最快变体**：「进班即首通、首通即成单」。它和 case3 一起划出了 1A 路径的**节奏带宽**：
>
> - **下限**：首通 6.8min + 当天成单（case9）
> - **上限**：首通 9.5min + 二通 26.8min + 跨 7 天成单（case3）
>
> AI 销售实验设计应该覆盖这两个节奏带宽——**实验组A1：首通即逼单；实验组A2：首通诊断+二通逼单**——分别对照转化率。
