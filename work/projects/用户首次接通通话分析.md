# 用户首次接通通话分析

> 原文档：[石墨文档](https://shimo.zhenguanyu.com/docs/kpOzBDlJGmLjivOY) | 创建时间：2026-02-04

## 分析范围

- **通话范围**：首次接通通话（销售和用户第一通接通的电话）
- **时间范围**：1222 期～0119 期直投用户（标单、AB 专组）

## 分析维度

1. **首次通话成功率**：销售和用户建联完成首次通话的困难程度
2. **通话时长分布**：首次接通电话的时长分布
3. **电话内容分布**：首次接通的电话中，通话时长和内容表达的结构

---

## 一、首次通话成功率

### 口径说明

| 指标 | 口径 |
|------|------|
| 首次通话接通率 | 接通人数 / 总人数 |
| 首次电话成功率（接通用户） | 接通电话次数 / 接通用户的总拨通次数（销售视角的成功率） |
| 首次电话成功率（整体） | 接通电话次数 / 总拨通次数 |
| 平均接通拨打次数 | 销售打多少电话才接通（分接通用户 / 整体用户） |

### 关键数据

- **86.87%** 的直投用户能够接起首次通话
- 销售对直投用户发起首次电话的成功率 **17.26%**（vs 大盘标单 **25.93%**）
- 直投销售平均拨打 **5.8 次**（vs 大盘 **3.9 次**）电话用户才会接通
- **24.81%** 的用户拨打一次电话就会接

## 二、电话时长分布

> 通话时长分段口径：0-1m 为 0＜时长≤1min，占比分母为首次接通的电话数

### 关键数据

- **36.7%** 的用户通话时长小于 1min
- 占比较多的另一个区间是 **10~15min**，占比 **17%**
