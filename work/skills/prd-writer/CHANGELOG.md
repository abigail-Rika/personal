# Changelog

## [0.3.0] - 2026-02-27

### Added
- SKILL.md：新增「PRD 类型判断」模块——区分🟢快速验证型和🔵完整方案型
- SKILL.md：快速验证型核心三问：有效性、成本可控、无副作用

### Changed
- **prd-writer 和 prd-review 的定位区分**：
  - prd-writer：从"我的视角"出发的写作思考搭档，口吻从"检查标准"改为"写的时候想想这些"
  - prd-review：从"领导视角"出发的预审工具，增加"领导可能会问"和"改进思路"输出
- SKILL.md：身份定位从"撰写助手"改为"写作搭档"，增加与 prd-review 的关系说明
- SKILL.md：各章节从"撰写标准"改为"写作指引"，口吻从审查式改为引导式
- SKILL.md：自查清单改为"提交前问自己"，用领导追问的方式帮你自检
- prd-review SKILL.md：增加定位说明，强调"帮你发现问题+给改进思路"
- prd-review SKILL.md：输出格式增加"领导可能会问"和"修改优先级"
- PRD_TEMPLATE.md：顶部增加 PRD 类型选择，各节增加 🟢可简化/可跳过 标注

## [0.2.0] - 2026-02-27

- PRD_TEMPLATE.md：新增 1.2 用户视角、1.3 问题归因链、2.3 目标依据与成本、4.1 方案定位、4.2 方案对比、6.3 效果归因设计
