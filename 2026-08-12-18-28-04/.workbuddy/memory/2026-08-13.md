# 2026-08-13

- 跟进用户 Obsidian Claudian 配置 DeepSeek 的问题：用户反馈按 DeepSeek 官方文档配置但仍失败。文档里提供了两个 base_url（OpenAI 与 Anthropic 两种格式），关键提示 Claudian 基于 Anthropic SDK，应使用 `https://api.deepseek.com/anthropic`。
- **根因已定位（通过读插件源码）**：Claudian 2.1.3 不是直连 API 的聊天插件，而是拉起 Claude Code/Codex CLI 子进程作为 agent（manifest 描述 + 代码中的 cliResolver/child_process/spawn 证据）。用户机器上 `claude`、`codex` 均未安装 → `prepare()` 阶段 `supervisor.acquire()` 起进程失败 → 抛 `ChatExecutionPreHandoffError` → UI 只显示 "Message was not sent. Please try again."，无网络请求、无 console 报错。另外插件 data.json 中只有 tabManagerState，未见已保存的 provider 配置。
- 解决方案：`npm install -g @anthropic-ai/claude-code`（系统 node 在 /usr/local/bin，可用）→ 在 Claudian 设置里配置 DeepSeek provider（base_url 用 https://api.deepseek.com/anthropic、key、模型 deepseek-v4-pro）→ 重启 Obsidian。
