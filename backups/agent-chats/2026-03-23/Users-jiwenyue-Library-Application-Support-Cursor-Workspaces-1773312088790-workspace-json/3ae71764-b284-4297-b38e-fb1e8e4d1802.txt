Description: # 海豚AI学 - 产品与技术上下文

## 产品概览

- **产品名称**：海豚AI学
- **所属公司**：猿辅导
- **产品定位**：AI驱动的小学数学在线学习产品
- **核心模式**：AI老师实时讲解 + 互动练习，替代真人直播课
- **目标用户**：小学生（当前主要覆盖五年级），使用人教版数学教材

## 课程流程

一节数学AI课的典型流程：
1. **例题讲解**（example）— AI老师逐步讲解例题，配合板书动画
2. **练习题**（exercise）— 学生独立做题，AI实时判断和反馈
3. **语音快答**（quick-ask）— 口头快速问答，检验理解

关键交互组件：
- **题目面板**：展示题干、选项
- **板书区**：AI老师的手写讲解动画
- **答题区**：选择题、填空题、判断题等多种交互形式
- **AI形象（"小白"）**：虚拟老师形象，配合语音讲解

## 设备与端

- **手机端**：横屏使用，左右等宽分栏（左题目 | 右板书+交互）
- **Pad端**：竖屏使用，单栏布局
- **客户端**：iOS + Android 原生壳，内嵌 WebView 加载前端页面

## 业务核心指标

| 指标 | 说明 |
|------|------|
| 首单 ROI / UE | 首次付费的投入产出比和单位经济模型 |
| 体验课转化率 | 体验课用户转为正价课付费用户的比例 |
| 周完习率 | 在课用户每周完成学习的比例（在课留存） |
| 长续率 | 老用户续费下一期课程的比例 |
| 退费率 | 用户申请退费的比例 |

## 用户生命周期

```
获客 → 体验课 → 首单转化 → 在课学习 → 续费/断课
         ↓                    ↓           ↓
      转化率              周完习率    长续率/退费率
```

- **断课用户**：曾付费但未续费、当前不在课的老用户
- **在课用户**：当前有正价课在学的用户

## 十、增长侧 AB 实验沉淀

来源：[增长侧 AB 实验汇总](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=963282611)，截至 2025.12.24

### 沉淀的关键认知

**1. 漏斗前端强制行为不一定提升端到端效率**（实验1）
- 强制登录提高了登录率，但流失用户在后续环节同样会流失，说明增量用户质量较低
- 启示：漏斗前端的"堵漏"要区分是真正减少流失还是只是延后流失

**2. 挽留弹窗是有效的析出提升手段**（实验2、4）
- 前测挽留弹窗改版显著提升析出（p=0.002）
- 付费浮层的挽留弹窗也贡献了下单→支付成功率的提升

**3. 信息量与转化存在倒 U 关系**（实验4、5）
- 付费浮层信息更全面 → CTR 反而跌 3pp。猜想：信息过多增加决策成本
- 暖色系优于冷色系，情感驱动 > 信息堆砌
- 启示：析出场景下"简洁+情感"优于"全面+理性"

**4. 加微页与计划页存在交互效应，不能单变量优化**（实验3）
- 最佳组合是"交叉混搭"而非"全新"或"全旧"
- 标单大盘最佳：旧加微+新计划；直投专组最佳：新加微+旧计划
- 原因分析：
  - 新加微页建立"专属学习安排"预期 → 落地旧计划页（有学习规划环节）形成呼应
  - 旧加微页预期弱 → 落地新计划页（清晰课程安排）深化"课程"概念
- 启示：用户预期管理是连续的，相邻页面之间需要"期望差"来保持动力

**5. 试看内容的"替代效应"**（实验6）
- 有试看视频 → 用户在其他位置析出率下跌（4.1%→3.3%）
- 点击过试看的用户在其他页面析出率更低（2.7%）
- 启示：免费体验满足了探索需求，反而降低了付费动机。试看/试用类功能需要在"体验够了"和"还想要更多"之间找到平衡点

**6. 新计划页对早期完课有正向影响，但可能恶化转化**（实验3复盘）
- 直投专组：新计划页显著提升入门测到完测率和 D1 到课率
- 但转化率反而偏低。推测原因：
  - 用户提早自主学习 D1 → D1 完课到销售跟进解锁 D2 的间隔变长
  - 已知 D1D2 解锁间隔 0-1 天、完课间隔 1 天时转化率最高
  - 新计划页筛选效果弱 → 销售做功更分散、效能降低
- 启示：产品优化和服务节奏需要联动，产品侧提前了用户行为但服务侧没跟上

### 实验方法论沉淀

- **AB 平台**：switch 平台，支持实验变量配置和分流
- **置信标准**：p < 0.05 认为置信
- **常见陷阱**：
  - 单看局部指标正向不代表端到端正向（实验1、6）
  - 多变量交叉时单变量分析会误导（实验3）
  - 转化率受销售做功影响大，样式实验对转化率的影响往往不显著（实验3复盘）

**断课老用户析出瓶颈**（整体析出率不到 3%，周活跃 ~1.4w）：
1. **广告位曝光率低**（~41% vs 新用户 97%）：PAD 不展示首页致首页广告位无效（~40%）、秒开关 APP（~25%）
2. **广告位 CTR 低**：「免费」「0 元」等营销文案引发防备，用户需主动点击才能进入析出场景
3. **入口分散**：仅 ~50% 断课活跃用户有广告位曝光

**改进方向**（断课用户增加前测，2026.1 启动 AB）：用前测问答替代营销弹窗，提升曝光率（目标 80%）和参与感，前测通过后展示落地页引导留资。

### CC 全流程 SOP

**阶段一：建联**

目标：电话接通 + 加微信

| 触达轮次 | 操作 |
|---------|------|
| 首次建联 | 两次手机号拨号 + 一次工作台外呼（都没接 → 下一个） |
| 二次跟进 | 两次工作台外呼 + 工作台群发加微短信 |
| 重点跟进 | 以上均未联系上 → 手机发送加微短信 |

**阶段二：挖需（SPIN）**

目标：了解学情、判断意向、打标签（A/B/C）

- **S（现状）**：成绩、学科表现、补习经历、走读/住校、作业时间
- **P（痛点）**：基础薄弱还是思维固化？计算板块还是应用板块？
- **I（影响）**：不解决会怎样（落后、厌学、升学压力）
- **N（价值）**：海豚个性化方案如何匹配

**阶段三：产品介绍 + 约习**

目标：让家长理解产品价值，约定体验课时间

- 介绍学练补三环节 + AI 动画模式
- 约习时间在工作台勾选确认
- 微信留痕 + 到课提醒

**阶段四：回访（完课后）**

目标：反馈学习情况，建立信任，推动转化

首次回访：
1. **破冰** → 确认孩子是否独立完成学习
2. **和孩子聊**（区分小学/初中）→ 表扬学习情况 → 抽查知识点 → 设立小目标 → 确认能否坚持
3. **和家长聊** → 按学练补三步逐一反馈课堂情况（区分学得好/学得差的反馈策略）→ 介绍 AI + 真人助理模式 → 规划学习 → 默认关单

二次回访（体验课全部完成后）：
1. 反馈后续课程表现
2. **达共识**：为什么学 → 为什么在海豚学 → 为什么现在学
3. **默认关单** → 带家长打开 APP 报名

**阶段五：关单与异议处理**

目标：推动付费转化，处理犹豫和拒绝

关单策略（按场景选用）：

| 策略 | 核心方向 |
|------|---------|
| 学情关单 | 按年级拆解知识点递进关系，说明当下不学对后续的影响 |
| 福利关单 | 200 优惠券 / 小猿搜题 VIP / 猿题库终身 / 亲子账号（多孩免费）/ 全科微课视频 |
| 调退保障关单 | 14 天无理由全额调退，按周扣费，合同保障 |
| 竞品对比 | 对比学习机（科大讯飞）/ 松鼠 AI / 线上直播课 / 洋葱，用海豚优势对标竞品不足 |

异议处理：

| 异议 | 应对 |
|------|------|
| 考虑一下 | 追问具体顾虑（时间还是价格），针对性回应 |
| 和爸爸商量 | 争取直接和爸爸沟通，或约定下次联系时间 |
| 孩子不愿意 | 引用之前和孩子的沟通记录，说明孩子实际表现积极 |
| 想再试听 | 强调正式课才有完整规划，14 天内可全额调退 |

### 用户分层标签

**建联后（A/B/C）**：

| 标签 | 条件 |
|------|------|
| A | 有学习经验 + 现未报班/不满意 + 明确需求 + 购买力强 + 配合度高。朋友推荐直接标A |
| B | 配合度高，但不完全满足 A 类条件 |
| C | 配合度低，且不满足 A 类条件 |

**回访后（S/A+/B+）**：

| 标签 | 条件 |
|------|------|
| S | 完课后主动回复 + 家长认可 + 孩子喜欢 |
| A+ | 无主动回复，但家长认可、孩子喜欢 |
| B+ | 回访不配合，微信不回复 |

**转化后**：考虑 / 不考虑

### 工作台操作

- 建联记录：培优/补差、各科成绩、走读/住校、补习班、意向度、约习时间
- 标签管理：建联 A/B/C、回访 S/A+/B+、转化 考虑/不考虑
- 约习时间：工作台勾选确认

[标签体系文档](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=618924380) | 研发侧：Orion 标签平台 | 私域侧：企微标签 → 运营能效平台(emon)

### 用户生命周期（aries_user_identify）

用户在系统中的核心身份标签，驱动所有入口展示、限购判断和人群圈定。

```
注册用户(REGISTER_USER)
    ↓ 购买体验课 / leads 激活
体验在读(TRIAL)  ←→  销售体验在读(SALES_TRIAL) / CC体验在读(CC_TRIAL)
    ↓ 出班或囤量池释放
体验断课(TRIAL_OVERDUE)  ←→  销售体验断课 / CC体验断课
    ↓ 购买正式会员
会员在读(VIP)  →  销售已转化(SALES_TRANSFORMED) / CC已转化(CC_TRANSFORMED)
    ↓ 到期或退费（过保护期后）
会员断课(VIP_OVERDUE)
```

状态刷新触发事件：leads 激活、会员购买、出班/囤量池释放、退款、会员到期。

注意：
- 体验在读用户退款后仍标记为「体验在读」，出班后才变「体验断课」
- 会员断课 = 到期过保护期 或 退费过保护期（全额退费不用过保护期）
- 销售/CC 身份标签独立于生命周期标签，购买会员后在渠道身份视角始终为「已转化」

### 体验课限购逻辑

限购判断决定用户看到的入口和析出路径，是增长产品的核心规则之一。

**不限购条件**（同时满足）：
1. 用户不是体验在读 / 会员在读 / 会员断课
2. 最近一次购买 CC 或销售体验课的时间 无值 或 距今 ≥ 210 天

即：注册用户、体验断课用户，且距上次购买体验课超过 210 天（约 7 个月），才可再次购买体验课。

### 直投新用户漏斗（实验背景数据）

来源：[强制登录实验](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=859434203) + [计划页提升析出优化](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=913910240)，截至 2025.8

```
App 激活
  ↓ 登录成功率 ~75%（25%在登录环节流失）
注册登录
  ↓ 前测通过率 ~95.56%
前测完成
  ├─ 析出（购买体验课）：前测析出率 ~15.7%
  └─ 未购买进入端内：占全部激活用户 ~53%
      ├─ 20% 在计划页加载前退出
      └─ 80%+ 落在计划页

```

整体析出率 ~17.5%，其中计划页贡献 1.4pp

### 探索中的实验方向：先前测再登录

来源：[先前测再登录方案](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=868016361)，2025.5（方案设计阶段，未上线实验）

**核心假设**：当前"先登录再前测"模式下登录成功率仅 ~75%。如果改为"先前测再登录"，利用沉没成本和认知收获感（"测试让我更了解自己"），登录行为从"门槛"变成"奖励解锁"，预期登录率可提升至 ~90%。

| 模式 | 前测通过率 | 登录成功率 | 预期析出率 |
|------|-----------|-----------|-----------|
| 先登录（现状） | 95.56% | 75% | 15.7% |
| 先登录（优化后） | 96% | 80% | 17% |
| 先前测（预估） | 92% | 90% | 17% |

**竞品参考**：
- 多邻国：开屏→前测→内容学习→登录（登录最后置，沉没成本最大化）
- Brilliant：开屏→前测→登录+订阅→内容学习（前测后立即转化）
- 两者共同点：前测中都嵌入了产品价值展示和动机激励
- 关键差异：海豚场景是"家长下载、孩子使用"，和竞品"用户给自己找工具"不同，不能直接照搬

**状态**：方案设计阶段，标注为"施工中"，待 AB 实验验证（基于经验判断，待验证）

### 沉淀的关键认知

**1. 漏斗前端强制行为不一定提升端到端效率**（实验1）
- 强制登录提高了登录率，但流失用户在后续环节同样会流失，说明增量用户质量较低
- 启示：漏斗前端的"堵漏"要区分是真正减少流失还是只是延后流失

**2. 挽留弹窗是有效的析出提升手段**（实验2、4）
- 前测挽留弹窗改版显著提升析出（p=0.002）
- 付费浮层的挽留弹窗也贡献了下单→支付成功率的提升

**3. 信息量过多可能抑制即时点击**（实验4、5）（单实验猜想，待更多验证）
- 事实：付费浮层信息更全面 → CTR 反而跌 3pp；暖色系全量后整体转化更好
- 猜想：信息过多增加决策成本，析出场景下"简洁+情感"可能优于"全面+理性"

**4. 加微页与计划页存在交互效应，不能单变量优化**（实验3）
- 最佳组合是"交叉混搭"而非"全新"或"全旧"
- 标单大盘最佳：旧加微+新计划；直投专组最佳：新加微+旧计划
- 原因推测（基于数据分析，非验证结论）：
  - 新加微页建立"专属学习安排"预期 → 落地旧计划页（有学习规划环节）形成呼应
  - 旧加微页预期弱 → 落地新计划页（清晰课程安排）深化"课程"概念
- 启示（推测）：用户预期管理是连续的，相邻页面之间需要"期望差"来保持动力

**5. 试看内容的"替代效应"**（实验6）
- 事实：有试看视频 → 计划页析出无显著变化，但其他位置析出率从 4.1%→3.3%；点击过试看的用户在其他页面析出率更低（2.7%）
- 推测：免费体验满足了探索需求，反而降低了付费动机。试看/试用类功能需要在"体验够了"和"还想要更多"之间找到平衡点

**6. 新计划页对早期完课有正向影响，但可能恶化转化**（实验3复盘）
- 事实：直投专组新计划页显著提升入门测到完测率和 D1 到课率（置信）；但转化率偏低（不显著，受多因素影响）
- 推测原因（3个假设，均未验证）：
  - 假设1-跟进间隔：用户提早自主学习 D1 → D1 完课到销售跟进解锁 D2 的间隔变长。参考数据：D1D2 解锁间隔 0-1 天、完课间隔 1 天时转化率最高（来源：历史分析，原始出处待确认）
  - 假设2-筛选效果：新计划页引导效果强 → 更多低意向用户也进入漏斗 → 销售做功更分散
  - 假设3-服务配合度：专组新计划页对应的主动加微率、被动加微成功率整体不如旧计划页
- 启示（推测）：产品优化和服务节奏需要联动，产品侧提前了用户行为但服务侧没跟上

### 实验方法论沉淀

- **AB 平台**：switch 平台（即基建能力中的"AB 实验能力"），支持实验变量配置和分流
- **置信标准**：p < 0.05 认为置信
- **常见陷阱**：
  - 单看局部指标正向不代表端到端正向（实验1、6）
  - 多变量交叉时单变量分析会误导（实验3）
  - 转化率受销售做功影响大，样式实验对转化率的影响往往不显著（实验3复盘）

## 二、增长全链路与核心指标

### 漏斗总览

```

    ↓ 曝光
```

## 三、组织角色与分工

### 线索获取

日常关注端内 leads 析出，从三个层面理解：
- **数量**：充分利用所有流量，关注析出效率
- **抓手**：基于渠道和用户特点设计流程，平衡用户体验和流程效率
- **质量**：不同质量的 leads 适配不同的承接人效和转化形式

### 线索转化：销售 vs CC

| 维度 | 销售（标准单周） | CC |
|------|----------------|-----|
| 周均人效 | 35-40 | 120-150 |
| 跟进形式 | 固定周期进量、标准化流程 | 随时进量、灵活跟进 |
| 用户体验流程 | 所有用户体验统一课程内容 | 沟通学情后定制下发课包 |
| 服务特点 | 更深入，周期更长 | 更灵活：断课用户转化 ~3 天，新客更长 |
| 主接用户身份 | 首次购买体验课的用户 | 新用户 + 断课用户 |
| 主接年级 | 小高 + 初中 | 小低 + 9 年级 |

转化目标：提升人头转化率
1. **提升过程效率**：流程优化提升加微率、到完课率等
2. **效果外化**：提升体验课的价值感知

### 自习助理

提供学习服务，保证到习、完习，确保学习效果。归因窗口 14 天。

## 二、增长全链路与核心指标

### 漏斗总览

```
市场投放（信息流/直播电商/app直投）
    ↓ 曝光
落地页 / 电商渠道
    ↓ leads 析出（析出率）
体验课购买
    ↓ 分配（按用户质量/年级分给销售或CC）
建联（电话 + 加微）
    ↓ 加微率 / 首通率
催习
    ↓ day1 到习率
体验课完课
    ↓ day1 完习率 / day2 到习 / 完习率
回访和服务
    ↓ 转化率
首单购买（正价课）
    ↓ 首单 ROI / UE
在课学习
    ↓ 周完习率
续费 / 断课
    ↓ 长续率 / 退费率
```

## 三、组织角色与分工

### 线索获取

日常关注端内 leads 析出，从三个层面理解：
- **数量**：充分利用所有流量，关注析出效率
- **抓手**：基于渠道和用户特点设计流程，平衡用户体验和流程效率
- **质量**：不同质量的 leads 适配不同的承接人效和转化形式

### 线索转化：销售 vs CC

| 维度 | 销售（标准单周） | CC |
|------|----------------|-----|
| 周均人效 | 35-40 | 120-150 |
| 跟进形式 | 固定周期进量、标准化流程 | 随时进量、灵活跟进 |
| 用户体验流程 | 所有用户体验统一课程内容 | 沟通学情后定制下发课包 |
| 服务特点 | 更深入，周期更长 | 更灵活：断课用户转化 ~3 天，新客更长 |
| 主接用户身份 | 首次购买体验课的用户 | 新用户 + 断课用户 |
| 主接年级 | 小高 + 初中 | 小低 + 9 年级 |

转化目标：提升人头转化率
1. **提升过程效率**：流程优化提升加微率、到完课率等
2. **效果外化**：提升体验课的价值感知

### 自习助理

提供学习服务，保证到习、完习，确保学习效果。归因窗口 14 天。

### CC 全流程 SOP

**阶段一：建联**

目标：电话接通 + 加微信

| 触达轮次 | 操作 |
|---------|------|
| 首次建联 | 两次手机号拨号 + 一次工作台外呼（都没接 → 下一个） |
| 二次跟进 | 两次工作台外呼 + 工作台群发加微短信 |
| 重点跟进 | 以上均未联系上 → 手机发送加微短信 |

**阶段二：挖需（SPIN）**

目标：了解学情、判断意向、打标签（A/B/C）

- **S（现状）**：成绩、学科表现、补习经历、走读/住校、作业时间
- **P（痛点）**：基础薄弱还是思维固化？计算板块还是应用板块？
- **I（影响）**：不解决会怎样（落后、厌学、升学压力）
- **N（价值）**：海豚个性化方案如何匹配

**阶段三：产品介绍 + 约习**

目标：让家长理解产品价值，约定体验课时间

- 介绍学练补三环节 + AI 动画模式
- 约习时间在工作台勾选确认
- 微信留痕 + 到课提醒

**阶段四：回访（完课后）**

目标：反馈学习情况，建立信任，推动转化

首次回访：
1. **破冰** → 确认孩子是否独立完成学习
2. **和孩子聊**（区分小学/初中）→ 表扬学习情况 → 抽查知识点 → 设立小目标 → 确认能否坚持
3. **和家长聊** → 按学练补三步逐一反馈课堂情况（区分学得好/学得差的反馈策略）→ 介绍 AI + 真人助理模式 → 规划学习 → 默认关单

二次回访（体验课全部完成后）：
1. 反馈后续课程表现
2. **达共识**：为什么学 → 为什么在海豚学 → 为什么现在学
3. **默认关单** → 带家长打开 APP 报名

**阶段五：关单与异议处理**

目标：推动付费转化，处理犹豫和拒绝

### 用户生命周期（aries_user_identify）

用户在系统中的核心身份标签，驱动所有入口展示、限购判断和人群圈定。

```
注册用户(REGISTER_USER)
    ↓ 购买体验课 / leads 激活
体验在读(TRIAL)  ←→  销售体验在读(SALES_TRIAL) / CC体验在读(CC_TRIAL)
    ↓ 出班或囤量池释放
体验断课(TRIAL_OVERDUE)  ←→  销售体验断课 / CC体验断课
    ↓ 购买正式会员
会员在读(VIP)  →  销售已转化(SALES_TRANSFORMED) / CC已转化(CC_TRANSFORMED)
    ↓ 到期或退费（过保护期后）
会员断课(VIP_OVERDUE)
```

状态刷新触发事件：leads 激活、会员购买、出班/囤量池释放、退款、会员到期。

注意：
- 体验在读用户退款后仍标记为「体验在读」，出班后才变「体验断课」
- 会员断课 = 到期过保护期 或 退费过保护期（全额退费不用过保护期）
- 销售/CC 身份标签独立于生命周期标签，购买会员后在渠道身份视角始终为「已转化」

### 体验课限购逻辑

限购判断决定用户看到的入口和析出路径，是增长产品的核心规则之一。

**不限购条件**（同时满足）：
1. 用户不是体验在读 / 会员在读 / 会员断课
2. 最近一次购买 CC 或销售体验课的时间 无值 或 距今 ≥ 210 天

即：注册用户、体验断课用户，且距上次购买体验课超过 210 天（约 7 个月），才可再次购买体验课。

## 四、增长侧 AB 实验沉淀

来源：[增长侧 AB 实验汇总](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=963282611)，截至 2025.12.24

### 实验清单

| # | 实验 | 上线 | 核心结论 | 结果 |
|---|------|------|---------|------|
| 1 | 强制登录实验 | 2025.5（数据观测期 9.12~10.12） | 「强制+有利益文案」登录率比「可跳过」高 1.4pp（置信），但登录析出率和端到端效率无显著差异 | 下线强制无文案组 |
| 2 | 前测挽留弹窗 | 2025.8.18 | 新弹窗样式析出率显著优于旧样式（p=0.002） | 全量实验组 |
| 3 | 加微页 x 计划页交叉实验 | 2025.8 | 交叉组合效果更好（旧加微+新计划、新加微+旧计划）；新计划页显著提升入门测到测率 | 全量旧加微+新计划 |
| 4 | 计划页付费浮层优化 v1 | 2025.8.28 | 旧样式 CTR 更好；新样式下单→支付成功率更高（由挽留弹窗贡献）。信息更全面的弹窗 CTR 反而跌 3pp | 继续优化 |
| 5 | 计划页付费浮层优化 v2 | 2025.10.30 | 暖色系整体转化更好 | 全量暖色 |
| 6 | 计划页试看视频 | 2025.10.13 | 售卖落地页曝光提升，但整体析出率下跌。计划页析出无显著变化，其他位置析出率从 4.1%→3.3%（点击过试看的用户更低：2.7%） | 回滚 |
| 7 | 加微页优化 v2 | 2025.12.09 | 进行中 | — |

### 直投新用户漏斗（实验背景数据）

来源：[强制登录实验](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=859434203) + [计划页提升析出优化](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=913910240)，截至 2025.8

```
App 激活
  ↓ 登录成功率 ~75%（25%在登录环节流失）
注册登录
  ↓ 前测通过率 ~95.56%
前测完成
  ├─ 析出（购买体验课）：前测析出率 ~15.7%
  └─ 未购买进入端内：占全部激活用户 ~53%
      ├─ 20% 在计划页加载前退出
      └─ 80%+ 落在计划页
           └─ 30% 有点击行为（资料库/我的/首页各占 ~40%）
```

整体析出率 ~17.5%，其中计划页贡献 1.4pp

### 探索中的实验方向：先前测再登录

来源：[先前测再登录方案](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=868016361)，2025.5（方案设计阶段，未上线实验）

**核心假设**：当前"先登录再前测"模式下登录成功率仅 ~75%。如果改为"先前测再登录"，利用沉没成本和认知收获感（"测试让我更了解自己"），登录行为从"门槛"变成"奖励解锁"，预期登录率可提升至 ~90%。

| 模式 | 前测通过率 | 登录成功率 | 预期析出率 |
|------|-----------|-----------|-----------|
| 先登录（现状） | 95.56% | 75% | 15.7% |
| 先登录（优化后） | 96% | 80% | 17% |
| 先前测（预估） | 92% | 90% | 17% |

**竞品参考**：
- 多邻国：开屏→前测→内容学习→登录（登录最后置，沉没成本最大化）
- Brilliant：开屏→前测→登录+订阅→内容学习（前测后立即转化）
- 两者共同点：前测中都嵌入了产品价值展示和动机激励
- 关键差异：海豚场景是"家长下载、孩子使用"，和竞品"用户给自己找工具"不同，不能直接照搬

**状态**：方案设计阶段，标注为"施工中"，待 AB 实验验证（基于经验判断，待验证）

### 沉淀的关键认知

**1. 漏斗前端强制行为不一定提升端到端效率**（实验1）
- 强制登录提高了登录率，但流失用户在后续环节同样会流失，说明增量用户质量较低
- 启示：漏斗前端的"堵漏"要区分是真正减少流失还是只是延后流失

**2. 挽留弹窗是有效的析出提升手段**（实验2、4）
- 前测挽留弹窗改版显著提升析出（p=0.002）
- 付费浮层的挽留弹窗也贡献了下单→支付成功率的提升

**3. 信息量过多可能抑制即时点击**（实验4、5）（单实验猜想，待更多验证）
- 事实：付费浮层信息更全面 → CTR 反而跌 3pp；暖色系全量后整体转化更好
- 猜想：信息过多增加决策成本，析出场景下"简洁+情感"可能优于"全面+理性"

**4. 加微页与计划页存在交互效应，不能单变量优化**（实验3）
- 最佳组合是"交叉混搭"而非"全新"或"全旧"
- 标单大盘最佳：旧加微+新计划；直投专组最佳：新加微+旧计划
- 原因推测（基于数据分析，非验证结论）：
  - 新加微页建立"专属学习安排"预期 → 落地旧计划页（有学习规划环节）形成呼应
  - 旧加微页预期弱 → 落地新计划页（清晰课程安排）深化"课程"概念
- 启示（推测）：用户预期管理是连续的，相邻页面之间需要"期望差"来保持动力

**5. 试看内容的"替代效应"**（实验6）
- 事实：有试看视频 → 计划页析出无显著变化，但其他位置析出率从 4.1%→3.3%；点击过试看的用户在其他页面析出率更低（2.7%）
- 推测：免费体验满足了探索需求，反而降低了付费动机。试看/试用类功能需要在"体验够了"和"还想要更多"之间找到平衡点

**6. 新计划页对早期完课有正向影响，但可能恶化转化**（实验3复盘）
- 事实：直投专组新计划页显著提升入门测到完测率和 D1 到课率（置信）；但转化率偏低（不显著，受多因素影响）
- 推测原因（3个假设，均未验证）：
  - 假设1-跟进间隔：用户提早自主学习 D1 → D1 完课到销售跟进解锁 D2 的间隔变长。参考数据：D1D2 解锁间隔 0-1 天、完课间隔 1 天时转化率最高（来源：历史分析，原始出处待确认）
  - 假设2-筛选效果：新计划页引导效果强 → 更多低意向用户也进入漏斗 → 销售做功更分散
  - 假设3-服务配合度：专组新计划页对应的主动加微率、被动加微成功率整体不如旧计划页
- 启示（推测）：产品优化和服务节奏需要联动，产品侧提前了用户行为但服务侧没跟上

### 实验方法论沉淀

- **AB 平台**：switch 平台（即基建能力中的"AB 实验能力"），支持实验变量配置和分流
- **置信标准**：p < 0.05 认为置信
- **常见陷阱**：
  - 单看局部指标正向不代表端到端正向（实验1、6）
  - 多变量交叉时单变量分析会误导（实验3）
  - 转化率受销售做功影响大，样式实验对转化率的影响往往不显著（实验3复盘）

### CC 全流程 SOP

**阶段一：建联**

目标：电话接通 + 加微信

| 触达轮次 | 操作 |
|---------|------|

**阶段二：挖需（SPIN）**

目标：了解学情、判断意向、打标签（A/B/C）

- **S（现状）**：成绩、学科表现、补习经历、走读/住校、作业时间
- **P（痛点）**：基础薄弱还是思维固化？计算板块还是应用板块？
- **I（影响）**：不解决会怎样（落后、厌学、升学压力）
- **N（价值）**：海豚个性化方案如何匹配

**阶段三：产品介绍 + 约习**

目标：让家长理解产品价值，约定体验课时间

- 介绍学练补三环节 + AI 动画模式
- 约习时间在工作台勾选确认
- 微信留痕 + 到课提醒

**阶段四：回访（完课后）**

目标：反馈学习情况，建立信任，推动转化

首次回访：
1. **破冰** → 确认孩子是否独立完成学习
2. **和孩子聊**（区分小学/初中）→ 表扬学习情况 → 抽查知识点 → 设立小目标 → 确认能否坚持
3. **和家长聊** → 按学练补三步逐一反馈课堂情况（区分学得好/学得差的反馈策略）→ 介绍 AI + 真人助理模式 → 规划学习 → 默认关单

二次回访（体验课全部完成后）：
1. 反馈后续课程表现
2. **达共识**：为什么学 → 为什么在海豚学 → 为什么现在学
3. **默认关单** → 带家长打开 APP 报名

目标：推动付费转化，处理犹豫和拒绝

| 竞品对比 | 对比学习机（科大讯飞）/ 松鼠 AI / 线上直播课 / 洋葱，用海豚优势对标竞品不足 |

异议处理：

| 异议 | 应对 |
|------|------|

## 一、分析框架

**核心问题**：不同质量的流量，是否匹配了合理的承接路径？

分析逻辑：梳理流量分类 → 定义质量分级 → 用转化率验证 → 对照承接方式 → 识别错配

**关键原则**：质量必须用服务介入前就能观察到的信号来定义，转化率只用来验证。因为转化率 = leads 本身质量 x 承接方式效果，混在一起无法区分"leads 本来就差"和"被服务拖了后腿"。
