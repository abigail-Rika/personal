在 VS Code / Cursor 的文件树中，这些颜色和标记的含义是：

- **绿色**（如 `_site`、`work`）— 表示**新增的文件/文件夹**，已加入 Git 追踪但远程还没有（或刚提交还没 push 时显示）

| 颜色 | 标记 | 含义 |
