# 灵感库

> 解决「收藏夹吃灰」的个人碎片干货库。刷到好东西 → 丢给我 → 我消化成笔记。

## 和 `知识沉淀/` 有什么区别

两套库分工看**受众**，不按主题分。

- **`知识沉淀/`** 是给 **AI 协作** 用的：沉淀规范、`description` / `triggers` / 自动索引脚本——**AI 自己写、AI 索引、AI 在下次任务里加载**，目的是让 AI 在类似任务中少走弯路。日常你基本不读它。
- **`灵感库/`** 是给 **你自己** 用的：Obsidian 双向链接、`[[MOC]]` 漫游、图谱视图——天然为人浏览设计。**你丢、我消化、你回看**。

所以两库**主题可以正交**：同一条方法论既可以沉淀进 `知识沉淀/`（for AI），也可以进 `灵感库/`（for 你），区别在于谁来用、怎么用，不是「工作向 vs 兴趣向」。

## 与 Abigail 的边界

一句话判据：**这条知识，如果哪天你不做副业了，还留不留？**

- 留 → 通用、长期、跨场景 → 放这里
- 不留（只对副业有意义）→ 放 Abigail 空间

副业专属内容（水晶手串、小红书起号、自媒体运营等）在独立的 Abigail 空间，不放在这里。

## 反哺机制（从 Abigail 搬过来）

Abigail 沉淀出的内容，如果提炼后能脱离副业也成立，可以搬到这里——但**不是复制原文，是重写一版通用版**：

1. 在 Abigail 发现「剥离副业后还有用」的方法 / 原则 / 洞察；
2. 丢给我，说「这条搬到灵感库」；
3. 我用通用语言重写（去掉副业场景词），写进 `笔记/<主题>/`，front matter 标 `source:` 回链 Abigail 原文件；
4. Abigail 原笔记加一行 `已提炼到 Personal 灵感库：xxx` 作去向提示。

反过来，灵感库里的通用方法被副业用上时不用搬，直接拿来用即可。

## 怎么用

1. **丢给我**：刷到一条觉得有用的内容，把链接 / 截图 / 一句话贴给我。
2. **我消化**：我提炼成「这是什么 / 为什么有用 / 你能怎么用」的结构化笔记，写进 `笔记/<主题>/`，并更新 `[[MOC]]` 和 `[[Inbox]]`。
3. **你回看**：在 Obsidian 里通过 `[[MOC]]` 或图谱漫游，笔记之间用 `[[双向链接]]` 连起来。

## 核心原则

**收藏 ≠ 拥有。** 只有消化过、用自己的话写过、能链接到已有知识的，才真正是你的。
