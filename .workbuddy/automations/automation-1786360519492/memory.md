# 每日一个为什么 - 执行记录

## 2026-08-10（第1期）

- **问题：** 为什么手指在水里泡久了会皱得像葡萄干一样？
- **领域：** 人体科学 / 生物学
- **核心知识点：** 手指起皱不是皮肤吸水膨胀，而是神经系统主动调控的血管收缩反应，能增强湿物抓握力（类似轮胎纹路）。
- **趣味点：** 颠覆了"泡水泡发"的直觉认知，揭示了进化赋予的实用功能。

## 2026-08-12（第2期）

- **问题：** 为什么蜂蜜永远不会过期？
- **领域：** 食物科学
- **核心知识点：** 蜂蜜低水分（<18%）、高糖分高渗透压、偏酸性（pH 3-4），三重屏障让微生物无法存��。埃及金字塔中出土的三千年蜂蜜仍可食用。
- **趣味点：** 蜂蜜的保质期比人类文明还长，本身即防腐剂。

## 2026-08-12（第3期）

- **问题：** 为什么天上的白云看着软绵绵的，却不会“哐当”一声掉下来？
- **领域：** 自然科学 / 气象学
- **核心知识点：** 云由极轻的微小水滴或冰晶组成，下落极慢；地面受热产生的上升气流持续托举，使其悬浮。水滴合并变重后才以雨的形式落下。
- **趣味点：** 云其实也在"掉"，只是掉得太慢，像一场被放慢了无数倍的雨。

## 2026-08-13（第4期）

- **问题：** 为什么你听自己录音里的声音，总觉得"这不是我"？
- **领域：** 人体科学 / 声学
- **核心知识点：** 说话时声带振动经头骨直接传导至内耳（骨传导），强化低频使自听声音更浑厚；录音只有气传导版本，少了低频加成，故听感更尖更薄更陌生。
- **趣味点：** 你平时听到的自己的声音，其实是一个自带"低音增强滤镜"的版本，录音才是别人耳朵里真实的你。
