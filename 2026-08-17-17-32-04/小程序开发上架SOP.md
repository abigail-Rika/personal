# 小程序开发 + 上架 SOP

> 适用平台：微信小程序为主，支付宝 / 抖音 / 百度小程序流程类似。教育类目有额外资质要求，见文末专项说明。

---

## 阶段 0：立项与资质准备（最容易被忽略、周期最长）

1. **定平台与形态**：先明确做微信 / 支付宝 / 抖音单一平台，还是多端复用（跨端框架）。
2. **注册账号与主体**：
   - 到对应平台开放平台/公众平台注册「小程序」账号（不是公众号）。
   - 主体分个人 / 企业 / 个体户 / 政府等，**这一步决定能力上限**：
     - 个人主体：免费，但**无法开通支付、不能做直播、部分类目不可选**。
     - 企业主体：需营业执照 + 对公账户 + 管理员实名/对公打款验证，可开通支付。
   - 微信企业主体如要做支付/更多能力，需「微信认证」（300 元/年，可选）。
3. **选定服务类目 + 准备资质**：不同类目需不同资质（教育、医疗、金融、直播、社交、网约车等门槛高）。**先确认类目再立项**，避免开发完发现资质拿不到。
4. **域名与备案（周期 1–2 周，务必提前）**：
   - 注册域名 + 完成 ICP 备案（域名和服务器都要备案）。
   - 配置 HTTPS 证书。
5. **技术选型**：
   - 原生 / Taro / uni-app（一套代码多端）/ 低代码平台（如秒哒）。
   - 后端：自建服务器 或 微信云开发（CloudBase，免运维、免服务器）。
6. **拿到 AppID**，安装对应开发者工具。

## 阶段 1：产品设计

- PRD → 交互稿 → 视觉稿。
- 增长视角：**先定核心转化路径和埋点方案**，别等上线了再补埋点。

## 阶段 2：开发与联调

- 配置 `request` 合法域名白名单（业务域名、WebView 域名同理，必须 HTTPS 且在后台配置）。
- 登录/授权：`wx.login` 换取 openid；手机号需通过认证后才可获取。
- 支付（如需）：申请微信支付商户号，绑定小程序 AppID。
- 联调、真机测试、兼容性测试（iOS/Android、不同机型）。

## 阶段 3：提审

- **隐私合规（强制，缺一不可）**：
  - 填写「用户隐私保护指引」和「收集的信息声明」。
  - 提供《隐私政策》文本，并在小程序内可访问。
- 上传体验版，添加体验成员做真实环境测试。
- 提交审核：**功能必须完整可用**、提供测试账号、上传类目资质材料。
- 审核周期通常 1–7 天。

## 阶段 4：发布与运营

- 审核通过后提交发布，可全量或分阶段（灰度）发布。
- 建立监控：崩溃监控、性能、埋点转化数据。
- 版本管理与回滚机制。
- 迭代：每次改动需重新提审。

## 注意事项清单（按踩坑概率排序）

1. **主体资质决定能力上限**：个人主体无支付、无直播，后期想加只能迁移主体，很麻烦。能上企业主体就上企业。
2. **类目资质提前确认**：教育/医疗/金融等类目资质周期长，**立项前先锁定类目**。
3. **ICP 备案 1–2 周**：域名 + 服务器都要备案，别卡在最后一步。
4. **HTTPS + 域名白名单**：线上请求必须走 HTTPS，且域名要加进后台 `request` 合法域名。
5. **隐私合规是硬门槛**：隐私保护指引、信息收集声明、隐私政策三件套缺一不可，否则直接驳回。
6. **iOS 虚拟支付限制**：虚拟商品（课程、会员、虚拟币）在 iOS 端**不能走微信支付**，否则被拒/下架，需规划合规方案（这直接影响教育类产品的变现路径）。
7. **常见被拒原因**：
   - 诱导分享/关注/下载（如「分享解锁」）。
   - 功能不完整、测试账号打不开、页面白屏。
   - 虚拟支付违规。
   - 类目与内容不符、资质不全。
8. **名称/头像/简介规范**：不得侵权、不得含诱导词、不得与主体不符。
9. **版本号规范**：符合语义化版本，审核通过后**不能随意更改服务类目**。
10. **上线后动作**：埋点先行、灰度发布、保留回滚能力。

---

## 教育类目专项（重要）

- 学科类培训受「双减」政策严格限制，涉学科内容基本无法上架，需先确认业务性质。
- 教育类小程序通常需提供办学/培训相关资质或《增值电信业务经营许可证》等，具体以平台最新类目要求为准。
- 课程售卖涉及虚拟支付，**iOS 端变现方案要单独设计**（这是教育产品的核心合规风险点）。

| 阶段 | 关键产出 | 易错点 |
| --- | --- | --- |
| 立项 | 平台/主体/类目/资质/备案 | 类目资质没提前确认 |
| 设计 | PRD、埋点方案 | 埋点后补 |
| 开发 | AppID、HTTPS、支付 | 域名白名单漏配 |
| 提审 | 隐私三件套、测试账号 | 隐私指引缺失、功能不完整 |
| 发布 | 灰度、监控、回滚 | 一次性全量、无回滚 |
