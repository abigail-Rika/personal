# 用户首次接通通话分析

> 创建时间：2026-02-04 | 数据来源：[石墨文档](https://shimo.zhenguanyu.com/docs/kpOzBDlJGmLjivOY)

## 探查问题

直投用户首次接通通话的成功率、时长分布和内容结构是怎样的？销售建联的效率如何？

## 数据范围与口径

| 维度 | 说明 |
|------|------|
| 时间范围 | 1222 期 ~ 0119 期 |
| 用户范围 | 直投用户（标单、AB 专组） |
| 核心指标口径 | 首次通话接通率 = 接通人数/总人数；首次电话成功率 = 接通次数/总拨通次数；平均接通拨打次数 = 总拨通次数/接通人数 |
| 数据来源 | [石墨文档](https://shimo.zhenguanyu.com/docs/kpOzBDlJGmLjivOY)、[飞书数据](https://my.feishu.cn/base/E4gIbEPoba1LB0sroVpcgreCniC?from=from_copylink) |

## 关键发现

### 发现 1：86.87%的直投用户能接起首次通话，但销售平均要拨5.8次才能接通

| 指标 | 直投用户 | 大盘标单 |
|------|---------|---------|
| 首次通话接通率 | **86.87%** | - |
| 首次电话成功率 | **17.26%** | **25.93%** |
| 平均接通拨打次数 | **5.8 次** | **3.9 次** |
| 拨打一次即接通 | 24.81% | - |

直投用户的接通率不低（86.87%），但单次拨打成功率远低于大盘（17.26% vs 25.93%），销售需要多拨近2次才能接通。24.81%的用户一次就接，剩余用户需要反复拨打。

### 发现 2：36.7%的首次接通通话不到1分钟，但10-15分钟区间也占17%

| 时长区间 | 占比 |
|---------|------|
| 0-1 min | **36.7%** |
| 10-15 min | **17%** |

通话时长呈两极分布：超过三分之一的通话不到1分钟（可能是用户忙/挂断/拒绝），但有显著比例达到10-15分钟的深度沟通。

## 可复用结论

- **直投用户触达成本比大盘高**：平均5.8次拨打 vs 大盘3.9次，销售人效损耗更大
- **首次通话存在明显的"1分钟淘汰关"**：36.7%的通话不到1分钟，销售需要在开场30秒内抓住用户注意力，否则大概率被挂断
- **通话时长两极化意味着用户筛选效果明显**：能聊超过1分钟的用户大概率有真实需求，应该重点跟进
