# 示例：批量状态同步

## 输入

用户一次性汇报多条 todo 状态：

> todo：
> 1. 抽奖激励活动复盘，预计4.5 结束之后整体复盘
> 2. 电商短信，本周一已经上线
> 3. 投放落地页需求，方案中
> 4. 投放前置弹窗，方案中，等下你和我一起写
> 5. 落地页模板适配春季课，已经通过配置完成适配，后续可能会对教材和年级进行组件重构
> 6. 断课前测，目前先解决曝光问题
> 7. 大促需求，下周开始搞

## 处理过程

逐条匹配：

| 用户说的 | 匹配到 | 操作 |
|---------|--------|------|
| 抽奖激励活动复盘，预计4.5结束 | #1 抽奖激励活动需求 | 更新 TODO 和状态 |
| 电商短信，本周一已上线 | #4 电商短信 | 移到已完成 |
| 投放落地页需求，方案中 | #5 投放落地页需求 | 更新状态 |
| 投放前置弹窗，方案中 | #9 投放挽留弹窗 | 更新标题+状态+TODO |
| 落地页模板适配，已完成 | #10 落地页模板适配 | 移到已完成 |
| 断课前测，先解决曝光 | #6 断课前测 | 更新 TODO 和状态 |
| 大促需求，下周开始 | 无匹配 | 新增条目 |

## 输出

更新 todos.md 后，输出摘要：

**状态变更：**
- #1 抽奖激励 → 活动进行中，预计 4.5 结束后整体复盘
- #4 电商短信 → 已完成，移到已完成区
- #5 投放落地页 → 方案中
- #9 投放前置弹窗 → 方案中
- #10 落地页模板适配 → 已完成，移到已完成区
- #6 断课前测 → 目前先解决曝光问题

**新增：**
- #7 大促需求 → 下周开始搞

## 备注

- 用户说"投放前置弹窗"，原 todos 中叫"投放挽留弹窗"，按语义匹配并更新标题
- 电商短信和落地页适配完成后，精简描述移到已完成区
- 排版后序号从 1 重新编排，🔥 的排在 ⏳ 前面
