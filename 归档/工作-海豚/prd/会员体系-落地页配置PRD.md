# 会员体系管理中心 · 落地页配置 PRD

> 业务方向：二手手机回收平台 · 会员体系 · 活动落地页搭建
> 文档版本：v0.1（基于原型图编写）
> 涉及页面：
> 1. `会员体系管理中心 / 落地页配置`（列表页）
> 2. `会员体系管理中心 / 落地页管理 / 新增落地页 / 添加文本组件`
> 3. `会员体系管理中心 / 落地页管理 / 新增落地页 / 添加图片组件`
> 4. `会员体系管理中心 / 落地页管理 / 新增落地页 / 添加按钮组件`

---

## 1. 背景与目标

会员体系活动（实时况价、报价激励等）需要一个**H5 落地页**作为对外承接载体。当前每次活动都要前端写一版定制页面，研发成本高、上线慢、不可复用。

本需求提供一个**可视化落地页搭建后台**，运营在无需开发介入的前提下，可完成：

- **新建 / 复制 / 修改 / 关联活动**的全生命周期管理
- 通过**文本 / 图片 / 按钮**三类基础组件自由拼装落地页
- 与「活动管理」模块联动，可一键绑定到具体活动

---

## 2. 名词解释

| 名词 | 含义 |
| --- | --- |
| 落地页 | 一个对外的 H5 页面，由若干组件按顺序拼装而成 |
| 组件 | 落地页的基本单元，当前支持「文本组件」「图片组件」「按钮组件」三种 |
| 参数 / 参数置换 | 落地页中预留的占位符（如活动名、目标值、奖励额），在关联活动时由系统自动替换为活动实际值 |
| 关联活动 | 一个落地页可被绑定到一个或多个活动；进入活动时打开该落地页 |
| 关联状态 | 落地页是否已被任何活动引用，决定该落地页能否被修改 / 删除 |

## 4. 模块 A：落地页列表

### 4.1 入口与权限

- 入口：`会员体系管理中心` → 左侧导航 → 「落地页配置」
- 权限：仅「活动运营 / 会员体系运营」可见

### 4.2 顶部筛选区

| 字段 | 控件 | 必填 | 说明 |
| --- | --- | --- | --- |
| 创建人 | 输入框 | — | 模糊匹配创建人姓名 / 工号 |
| 修改人 | 输入框 | — | 模糊匹配最近修改人 |
| 业务模块 | 下拉 | — | 选项：实时况价 / 一口价 / 充值返现 ……（**待业务侧补充完整枚举**） |
| 关联活动 | 输入框 | — | 模糊匹配活动名称或活动 ID |
| 修改时间 | 日期范围选择器 | — | 默认空 |

**操作按钮**：
- 主操作 `新建`（蓝色，最右）→ 跳转到落地页编辑器
- 次操作 `搜索`（蓝色）/ `重置`（白色）

**校验**：所有筛选项均可空，等价于不筛选。

### 4.3 列表字段

| 列 | 来源 | 排序 | 说明 |
| --- | --- | --- | --- |
| 落地页 ID | 系统自动生成 | 默认按创建时间倒序 | 8 位数字，例如 `B01001` |
| 创建人 | 自动写入登录账号 | — | — |
| 修改人 | 最近一次修改账号 | — | — |
| 业务模块 | 创建时选择 | 支持 | — |
| 关联活动 | 关联记录 | — | 多个活动用 `、` 分隔；未关联时显示「-」|
| 修改时间 | 自动 | 支持 | `YYYY-MM-DD HH:mm:ss` |
| 操作 | — | — | 见 §4.4 |

### 4.4 行操作

| 按钮 | 显示条件 | 行为 |
| --- | --- | --- |
| 关联活动 | 关联状态 = 未关联 | 弹窗选择一个或多个活动，确认后写入关联表 |
| 复制 | 始终显示 | 复制当前落地页全部配置，生成新草稿，落地页名称自动加 `_copy` 后缀 |
| 编辑 | 关联状态 = 未关联 | 跳转到编辑器，可全字段修改 |
| 查看 | 关联状态 = 已关联 | 跳转到只读编辑器，禁止任何修改（**保护已上线落地页**）|
| 删除 | 关联状态 = 未关联（**待确认**）| 二次确认后软删除 |

**状态联动规则**：
- 已关联活动的落地页：仅允许「查看」「复制」
- 未关联活动的落地页：可「关联活动」「复制」「编辑」「删除」

### 4.5 分页

- 默认每页 10 条
- 支持切换 10 / 20 / 50 / 100
- 支持跳页

## 5. 模块 B：落地页编辑器

### 5.1 顶部信息（编辑器全局字段）

> 顶部为非组件、非可视的元数据，进入编辑器即可填写。

| 字段 | 控件 | 必填 | 校验 |
| --- | --- | --- | --- |
| 落地页名称 | 单行文本 | ✓ | 1 ~ 30 字，同业务模块下不重名 |
| 业务模块 | 下拉单选 | ✓ | 见 §4.2 |
| 备注 | 多行文本 | — | ≤ 100 字 |

### 5.2 三栏布局总览

```
┌──────────┬──────────────────┬──────────────┐
│ 组件库   │  参数预览区       │ 属性配置面板  │
│ (左)     │   (中)            │  (右)         │
│          │                   │               │
│ + 添加   │  ┌─────────────┐ │  当前选中     │
│   文本   │  │ 模拟手机框  │ │  组件的属性   │
│ + 添加   │  │ ↑ 可滚动    │ │  在此编辑     │
│   图片   │  │ ↓ 显示落地页│ │               │
│ + 添加   │  │   实际效果  │ │               │
│   按钮   │  └─────────────┘ │               │
└──────────┴──────────────────┴──────────────┘
              [ 提交 ]    [ 取消 ]
```

**通用规则**：
- 左侧 3 个组件按钮均可**多次点击**，每次点击向预览区追加 1 个新组件
- 中间预览区点击任意组件 → 该组件高亮 + 右侧属性面板自动切换至对应配置
- 右侧属性面板只显示**当前选中组件**的配置；未选中时显示「请在左侧选择组件添加或在中间选择已有组件编辑」的占位说明
- 底部 `提交`（蓝）/ `取消`（白）按钮全局生效，对整个落地页配置生效

### 5.3 组件库（左栏）

| 组件类型 | icon | 行为 |
| --- | --- | --- |
| 添加文本 | 文本 icon | 在预览区追加一个空文本组件 + 自动选中该组件 + 右栏切换至「文本配置面板」 |
| 添加图片 | 图片 icon | 同上，类型为图片 |
| 添加按钮 | 按钮 icon | 同上，类型为按钮（默认行为：关闭弹窗）|

### 5.4 参数预览区（中栏）

预览区按手机比例（375×667 或 750×1334，**待视觉确认**）展示，从上到下渲染所有已配置组件。

**头部固定区**（不可编辑、不可删除）：
- 左侧返回箭头 `<`
- 顶部标题：`请输入_xxx 名称（字符数 xxx）` —— 自动取「落地页名称」字段，超过字符数省略号
- 标题下方说明文字（取自参数置换的说明，由系统读取）

**底部固定区**：
- 蓝色 CTA 按钮：`开始挑战`（**文案是否可配置 - 待确认**）
- 该按钮的跳转行为由活动配置决定（如：报名 / 跳转 H5 / 唤起 App）

**中部可编辑区**（组件渲染区）：
- 按添加顺序从上到下渲染
- 每个组件 hover 时显示「上移 / 下移 / 删除」工具条
- 单击组件 → 高亮 + 右栏属性面板切换
- 拖拽手柄（**待确认是否支持拖拽排序，建议支持**）可自由调整顺序

### 5.5 文本组件 · 属性配置（右栏）

| 字段 | 控件 | 必填 | 校验 / 说明 |
| --- | --- | --- | --- |
| 文本内容 | 多行文本输入框（textarea，≈ 6 行高）| ✓ | 1 ~ 200 字（**待确认**）；支持换行；不支持富文本 |
| 排序 | 三按钮：`上移` `下移` `删除` | — | 「上移」当组件不是第一个时可点击；「下移」当不是最后一个时可点击；「删除」二次确认 |

**默认值**：插入时文本内容为空、定位插入到预览区当前位置。

**待补充字段**（原型未画但建议加，**待评审**）：
- 文本字号（小 / 中 / 大 三档）
- 字体颜色（颜色选择器或固定 4-6 个色板）
- 对齐方式（左 / 居中 / 右）
- 是否加粗 / 是否斜体

> 如设计阶段确认仅支持纯文本（无样式），则按原型保留 1 个 `文本内容` 字段即可。

### 5.6 图片组件 · 属性配置（右栏）

| 字段 | 控件 | 必填 | 校验 / 说明 |
| --- | --- | --- | --- |
| 上传图片 | `上传` 按钮 + 预览缩略图 | ✓ | 支持 jpg / png / webp；≤ 2MB；建议宽度 750px |
| 排序 | 三按钮：`上移` `下移` `删除` | — | 同文本组件 |
| 跳转 | 开关（默认：关）| — | 开 → 显示「跳转链接」输入框；关 → 隐藏 |
| 跳转链接 | 单行文本输入框 | 「跳转 = 开」时 ✓ | 必须以 `http://` 或 `https://` 开头；支持 schema（如 `app://...` **待确认**） |
| 跳转说明 | 灰色小字 | — | 「点击图片将跳转至该链接」（**保持原型文案**） |

**默认值**：
- 「跳转」默认关
- 上传成功后预览图替换占位图

**多张图片**：
- 通过左栏「添加图片」多次点击，可在预览区放多张图片
- 每张图片独立配置自己的跳转

### 5.7 按钮组件 · 属性配置（右栏）

> 按钮组件用于在落地页中插入一个**用图片做样式的可点击区域**，默认行为是**关闭弹窗**（当落地页本身作为弹窗形态承载时）。

**右栏标题**：`添加按钮（关闭弹窗）`

| 字段 | 控件 | 必填 | 校验 / 说明 |
| --- | --- | --- | --- |
| 按钮图片 | `上传` 按钮 + 预览缩略图 | ✓ | 支持 jpg / png / webp；≤ 2MB；建议尺寸 200 × 80 px（**待视觉确认**）|
| 排序 | 三按钮：`上移` `下移` `删除` | — | 同其它组件 |
| 跳转 | 开关（默认：开）| — | 开关语义见下方说明 |

**「跳转」开关语义**（与图片组件不同，**重点对齐项**）：

| 开关状态 | 点击按钮的行为 |
| --- | --- |
| 关 | 执行**默认行为**：关闭当前弹窗（或返回上一页）|
| 开 | **阻止默认关闭行为**；具体跳转目标由**外部活动配置**决定，**本组件不维护跳转 URL** |

**与图片组件的核心差异**：

| 维度 | 图片组件 | 按钮组件 |
| --- | --- | --- |
| 跳转字段 | 上传图片 + 跳转开关 + 跳转链接 | 上传图片 + 跳转开关（**无跳转链接**） |
| 默认行为 | 无（纯展示） | 关闭弹窗 |
| 跳转目标 | 由本组件配置 URL | 由外部活动配置 |
| 典型用途 | 落地页主视觉、长图说明 | 「我知道了」「关闭」「立即参与」等触达后动作按钮 |

> ⚠️ **本组件没有跳转链接输入框**是与图片组件的关键差异，前后端实现时不要错把图片组件的 schema 套过来。
>
> **「跳转开关 = 开」时跳转目标到底取自哪里？** PRD 当前写法是「由外部活动配置决定」，但活动配置里目前没有这个字段。需要与业务方确认：
> 1) 是补一个活动配置字段（推荐）
> 2) 还是按钮组件其实应该补「跳转链接」输入框，原型只是漏画了？
>
> 详见 §9 待确认问题 Q2、Q9。

### 5.8 底部全局操作

| 按钮 | 行为 |
| --- | --- |
| 提交 | 1）全局校验：落地页名称、业务模块、至少 1 个组件、所有组件必填项；<br>2）校验通过 → 调创建/更新接口；<br>3）成功 toast → 回到落地页列表 |
| 取消 | 如有未保存修改，弹二次确认；确认后丢弃修改并返回列表 |

**全局校验逻辑**：

- 至少 1 个非头部、非底部的组件（即文本 / 图片 / 按钮任一）
- 各组件的必填项不能为空
- 图片组件「跳转 = 开」时跳转链接 URL 合法

## 7. 异常 / 边界处理

| 场景 | 处理 |
| --- | --- |
| 上传图片超过 2MB | 阻断 + toast「单张图片不能超过 2MB」 |
| 上传图片格式非 jpg/png/webp | 阻断 + toast「仅支持 jpg、png、webp」 |
| 跳转开关开启但链接为空 | 提交时拦截，输入框标红 |
| 跳转链接不合法 | 输入失焦时标红「请输入合法的 URL」 |
| 按钮组件「跳转 = 开」但活动未配置跳转目标 | 落地页运行时无跳转目标，按 fallback 处理（保持默认关闭，**待业务确认**）|
| 编辑已关联活动的落地页 | 不允许进入「编辑」入口，仅可「查看」 |
| 删除已关联活动的落地页 | 隐藏「删除」按钮 |
| 落地页名称重复 | 提交时后端返回错误「同业务模块下落地页名称已存在」 |
| 网络异常导致提交失败 | toast 「保存失败，请重试」+ 保留本地表单 |

## 9. 待确认问题（评审需对齐）

| # | 问题 | 默认建议 |
| --- | --- | --- |

| Q6 | 落地页是否需要「保存草稿」？ | 提供，避免误关 |
| Q7 | 列表中「业务模块」枚举有哪些？ | 待业务侧补充 |
| Q8 | 跳转链接是否允许 schema (`app://...`)？ | 允许 |
| Q9 | 按钮组件「跳转 = 开」但活动未配置跳转目标时的 fallback 行为？ | 保持默认关闭（不跳转），上报埋点便于排查 |
| Q10 | 关联活动入口：列表行内按钮 vs 活动管理后台反向关联？ | 双向都支持，列表行内为主 |
| Q11 | 落地页是否允许跨业务模块复用？ | 不允许，复用必须先复制 |

| Q13 | 一个落地页是否允许放多个按钮组件？ | 允许（如「立即领取」+「下次再说」），不做数量限制 |

## 10. 附录 · 字段速查表
