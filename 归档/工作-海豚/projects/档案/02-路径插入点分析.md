## 一、先厘清"用户路径"的 5 个维度

讨论里"路径"这个词糅杂了 5 个维度，先拆清楚：

| 维度 | 含义 | 在档案讨论里的角色 |
|:-|:-|:-|
| **来源维度** | 电商 / 直投 / 私域 / 老带新 | 决定档案首诊入口文案 + 进 app 前的认知差异 |
| **设备维度** | iOS / Android / H5 / 小程序 | 决定档案首诊 UI 要做几个版本 |
| **支付路径** | 电商支付 → 跳 app / 直投落地页 → 跳 app / 私域销售推链接 | 决定加微页是否存在、是否前置 |
| **时序维度** | 购买 → 加微 → 启动 → 前测 → 计划页 → 学 → 首通 | **决策点 C 在讨论的就是这条** |
| **激活状态** | 首次启动 / 二次启动 / 跨设备登录 | 决定档案首诊触发时机 |

> 纪要 2.1 的共识只覆盖了"来源 × 时序"两个维度的一个交叉点，剩下维度本节补齐。

## 二、MVP 范围内（新用户付费路径）的插入点设计

### 2.1 来源 × 时序 的主链路

```
电商：电商支付 →【加微页】→ 启动 app →【欢迎层?】→ 前测 → 【档案首诊】→ 计划页 → 学 → 首通
直投：直投支付 →【加微页】→ 启动 app → 前测 → 【档案首诊】→ 计划页 → 学 → 首通
```

**已共识（来自纪要 2.1）**：
- 档案首诊收口在"前测之后 + 计划页首次进入之间"（同一插入点）
- 入口文案做 2 个变体（电商需要补"欢迎"层叙述）

**4 个未对齐的关键缺口**：

| # | 缺口 | 影响业务方 | 紧急度 |
|:-|:-|:-|:-:|
| C1 | 前测 vs 档案首诊的去重：前测已经收年级/教材，档案首诊还要不要再收一次？怎么衔接？ | 体验设计 | 高 |
| C2 | 电商用户的"欢迎层"放在哪：纪要 2.2 说"靠新人引导补不靠档案兜底"，但**新人引导谁来补？** | 电商业务方 + 体验 | 高 |
| C3 | 加微页 vs 档案首诊在 app 启动前后的位置（决策点 C 的子项） | 销售 + 体验 | 高 |
| C4 | 首次进计划页 vs 后续进计划页的入口呈现差异 | 体验设计 | 中 |

### 2.2 设备维度的盲区（**纪要完全没提**）

| 设备 | MVP 是否要做 | 风险 |
|:-|:-|:-|
| iOS / Android | 必做 | 无 |
| **H5** | 需要确认电商部分渠道是否走 H5 落地页（拼多多/抖音商城等可能有） | 如果 H5 占电商一定比例但 MVP 不支持，**电商用户的档案渗透率会有明显缺口** |
| 微信小程序 | 同上 | 同上 |

→ **待和增长 / 电商业务方核对**：电商各渠道 H5/小程序占比？>10% 的话 MVP 范围要重新讨论。

### 2.3 激活状态的盲区

| 状态 | 档案首诊触发逻辑 | 备注 |
|:-|:-|:-|
| 首次启动 | 走主链路 | MVP 必做 |
| 跨设备登录（手机 A 买、平板 B 学） | 档案在哪个设备建立？两个设备如何同步？ | MVP 是否支持待对齐 |
| 二次启动前没填档案 | 顶部入口持续提醒 | 和决策点 B 的 (b) 一致 |

## 三、MVP 不覆盖的路径（先认账、后处理）

按纪要 2.1 共识，以下场景延后处理。本节先做认知，避免组长/业务方临时点名时被问倒。

| 场景 | 延后理由 | 后续处理时点 |
|:-|:-|:-|
| 历史已购用户 | 数据不全、目标感时机已过 | 完整方案阶段考虑"补建档案"机制 |
| AI 销售析出用户 | 进入路径不同，析出后由 AI 销售引导 | 和 v2 AI 销售 0 转体方案合并讨论 |
| 未填首诊补建 | 卡点策略 (b) 软引导可覆盖一部分 | 看 MVP 数据决定是否专门做 |
| 私域用户（已加销售微信再付费） | 量级小、加微页流程不同 | 完整方案阶段 |
| 老带新 | 量级小、用户类型混杂 | 完整方案阶段 |

## 五、3 个最容易被忽略的交叉判断

1. **电商用户买的时候不一定有"目标感"** —— 9 元课对很多电商用户而言更像是"图便宜先囤一份"，目标感建立的难度本身比直投高一档。**档案在两条路径下的预期效果不应该用同一条线衡量** → 验证时必须分桶看。

2. **加微页存在的本质是销售提效，不是用户体验**——这意味着加微页和档案首诊在产品定位上是**对立的**（一个为销售、一个为产品体验）。决策点 C 看似是时序问题，实质是"两个利益方谁先抢用户注意力"的取舍。

3. **决策点 D 的指标选择会反向决定本节的范围**：
   - 选完习率 → 路径设计可以放松，加微页位置不那么重要，工作台改造可以延后
   - 选首通反馈率 → 路径必须严格保证"档案首诊在首通前完成"，工作台改造都要前置
