## 0. 总览：当前对话模拟的核心假设 vs 真实数据

对话模拟里隐含的核心假设：

```
新客触达 = 电话首通 → 加微 → 文字诊断（4 轮）→ 出简报 → 推课 → 价格博弈 → 成单
```

真实数据里发生过的成单链路：

| Case | 渠道 | 电话首通 | 微信首诊 | 成单时点 | 路径 |
|---|---|---|---|---|---|
| case3 | 直投 9.9 元 | **9.5 min 长聊**（4-11）→ 26.8 min 长聊（4-18）| 跨 7 天微信跟进 | 7 天后成单 ¥1049 | **1A 电话标准销售** |
| case9 | 直投 9.9 元 | **6.8 min 首通即成单**（12:30）| 加微 → 12 分钟微信结构化问诊（12:17~12:29）→ 立刻拨电话 | **进班 8.5 小时内闭环** ¥1399 | **1A 电话标准销售（最快变体）**|
| **case4** | VIP 页 model 直投 | **0/6 全失败**（家长手机故障，"已关机"）| 加微 → **1 小时微信语音对话**（≥30 条 VOICE 来回）→ 主动追价 | **次日成单 ¥1399** | **1A' 微信语音替代** ⚠️ |

| Case | 渠道 | 卡在哪个环节 | 原因 |
|---|---|---|---|
| case6 | 直投 9.9 元 | 加微 | 2 通 0 接通即弃，未加微 |
| case7 | 私域 SOP | 首诊 | 加微后用户只回"四年级"，销售 24h 内放弃挖学情，进 SOP 群发 46 天 |
| case8 | AI 外呼弹窗 | 首通 | 5 通密集占线（同日 5 小时内），后续微信单向群发 34 天 |
| case10 | VIP 主动咨询 | 首通 | 12s 接通秒挂，35s 内连拨 3 次后弃，未加微 |

**真实数据传递的 3 个核心事实**：
1. **电话首通不是必经环节**——case4 6 通全失败仍然成单
2. **失败 case 不是"销售技能差"——多数失败发生在「电话未接通」这一上游断点**（4/6 失败）
3. **唯一"首诊环节失败"的 case 是 case7**——用户只回"四年级"，销售当下决策"不挖了"

## 1. 全局悬浮点 ×9 + 修正方向

> 这 9 个悬浮点同时影响 Case A/B/C 三套话术。修正后的话术原型见 §2。

### 悬浮点 1：把"电话首通"当成入口 / 必经环节

**对话模拟里现状**：
- Case A / B1 / B2 / C 全部从 `[电话] 19:32 · AI 拨出，接通约 25-30 秒` 开头
- 阻塞分支里只考虑"在忙 / 不需要 / 你怎么有我电话"等**已接通**情况的话术

**真实数据反例**：
- 4/6 失败 case 卡在"电话未接通"（含占线、关机、秒挂）
- case4 销售期 6 通全失败仍然成单——**靠加微即转语音对话**

**修正方向**：
- 把"电话首通"降级为"触达手段之一"，不是入口
- 阻塞分支必须新增 **「电话未接通 / 占线 / 关机」分支**：
  - 第 1 通失败：30 分钟内重拨 1 次（不同时段）
  - 第 2 通仍失败：**立刻发加微短信 + 微信主动加** → 加微后**主动发起微信语音通话**（不等用户回复）
  - 第 3 通：跨日重排（不同时段段）
- ⚠️ AI 销售相对真人销售在这条路径上有**零成本优势**——没有"销售面子"问题，反复主动语音呼叫的边际成本接近 0

---

### 悬浮点 2：假设家长会按节奏稳定回 4 轮

**对话模拟里现状**：
- Case A 阶段 ③ 设计：家长回 4 轮（"还行吧"→"上次月考88"→"读题转不过来"→"倍数那种"）
- Case B 阶段 ③ 设计：家长回 4 轮（"95"→"应用题+几何"→"不知道用谁除以谁"→"长方形")
- 每轮都是几十字内的清晰具象回复

**真实数据反例**：
- 失败 case 用户回复量：case6 = 0 条 / case7 = 3 条 / case8 = 1 条 / case10 = 0 条
- 唯一"被引导出 4 轮"的是 **case9**（成单），且不是因为话术高明，是因为**用户加微后主动追问"牛牛老师怎样学习"**

**修正方向**：
- **加微后第一条业务回复的丰富度是分流信号**：
  - 用户回「小名+年级+主动追问」→ 进入"快诊深挖模式"（case9 路径）
  - 用户只回小名/年级 → 进入"轻问诊模式"，2 轮就停（不要再追问到第 4 轮）
  - 用户 0 回 → **不要继续追问**，进入"延后触达 + 内容种草"模式（不能假装家长有第 2 轮回应）
- 把 Case A 阶段 ③ 的"4 轮诊断"写成**条件分支**而非固定剧本
- 失败兜底：用户 0~1 条回应时，AI 的下一动作不是「继续问」而是「**说一句然后停**——说一个具体的孩子可能存在的问题/家长可能的痛点，让家长自然接话」

---

### 悬浮点 3：知识点跳跃式诊断（"找谁是 1 份" / "找整体"）

**对话模拟里现状**：
- Case A：从「错应用题大题」→ 「读题转不过来」→ 「倍数还是比多比少」→ 「找谁是 1 份」（**4 跳**）
- Case B：从「错应用题」→ 「不知道用谁除以谁」→ 「找整体」（**3 跳**）

这要求 AI：
1. 能把家长口述映射到具体知识点
2. 家长稳定回 3-4 轮
3. 用 4 年级 / 5 年级具体知识点术语

**真实数据反例**：
- case3、case4、case9 三个成单 case 里**没有一例**出现"找谁是 1 份" / "找整体"这种结构化诊断结论的对话片段（已经全文翻看过）
- case9 真实首诊路径：「现在三年级吧？数学英语最近一次考多少分？」→「应用题确实错了一道」→**就直接推体验课了**，没继续深挖
- case4 直接跳过首诊——加微 2 分钟用户就问"怎么报课"，销售直接讲产品介绍

**修正方向**：
- **首诊不需要给出具体知识点诊断**——真实成单的诊断深度只到「应用题 / 几何 / 概念混淆 / 计算粗心」**大类**层级
- 把"找谁是 1 份" / "找整体"类**具象推断**从首诊阶段移到 **「体验课第 1 节」**——让 AI 老师讲题时再具象化，符合"体验课才是诊断的真正交付物"逻辑
- 首诊话术原型：
  - 「**应用题主要分 3 类——比多比少 / 倍数 / 分数应用题。咱们小朋友主要错哪类，您还记得吗？**」（**给具体选项让家长挑**，不是开放式问)
  - 家长能挑出来 → 顺着推体验课；挑不出来 → 直接推体验课说"体验课第 1 节就能看出来"

### 悬浮点 4：每个 Case 都加"价格博弈 + 不强推承诺"（统一手法）

**对话模拟里现状**：
- Case A：「3 节都是 9 块？后面是不是还要推大课」→ 给"不强推 + 由家长决定"承诺
- Case B：「这 3 节就 9 块？后面会不会推大课」→ 给"不强推"承诺 + 完整学情后家长决定
- Case C：「上次也是 9 块结果你们后面一直推大课」→ 承认"也是销售动作"+ 差异化承诺 + 打断权

**真实数据反例**：
- **9 个 case 中，0 个 case 的家长说过"后面是不是还要推大课"** —— 这是从 case1 失望点反推出来的话术，不是来自家长在购买决策时的真实疑虑
- case4 家长追价问的是「**咱们这个一个学期是多少钱啊**」——她要的是**正价信息**（一上来就追正价），不是"9 元包不包大课"
- case9 家长没有任何价格博弈（直接成单 ¥1399 体验课）

**修正方向**：
- **不要预设家长会问"9 元包不包大课"**——这是 §3 反向②的失望点，**不应该提前在话术里挑明并解决**（反而是露怯）
- 真正需要的话术是 **「家长一上来追正价」的应对**：case4 类型用户加微后 1 小时内追问正价是高意向信号，应**直接给体验课报价 + 简单提一句"体验后家长决定要不要进正价"**
- "不强推"承诺**不写进推课话术，写进售后转交话术**——只有在用户已经付完 9 元后再说"3 节不合适随时退款，由助理给完整学情家长自己决定"，前置说反而显得此地无银

### 悬浮点 5：转交环节过度承诺差异化

**对话模拟里现状**：
- Case A 阶段 ⑤ 转交：「王老师有专门排课工具，比我更对口」
- Case B 阶段 ⑤ 转交：「会有学习管家王老师跟进 ...... 课前一天她会再提醒一次」
- Case C 阶段 ⑤ 转交：「王老师知道您是怎么过来的、看重什么、最反感什么，不会再用通用话术」

**真实数据反例**：
- case1 助理 hexinwh09 跟进 48 小时推送 **40+ 条 SOP 群发**——抢购倒计时 / 优惠倒数 / 政策焦虑
- case7 助理 fanranranzz01 跟进 46 天推送 **56+ 条 SOP 群发**
- case8 助理跟进 35 天单向 SOP 群发
- **0 个 case 的助理期出现过"基于用户具体情况的个性化承接"**

**修正方向**：
- "助理会基于您具体情况"这种承诺**违反 §3 红线 1（不主动承诺专属规划师）**
- 转交话术应当**降到"知道 + 通知"两个动作**：
  - 「**我已经把咱们今天聊到的（年级 / 错题 / 关心点）发给学习管家了。她负责后续的排课和课前提醒，正式上课前一天她会找您。**」
  - **不承诺**"她会用个性化话术 / 她不会推大课 / 她比我更对口"
- 如果担心助理期 SOP 群发被反感，应当在转交时**给用户一个"打断权"的口令**：
  - 「您要是收到我们助理的消息不想看，回一个"先不聊"，她那边会标记，不会再连发」

### 悬浮点 6：忽略「微信语音对话」作为首通替代物（**case4 核心遗漏**）

**对话模拟里现状**：
- 三个 Case 都从"电话 → 加微 → 文字"展开
- **没有任何分支提到加微后销售可以主动发起微信语音通话**

**真实数据反例**：
- case4 销售 zhangzhengxuanzz01 在 03-12 14:23 加微，**14:27 立刻发首条微信 VOICE**，14:27~14:34 双方语音来回 10+ 次（家长 14:28 试图拒绝："现在不方便接"，但 14:29 又主动回了一条 VOICE）
- 14:34 一小时后 15:08 ~ 15:23 第二轮密集语音对话，家长由"现在不方便"转为"咱们这个一个学期是多少钱啊"主动追价
- 整个语音对话相当于**一通 1 小时分布式电话首通**

**修正方向**：
- **新增 Case A'（或在 Case A/B 加分支）**：「电话未接通 / 加微后用户主动追问报课时，立刻发起微信语音通话」
- 微信语音对话相对电话的 3 个优势：
  1. **家长可以"分时听"**——14:23 加微 → 14:43 家长说"一会有时间我看一下再联系你" → 15:08 主动重启对话（电话是同步的，没这个"延后听完再回"机制）
  2. **不需要"挂断"动作**——家长不需要找借口结束（电话经常因为"在忙"被掐断）
  3. **可以混合文字 / 图片 / 卡片**——case4 销售在语音流里穿插了 5+ 张产品图片
- 微信语音对话的 SOP 设计要点：
  - 单条 ≤ 30 秒（家长能快速消化）
  - 关键信息（价格 / 课时 / 优惠）用**文字补一条**（家长可以回看，不需要听语音）
  - 给家长**主动权**——「您方便时回复 1 条语音 / 文字都行」（不强求同步对话）

### 悬浮点 7：开场"抢断式"普适化（来自 case1/2 已接通样本，未验证未接通场景）

**对话模拟里现状**：
- Case A 主流程：「您先别挂电话，我是咱们海豚 AI 学的路老师，李明这边的学习情况是我这边在跟」
- 来自真实 case1/2 复盘——但 **case1/2 是已接通的样本**

**真实数据反例**：
- 4/6 失败 case 卡在"电话未接通"（占线/关机/秒挂）——抢断式开场根本没有触达机会
- case10 接通 12s 后秒挂——**用户没等抢断话术说完就挂了**

**修正方向**：
- 抢断式只适用于"已接通 ≥10s"
- 接通 <10s 的场景需要**「秒说完核心信息」**版抢断：
  - 「**小宇妈妈，海豚 AI 学，孩子学情有问题，加我微信看一眼**」（10 秒说完，3 个关键信息：身份 / 来意 / call to action）
  - 接通即被挂的概率很高，重点是**挂前家长记住了"海豚 AI 学 / 微信加好友"两个关键词**，方便后续加微短信被信任
- 抢断式还需要**根据用户来源分支**（参见悬浮点 8）

### 悬浮点 8：电话钩子 / 加微钩子按 case 设计，但忽略了"用户来源"分流

**对话模拟里现状**：
- Case A 钩子：「少量 APP 行为提醒」
- Case B1 钩子：「9 块体验课开课通知」
- Case B2 钩子：「5 分钟免费 AI 学情诊断」
- Case C 钩子：「升级公告 + 易错点清单」

**真实数据反例**：
- 真实 9 个 case 的渠道远多于这 4 类：`zt-planPage`（直投 9.9 元，case3/9/4 三个成单 case 都是它）/`vipPageConsult`（VIP 页主动咨询，case10）/`qw-sop_0yuan`（私域 SOP，case7）/`app_act-aicall`（AI 外呼弹窗，case8）
- 不同来源的用户**心智完全不同**：
  - `zt-planPage` 用户已经看过 VIP 页+留下姓名手机，他们要的是"**怎么开通**"——case4 加微 2 分钟问"怎么报课"，case9 加微回小名+年级
  - `vipPageConsult` 用户已经主动留咨询——他们要的是"**报价 / 区别**"，不需要"5 分钟诊断"钩子
  - `qw-sop_0yuan` 用户是 0 元钩子领回来的——他们要的是"**领奖品 / 不付费**"

**修正方向**：
- 钩子设计加上**用户来源分支**——
  - 直投/VIP 咨询用户（已看过产品页）→ 钩子是「**给您开通**」（隐含"您已经决定了一半"）
  - 私域 SOP 用户 → 钩子是「**0 元领课程包**」（兑现钩子承诺）
  - 完全冷启动 leads → 才用「**5 分钟诊断**」（这是产品力 demo 钩子，case A/B2 现状的核心场景）
- Case A 加在主文档里要标注它适用的**用户来源边界**（"APP 行为提醒"只适用于自然流量 APP 注册用户，不适用于直投/SOP 用户）

### 悬浮点 9：Case C「断课召回」整体没有真实成单 case 支撑

**对话模拟里现状**：
- Case C 整套话术（"破旧立新"、"承认是销售动作但更基于具体情况"等）设计得最精彩
- 但**没有任何来自真实成单数据的支撑**——case1 是失败 case（断课召回失败）

**真实数据反例**：
- 9 个 case 里没有"断课召回成单"的真实数据
- case1 晨晨的召回测试也失败了

**修正方向**：
- 在主文档里**给 Case C 加显式标注**："**Case C 当前为方案设计稿，缺成单 case 锚定，落地前需要补 3-5 个真实断课召回成单 case 验证**"
- 优先级：Case C 的优先级**降到 P2**——先做 Case A / Case B（有真实 case 支撑），再做 Case C

## 2. 修正后的话术原型（重点摘要）

### 2.1 抢断式开场分级（替代当前 Case A/B 统一抢断式）

| 接通时长 | 接通方式 | 话术原型 |
|---|---|---|
| **接通 < 10s** | 接通即被挂 / 秒挂 | 「**小宇妈妈，海豚 AI 学，孩子学情有问题，加我微信看一眼**」（10 秒说完 3 个关键词：身份/来意/CTA）|
| **接通 10~30s** | 一般在忙 | 抢断式（当前 Case A 模板）|
| **接通 ≥ 30s** | 家长有意愿听 | 抢断式 + 1 句具体钩子（参考 Case A v3） |
| **未接通**（占线/关机/振铃无人接）| — | 立刻发加微短信 + 微信加好友 + **加微通过后主动发起语音通话** |

### 2.2 加微后第一条业务回复的分流模型（替代当前 Case A/B 阶段 ③ 4 轮诊断）

```
家长加微首次业务回复：
├─ 包含「小名+年级+主动追问"怎么学/怎么报课"」
│   → 进入快诊深挖模式：3 轮内拿到「教材 + 成绩 + 错题大类」→ 推体验课
│   → 参考样本：case9
│
├─ 只包含「小名/年级」之一
│   → 进入轻问诊模式：1 轮拿到关键信息 → 推体验课
│   → 不要追问到第 4 轮（case7 教训：追问无效后会被销售放弃）
│
├─ 加微 2 分钟内主动追问「怎么报课/多少钱」
│   → 进入快速报价模式：直接发体验课 + 正价课报价 → 等回复
│   → 参考样本：case4
│
└─ 0 回复
    → 进入延后触达 + 内容种草模式（不假装有家长第 2 轮）
    → 24h 后用「关心型」单条触达：「您方便时跟我说下孩子年级，我看下能不能给您准备体验课」
```

### 2.3 电话失效兜底链路（**新增章节，替代"电话首通必经"假设**）

```
电话第 1 通：未接通（status=占线/关机/振铃无人接）
├─ 30 分钟后跨时段重拨（不同的时间段）
└─ 同时发加微短信 + 主动微信加（不等电话第 2 通）

电话第 2 通：仍未接通
├─ 加微通过后：60 秒内主动发起 1 条微信 VOICE
│   「妈妈您好，我是海豚 AI 学的 XX，电话好像一直没打通，我录段语音您方便时听一下」
├─ 跨日重排（next day 不同时段）

电话第 3 通：仍未接通
├─ 微信触达频次降到每日 1 条
├─ 不再主动拨打
└─ 用户主动回复时立刻进入快诊模式
```

### 2.4 首诊深度修正（**首诊不到知识点层级，到错题大类层级即可**）

错题大类 = 「比多比少 / 倍数 / 分数应用题 / 几何概念 / 计算粗心」

具象知识点诊断（"找谁是 1 份" / "找整体"）**留给体验课第 1 节**，作为体验课的**产品力承诺**——
- **首诊话术**：「**应用题主要分这几类，您还记得孩子主要错哪类吗？体验课的第 1 节，AI 老师会带孩子做几道题，能立刻看出来他真懂还是假懂**」
- 这样既不**冒充全能诊断师**，又给体验课一个**明确的价值锚点**——「体验课会做的事就是首诊做不完的事」

### 2.5 转交话术降权（不承诺差异化，给打断权）

替换当前 Case A/B/C 转交话术的统一原型：

```
[卡片] 转交档案 · 小朋友姓名
- 用户来源：xxx
- 加微聊到的关键点：xxx
- 孩子信息：xxx
- 已购：体验课 · xxx · ¥9

「✅ 已经把咱们今天聊的发给学习管家王老师了，正式上课前一天她会找您。
您要是收到她的消息不想看，回一个『先不聊』就行，她那边会标记，不会再连发。」
```

**比当前版本少的承诺**：
- ❌ "她有专门排课工具，比我更对口"（无证据，且违反 §3 红线 1）
- ❌ "她知道您是怎么过来的、看重什么、最反感什么，不会再用通用话术"（同上，真实助理期就是 SOP 群发）

**比当前版本多的**：
- ✅ "回'先不聊'就行"打断权——这是真实助理期 SOP 群发现象的**用户侧自救渠道**
