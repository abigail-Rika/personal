# AI 析出（0 转体验课）

状态：方案讨论

## 概述

用 AI 销售对当前未被利用的月均 7w+ 端内用户进行触达和转化，引导其购买体验课。这些用户已经装了 APP、有端内行为，但因为 CC 人效有限，78%～88% 从未被捞起过。AI 的边际成本趋近于零，即使转化率低于人工，也是纯增量。本方案目标是验证 AI 销售 0 转体验课链路的可行性，为后续规模化打基础。

---

## 一、背景与机会

### 1.1 问题：端内用户利用率低

直投持续带来大量用户，但绝大部分未被转化利用。

![1.00](https://static.moxtcontent.com/public/resource/ai/gen/8e171d5c-6ff7-449d-87e0-ac563ec6708e.png)

| **用户群** | **12 个月规模** | **12 个月的 leads 析出率** | **月维度未析出（3 月为例）** | **现状** |
| - | - | - | - | - |
| 新客（直投带来） | 40w 活跃 | 22% （标单 leads 6.3w，cc leads（主动+被动捞起）2.5w） | **~4.9w** | 约30% 未被捞起的用户，还会在 7 日内有活跃行为，未被捞起，无任何转化动作 |
| 体验课断课非限购 | 15w 活跃 | 12%（标单 leads 1900，cc leads 1.6w） | **~2.1w（活跃且没有被析出）** | CC 覆盖有限，大量流失 |
| 合计 | / | / | **~7.2w/月** | **当前产出 = 0** |

这 7.2w 用户不是冷流量——他们至少装了 APP、有端内行为，具备基本的品牌认知。其中新客未析出用户约 30% 在 7 日内仍有活跃行为，说明需求窗口尚未关闭。

> **注意：断课非限购的 2.3w/月是活跃用户口径。** 实际符合非限购条件（断课≥210 天）但近期未活跃的用户规模更大。这部分用户虽然没有主动回到 APP，但有手机号，可以通过 AI 电话主动触达。如果纳入，总池子会显著大于 7.2w。本方案先以活跃用户为基数做保守估算，非活跃用户作为后续扩量空间。

### 1.2 为什么现在可以做

**已有验证基础。** lubi（内部 AI 销售框架）已完成 4 期实验，验证了 AI 销售的核心能力：

- **AI 电话外呼**：加微率从 50%（纯短信）提升到 80%→但这是已购体验课用户的口径
- **AI 首诊对话**：能完成结构化学情诊断，家长接受度良好（截图案例：路老师与承治妈妈的首诊对话，家长和孩子均积极参与）
- **AI 催习与反馈**：lubi 案例中，有家长全程不回复但孩子一直跟着学习内容在学，最终主动询问价格
- **转化率**：lubi 第 3 期实验转化率 20%（lubi 是人机协同的数据，我们大盘 14%）

**试错成本极低。** 目标用户当前产出为零，AI 析出捞起的任何转化都是增量。不需要从 CC 池中分流，不影响现有业务。

### 1.3 这部分用户的情况分类

![1.00](https://static.moxtcontent.com/public/resource/ai/gen/0a987946-ea85-4d5c-af12-39665fadaa75.png)

AI 析出可以通过 把直投投放费摊到更多 leads 上 → 单 leads 成本下降 → 直投 ROI 提升 的路径，对直投渠道的 ROI 做改善和优化。

## 二、成本和收益预估

**提前考虑的提问：**

1. **直投扩量节奏：**

   1. 量级变动：预计 6 月底扩到 3k/周（现状是2k 左右/周），约 1.5 倍
   2. 扩量后的 leads 成本：扩量的前提是成本在可接受范围内，视为和现状一致
   3. 基于以上，假设量级变动，用户正常的析出率不变（弹性杠杆不变），​**不影响对 ROI 测算的结论**
2. **Ai 成本是否需要计算：**

   1. 目前外呼话费 0.1元/分钟，号码月租11元/个/月。最终的计费应该是固定的部分（外显号数量 * 11）+外呼费用（外呼总时长 * 0.1），摊到用户身上不超过 1 元/人
   2. 外呼中的 Ai 成本远低于外呼成本，可以忽略不计
   3. Ai 微信运营成本：基于0 转体的模式，Ai 能力比较简单，单用户运营成本预估在 1 元以下，最高不超过 10 元（聊满 20 轮+最好的模型）
   4. 基于以上，按照 10% 的加微→购买率，Ai 运营成本摊到单 leads 上可能会放大 10 倍。需要根据模式来看是否需要考虑金成本

**机制**：AI 销售 0 转体不增加直投投放成本（AI 运营成本视为 0），财务作用是把直投投放费摊到更多 leads 上 → 单 leads 成本下降 → 直投 ROI 提升。

### 2.2 风险敏感性

| **风险点** | **描述** | **量化影响** |
| - | - | - |
| **AI 析出 leads 转化率打折** | 冷用户首次转化率可能低于现有 leads 的 12.52%（参考 §6.5 断课前测：析出率提升 4.7 倍时转化率打 50% 折） | 提升乘数会按折扣同比衰减——若打 7 折，乐观目标的 ROI 提升从 ~32% 降到 ~22%，仍是显著的结构性增量 |
| **AI 偷走自然留存** | AI 提前转化的用户里，部分本来会自然回流并被现有 CC 析出，AI 不完全是纯增量 | 估算损失 ~9%（AI 真实增量 ≈ 91%）。测算第三组已显式把这个代价算进去 |

### 2.3 项目立意与阶段

项目目标不是"把 ROI 打正"（依赖基线波动、不可控），而是兑现一个**结构性 ROI 提升乘数**——保守目标 ~7%，乐观目标 ~32%。这个提升在任何 ROI 基线下都成立，sku 调整、转化率波动、客单价变化都不会让它失效。

| **阶段** | **覆盖范围** | **目标 AI 析出率** | **期望结果（与基线无关）** |
| - | - | - | - |
| **阶段一（冷启动）** | 保守池 5,188（全部未析出 × 30% 留存） | 5%（参考斑马析出率的打折力度） | 周新增 ~260 leads，​**ROI 整体提升 ~7%** |
| **阶段二（扩量）** | 乐观池 17,293（全部未析出活跃用户） | 10%（AI 链路体验优于 CC 召回的兑现） | 周新增 ~1,700 leads，​**ROI 整体提升 ~32%** |

## 三、方案设计

> **结构说明**：3.1 / 3.2 是"输入"——我们能参考的内外部经验；3.3 / 3.4 是"输出"——形式骨架（链路）和内容（钩子）。链路解决"怎么走"，钩子解决"凭什么走得通"。

### 3.1 内部参考：CC AI 外呼前测

> 来源：CC 之前的 AI 外呼析出实验（[企微文档](https://doc.weixin.qq.com/sheet/e3_AUcAUAanAJcCNpD6wm2WtRyakJlNt?scode=AE8Ahge8AAYPu7DCOmAb0AeAYFABY&tab=ucjgiw)）。
>
> **重要前置**：该实验**仅覆盖断课用户**（初中 4-9 年级），对应本方案 §3.4 的 **A-1 子层（断课非限购+行为）**。
>
> - 对 A-1：CC 数据可直接对照、校准假设
> - 对 A-2 / A-3 / B / C：CC 没有验证，**v1 方案在这些层的假设缺乏内部数据支撑**，是更大的风险敞口

> 口径理解（待确认）：
> - **接通召回率** ≈ 有意向 / 接通量；**有效沟通率** ≈ 有效通话 / 接通量
> - "有意向"定义需要对齐：是接通中表达兴趣？还是已转人工/已被打标为意向？
> - 4 个线索范围疑似为**互斥分桶**而非嵌套（574+3153+3321+8489=15537=总计），需进一步确认

#### 3.1.2 关键发现

1. **接通率总体 56%，比 v1 假设的 80% 低近 1/3**——v1 ROI 测算需要根据这个实测值做敏感性回测
2. **线索新旧度对接通率影响巨大**：最新线索（近 5 天）接通率仅 25%，越老反而越高（0-180 天达 71%）
   - 反常识结论：可能是越老的线索经过自然筛选，留下的是"接电话习惯好"的用户；或者最新线索号码错填、警觉性高
3. **"打通"不等于"打动"**：接通后有意向率仅 1.36%-4.97%——AI 能聊起来（有效沟通率 17%-59%），但缺少能促成意向的钩子
4. **越老的线索越冷**：0-180 天接通率最高（71%），但意向率最低（1.77%）——可能是被多次触达后麻木

#### 3.1.3 与 v1 ROI 测算假设的对照

| 参数 | v1 假设 | CC 实测 | 影响 |
| - | - | - | - |
| 接通率 | 80%（设想 1） | 总体 56%，新线索仅 25-37% | 若改用 56%，析出量缩水 30%；新线索池缩水 50%+ |
| AI 析出率（保守） | 5% | 接通后有意向率 1.4%-5%（且"意向 ≠ 购买"） | 实际 5% 可能高估，需要看"有意向→购买"的二级折损 |
| AI 析出率（乐观） | 10% | 实测最高 4.97% | 乐观假设缺乏内部数据支撑 |

> **结论**：CC 实测数据**没有提供钩子优化**就达到上述结果。一种解读是基线已经很弱、钩子优化的天花板有限；另一种解读是"AI 能打通但话术烂"，钩子是真正的瓶颈——本方案押注后者，所以钩子设计是核心。

#### 3.1.5 话术结构分析

##### CC AI 外呼的钩子设计

| 维度 | CC 实测 |
| - | - |
| **目标用户** | 断课用户（初中 4-9 年级） |
| **钩子类型** | **利益型**——限时免费赠送 + 寒假活动包装 |
| **个性化锚点** | "看到孩子经常在海豚 AI 学上学习 / 打开 app 看动画视频课"（端内行为） |

##### 话术亮点

1. **行为锚点用得自然**："看到孩子经常在 app 上学习 / 看动画视频课" 给了一个"我了解你家孩子"的信号
2. **拒绝挽留有 2 层**：利益点①（活动 + 规划）+ 利益点②（兴趣推断 + 多选择）
3. **承诺成本低**："把课程领到手机上看看" 是低门槛动作，不是直接购买
4. **结尾兜底**：拒绝挂机给了一个 APP 路径，留有回流机会

##### 话术问题（推测，与有意向率仅 1.4%-5% 相关）

1. **第一句就推销感强**："活动 / 赠送 / 限时免费" 第一句话堆 3 个促销词，触发家长本能反感
2. **AI 自报家门弱**：开场白没有明确"我是 XX 老师"或"我是海豚 AI 学的班主任"，身份模糊
3. **不让家长说话**：节奏赶——年级 → 学科 → 送课 → 转班主任，全是 AI 推送，缺少倾听
4. **"班主任承接"加了门槛**：用户最终还要再接一个班主任电话，挂断后不一定接得起来
5. **没有可视化兑现物**：所有承诺都靠口头说，没有"加微发资料 / 出报告"这种即时兑现
6. **挽留靠利益不靠服务**：用户对"还多送一套"的抗体已经很厚

#### 3.1.6 与 v1 钩子矩阵的对照

| 维度 | CC 实测 | v1 §3.4 钩子矩阵设计 | 差异点 |
| - | - | - | - |
| **钩子类型** | 利益型（免费送课 + 限时活动） | 服务型为主（学情诊断 / 学习规划） | v1 押注 "诊断/服务" 比 "免费送" 更能打动 |
| **AI 角色** | 轻意向筛选，承接靠人工 | AI 做加微 + 首诊 + 兑现物生成 | v1 让 AI 承担更多，省人工 |
| **承接路径** | 电话 → 班主任电话 | 电话 → 加微 → 微信运营 | v1 把用户拉到微信场景，便于持续运营 |
| **价格点** | 0 元（免费送） | 9 元体验课 | CC 更软；v1 押注"诊断软钩子 + 9 元体验硬转化"双层 |
| **兑现物** | 班主任电话承诺 + 课程入口 | 学情诊断报告 / 学习规划方案（可视化） | v1 强调"看得见的价值" |

**关键判断**：CC 实测有意向率 1.4%-5% 已经是"利益型钩子 + 轻 AI"的天花板信号。v1 押注的"诊断型钩子 + 重 AI"是一个**没被验证的新路径**——这是机会也是风险：

- **机会**：CC 没有跑过"服务型钩子"，天花板未知；学情诊断对家长来说是更软、更教育属性的接触
- **风险**：诊断生成的技术门槛、对话深度的承接、AI 服务感是否真的优于人工——这些都是新问题

#### 3.4.1 为什么钩子是关键

未析出家长 ≠ 现有 leads，差异在于：

- **没建立信任**：还不认识具体老师/班主任，lubi 的"加微率 80%"是已购用户口径，不能直接挪用
- **需求未显化**：家长自己也不一定清楚要解决什么问题
- **怕推销**：教育行业被电话骚扰过度，第一通电话定生死
- **没体验过产品**：对"9 元体验课"这个动作的价值感知是空的——9 元本身是钩子，还是需要更软的前置钩子？

CC AI 外呼前测（§3.1）的数据印证了这点：接通后有意向率仅 1.4%-5%——**AI 能打通，但缺钩子打动**。

###### 6 条钩子设计的硬启示

| # | 启示 | 对钩子设计的含义 |
| - | - | - |
| **1** | **5min 是硬门槛**——成单的 3 个 case 全部跨过 ≥5min 有效首诊接触；失败的 4 个全部没跨过 | 钩子的目标不是"卖课"而是"让用户聊够 5 分钟"——服务型钩子（诊断/规划）天然占优 |
| **2** | **话术不是核心，挖学情的能力是**——失败和成单 case 的开场话术完全一致；差异在销售是否在加微后主动追问拉满信息 | 钩子模板要**内建 N 轮追问 SOP**，强制 AI 在用户给最简回复时继续追问，而不是接受"四年级"这种最简答案就跳到下一步 |
| **3** | **价格切入必死**——召回 79 秒挂的案例已有"领过课程"行为锚点，销售切到价格 3000+（家长预期 1000）立马挂断 | 钩子里**绝对不主动提价格**；9 元放在最后一步，且作为"低门槛体验"而不是"产品定价" |
| **4** | **占线 ≠ 拒绝**——4 个未接通里 3 个是号码占线被错标为拒接 | AI 销售产品红线：**重排时机优于重拨频次**；占线自动延后 + 跨日重排 |
| **5** | **微信语音可作为电话失效的兜底通道**——case4 反例：1 小时微信语音替代失败的电话首通，照样成单 | 钩子要准备**双形式**：电话钩子 + 加微即语音钩子（这是 §3.3 设想 1 之外的新变体） |
| **6** | **"专属规划师"承诺降级会反噬**——失败 case 中销售从"1V1 规划"承诺降级为 SOP 群发，加重失望 | AI 销售红线：**绝不主动承诺"1V1 专属规划"**，避免后期落差 |

###### 钩子矩阵的修正方向

基于以上启示，§3.4.3 钩子矩阵需要补强（v1 修订点，下版迭代）：

1. **每个钩子都要标注"5 分钟话术结构"**——钩子不只是第一句话，要能撑过 5 分钟有效对话
2. **追问 SOP 是钩子的标配**，不是可选项——参考 case9 的"年级 → 学校 → 成绩 → 教材 → 下滑年级"5 轮追问模板
3. **A 组钩子要做电话+微信语音的双兜底**——A 组用户有手机号也有微信，电话失败立刻切微信语音
4. **CC 基线话术作为对照组的同时，要警惕话术天花板假设**——前测意向率 5% 可能本就是话术天花板（开场即促销词、不挖学情、SOP 群发），服务型钩子的预期可以适度上调

###### 端内点位 × 钩子 × 漏斗矩阵

| 页面 | 位置 | 钩子内容 | 广告位点击率 | 落地页转化率 | 析出率 | 承接形式 |
| - | - | - | - | - | - | - |
| **前测** | / | 简单信息收集 → "学习计划"付费解锁 | / | 15.1% | **15.1%** | AI 学习计划落地页（共用） |

>

>
> **注 3**：计划页点击后是内嵌付费浮层（不跳出 APP），浮层叙事 = 9 元试用会员权益 + 7000+ 资料库畅学 + 1 对 1 诊断规划服务——这套钩子内容和 v1 软钩子方案高度重合，是天然的端内对照。

###### 关键洞察

1. **「解锁内容」是端内最强钩子**——资料库 6.4% 析出（端内最高）
   - 点击率 87.4% 意味着用户**面对具体内容时点击意愿极强**
   - 钩子核心：用户已有非常明确的"我现在想要这个视频"诉求，9 元是直接"解锁条件"，钩子叙事极其紧凑
   - 对 AI 销售的启示：当用户已有具体行为/需求时，"具体内容+解锁"叙事 > "权益+优惠"叙事，对应 §3.4.3 A 组（已有认知）逻辑

2. **「会员权益」类钩子析出率普遍偏低**——首页 banner 0.7% / 会员页 1.2%
   - 钩子定位模糊：用户不知道"会员"具体能解决什么问题
   - 共用落地页跳转后转化率差异巨大（首页 banner 25.3% > 会员页 18.4% > 前测 15.1%），说明**入口意图浓度决定落地页转化天花板**
   - 对 AI 销售的启示：不要在 AI 销售里用"会员权益"作为钩子主语，要换成"具体能解决什么问题"

3. **「试用会员 + 付费浮层」点击率最高、但落地页转化偏低**——计划页 28.6% 点击 / 7.3% 落地页
   - 按钮文案"试用会员"在计划学习场景下吸引力强；付费浮层叙事（试用 + 资料 + 诊断规划）没让用户立即买单
   - 对 AI 销售的启示：这套浮层钩子叙事和我们要给 AI 销售设计的软钩子高度重叠，**已经在端内被打磨过，可直接复用**到 AI 销售话术中

4. **「前测信息收集 → 学习计划付费」端到端最干净**——15.1% 析出
   - 前测把用户拉进"答题/信息收集"动作，意图浓度被前置抬升
   - 对应 §6.5 海豚断课前测（析出率 4.7 倍）的结论，**端内、断课两个独立场景同时验证：轻量前测 → 个性化付费方案的承接是高效路径**
   - 对 AI 销售的启示：§3.4.4 软钩子里的"学情测评 / 前测"在端内有直接对照数据，可作为 B / C 组主推钩子的信心来源

##### 3.4.2.6 核心假设（v0）

基于以上数据 + CC 真实 case 洞察，本方案押注 6 个核心假设：

1. **利益型钩子（CC 已测）的天花板约 5%**——除非话术大幅优化，否则纯利益型很难突破
2. **服务型钩子（学情诊断/规划）有突破空间**——lubi 已购场景验证有效，未购场景待验证；CC 真实 case 进一步支持"挖学情 > 推产品"
3. **"测评 + 诊断"是 B/C 组的关键路径**——对没有历史数据的用户，先用轻量测评创造数据，再做诊断（参考断课前测的 4.7 倍杠杆）
4. **AI 主导的服务型钩子比 CC 模式更可持续**——把用户拉到微信场景，便于后续运营
5. **钩子的核心目标是"5 分钟有效对话"而不是"成交"**——CC case 验证 5min 是成单硬门槛；钩子设计的所有动作都应服务于这个中间目标
6. **【新】用户质量 ≠ 析出量**——斑马硬转模式接通→购买 5%（好）但**正价转化比大盘低 1-2pp**（差）。硬转拉来的用户被"提前成交"但需求/动机没养起来，后续承接不住。我们要追求的是 **析出量 × 用户质量**——这意味着除了 9 元硬转，还需要前置的**软钩子**（学情诊断/规划/资料/微课等）来养意愿，把未析出用户拉到接近自然 9 元用户的质量水平（详见 §3.4.4 钩子的两层结构）

| **第一句话术** | "看到孩子常在 app 看动画视频课，这周做寒假回馈活动，给孩子赠送了几节预习课程" | "看到您之前学过 XX，免费帮您做一次学情复盘，看看孩子现在水平" | "给您留了一个 9 元体验课名额，今天给您安排一节，上完老师反馈" |
| **兑现物** | 课程入口 + 班主任电话承接 | 学情诊断报告（结构化卡片） | 体验课 + 课后反馈 |
| **预期假设** | 实测：接通→意向 1.4-5% | 接通率 50% / 加微率 50% / 加微→购买 12%（待校准） | 接通率 50% / 接通→购买 6%（参考斑马）（待校准） |
| **主要风险** | 已知天花板低、推销感强 | 诊断报告生成质量 / "销售伤过我"反感 | 无钩子缓冲，硬转易被拒 |

**A 组子层差异化锚点**：

- **A-1 断课+行为**：钩 1 锚点用历史学习记录（"您之前学到 XX 章"）
- **A-2 VIP 咨询**：钩 1 升级为"方案对比 + 学习规划"，话术为"老师帮您把不同方案对比清楚"
- **A-3 资料库用户**：钩 1 锚点用"诊断盲区"（"看看免费资料覆盖不到的部分"）

###### B 少量行为组 → 主题："帮你想清楚"

|  | **钩 1（主推）：测评 + 学习规划** | **钩 2（辅助）：兴趣确认 + 资料引流** |
| - | - | - |
| **第一句话术** | "看到您在看我们的学习计划，免费帮您出一份学情测评和学习规划，您基于这个再决定要不要试" | "您是 X 年级家长，刚整理了一份 XX 学科资料合集，加微信发您，顺便聊下孩子情况" |
| **兑现物** | 测评结果 + 规划方案 | 资料包 + 后续跟进 |
| **预期假设** | 接通率 40% / 加微率 50% / 加微→购买 8%（待校准） | 接通率 40% / 加微率 60% / 加微→购买 5%（待校准） |
| **主要风险** | 测评需孩子参与，配合意愿不确定 | 弱钩子，"吃完就走"概率高 |

###### C 无行为组 → 主题："给你一个开始的理由"

|  | **钩 1（v1 原有）：老师分班 + 9 元体验** | **钩 2（主推）：新客福利 + 学情测评** |
| - | - | - |
| **第一句话术** | "您是 X 月下载的新客，老师给您分到我的班，9 元体验课帮孩子做学习诊断" | "您是本周新客，公司福利：免费学情测评 + 9 元体验课，今天给您安排" |
| **兑现物** | 体验课 + 课后诊断 | 测评结果 + 体验课 |
| **预期假设** | 接通率 40% / 加微率 25% / 加微→购买 6%（待校准） | 接通率 40% / 加微率 35% / 加微→购买 8%（待校准） |
| **主要风险** | 无信任基础，老师身份感知薄 | 测评需孩子配合，依赖家长协作 |

#### 3.4.4 钩子的两层结构：软硬组合

> **本节定位**：v1 方案的重要范式转变。
>
> 斑马 0 转体的硬转模式数据有两面：
>
> - ✅ 接通→购买 5%（量好）
> - ❌ **正价转化比大盘低 1-2pp**（质差）
>
> 后者说明：硬转拉来的用户被"提前成交"但需求/动机没养起来，9 元课完不成 → 走不到正价。要把未析出用户拉到"接近自然 9 元用户"的质量水平，**单层硬钩子不够，需要前置软钩子养意愿**。
>
> 这个判断也契合 §3.4.2.4 CC 真实 case 的"5min 硬门槛"洞察——软钩子天然就能撑过 5 分钟、自带追问场景。

##### 3.4.4.1 软硬钩子定义

| 钩子层 | 目标 | 关键动作 | 典型时长 | 衡量指标 |
| - | - | - | - | - |
| **软钩子（前置）** | 养意愿、显化需求、建立信任 | 学情诊断 / 规划 / 资料 / 微课 / 测评 | 当下 5-30 min ~ 跨数天 | 兑现物交付率、用户互动深度、对话轮次 |
| **硬钩子（转化）** | 引导购买 9 元体验课 | 推荐试听 / 兑现物里嵌购买入口 | 1-5 min | 接通→购买转化率 |

##### 3.4.4.2 软钩子候选清单

| 软钩子 | 兑现物 | 需用户付出 | 引出 9 元的方式 | 用户层适配 |
| - | - | - | - | - |
| **学情诊断**（基于历史数据） | 个性化诊断报告 | 15-30 min 对话 + 信息回答 | 报告末尾推荐试听课 | A 主推 |
| **学情测评/前测** | 测评结果 + 解读 | 5-10 min 答题（孩子参与） | 暴露薄弱点 → 9 元对应课 | B / C 主推 |
| **学习规划** | 规划方案文档 | 20-40 min 1v1 沟通 | 规划里"现阶段先体验 XX" | B 主推 |
| **资料合集** | PDF / 链接 | 加微信 | 资料里嵌购买入口 | C 辅助 |
| **免费微课 / 直播** | 课程视频 | 听课 30-60 min | 课程结尾推 9 元体系课 | C 辅助 |
| **试听小课** | 完整一节体验 | 听课 10-20 min | 听完推完整课 | A/B/C 通用 |

##### 3.4.4.3 各用户层的软硬组合（v0 推荐）

| 用户层 | 软钩子（前置养意愿） | 硬钩子（9 元转化） | 链路特征 | 链路时长 |
| - | - | - | - | - |
| **A 已有认知** | 学情诊断（30 min 1v1，基于历史数据） | 9 元体验课 + 课后反馈 | 重诊断、紧转化 | 当天或次日 |
| **B 少量行为** | 学情测评（创造数据）→ 学习规划 | 9 元体验课 | 创造数据 + 规划承接 | 2-3 天 |
| **C 无行为** | 简单测评 + 资料/微课 | 9 元体验课 | 低门槛建立感知 | 3-7 天 |

##### 3.4.4.4 软钩子对链路形式的影响

软硬两层钩子结构会**重塑 §3.3 链路形式的优先级**：

| 链路设想 | 对软硬组合的适配 | 原因 |
| - | - | - |
| **设想 1：加微 + AI 首诊** | ★★★ **最优** | 加微后可以承接长对话/跨天对话的软钩子；兑现物可以可视化交付（诊断报告、规划方案） |
| **设想 2：不加微 + AI 首诊** | ★ 不适合 | 电话内做完软钩子（诊断/规划）后没有持续承接场景；兑现物只能口头/短信 |
| **设想 3：不加微 + 人工服务** | ✗ 跳过软钩子 | 等同斑马硬转模式，正好是我们要超越的对照 |

→ **强化了"设想 1"的优先级**。在 §3.4.5 钩子×形式适配里会进一步明确。

##### 3.4.4.5 软硬组合的关键风险

| 风险 | 描述 | 缓解方向 |
| - | - | - |
| **链路拉长** | 软钩子→硬钩子可能跨数天，不是当下成交，整体析出周期变长 | 需要 ROI 测算时把"周维度析出"放宽到"30 天窗口析出" |
| **AI 能力门槛上升** | 软钩子（特别是诊断/规划）对 AI 对话质量和兑现物生成要求高 | 阶段 1 用 A 组（数据最全）验证可行性，再扩展到 B/C |
| **兑现物质量决定衔接** | 诊断报告/规划方案如果质量差，9 元转化反而下降 | 兑现物模板化 + 人工抽检 + 灰度迭代 |
| **"做完不买"沉没成本** | 软钩子做完用户不买 9 元，是否还能长期跟进？ | 跟进策略和 lubi 已购催习对齐；长期看待 LTV |
| **运营成本** | 软钩子需要更长 AI 对话 + 更多模型调用 | 见 §2 ROI 测算 "AI 运营成本 < 1 元/人" 红线 |

##### 3.4.4.6 软硬组合 vs 斑马硬转 vs CC 利益型 三组对照

| 模式 | 钩子结构 | 用户质量假设 | 析出周期 | 适合放在阶段 1 哪个组 |
| - | - | - | - | - |
| **斑马硬转**（外部参考） | 单层硬钩子（9 元） | 偏低（正价转化 -1~2pp） | 当天 | A 组对照臂之一 |
| **CC 利益型**（内部参考） | 单层钩子（免费送课） | 未知，意向率 1.4-5% | 当天 | A 组对照臂之一 |
| **v1 软硬组合**（本方案押注） | 软钩子 + 硬钩子 | 押注接近自然 9 元用户 | 1-7 天 | A/B/C 主推臂 |

> 阶段 1 实验设计将这三组都放进 A 组做对照（详见 §3.4.5 钩子×形式 → §3.4.5.2 阶段 1 推荐组合）。

| 钩子 | 最适合的形式 | 原因 |
| - | - | - |

| 学情测评 / 前测 | **设想 1**（深测评）或 **设想 2**（轻测评，电话内简单做） | 测评深度决定形式 |

| 用户层 | 主推：v1 软硬组合 | 对照 1：斑马硬转 | 对照 2：CC 利益型 |
| - | - | - | - |
| **A 已有认知** | 学情诊断（软）+ 9 元体验（硬） + **设想 1** | 直接 9 元硬转 + **设想 2 / 3** | CC 免费送课话术 + **设想 3** |
| **B 少量行为** | 测评+规划（软）+ 9 元（硬） + **设想 1** | 直接 9 元硬转 + **设想 2 / 3** | 不触达对照组 |
| **C 无行为** | 资料/微课+测评（软）+ 9 元（硬） + **设想 1** | 直接 9 元硬转 + **设想 2 / 3** | 不触达对照组 |

> - 主推臂验证：软硬组合能否打出 **更高析出量 + 更高用户质量**（9 元完课率 / 正价转化）
> - 对照 1 验证：斑马硬转模式在海豚环境下能复现 5% 接通→购买吗？正价转化是否同样 -1~2pp？
> - 对照 2 验证：CC 实测的 1.4-5% 是否就是利益型钩子天花板？
> 
> 三臂对照的关键产出：在阶段 1 数据下，能否得出"软硬组合的析出 × 质量 > 单层硬转"的结论。
>
> 最终每层跑几个钩子组合，取决于样本量是否够分（详见 §3.4.6 待讨论问题 9）。

#### 3.4.6 待讨论的钩子设计问题

1. **服务型钩子（学情诊断）vs 利益型钩子（免费送课）**：CC 实测利益型在断课用户上意向率 1.4-5%——这是天花板还是话术问题？阶段 1 是否直接在 A 组做对照（钩 0 vs 钩 1）？如果服务型打不过利益型，整个 v1 方向需要重估
2. **学情诊断的技术可行性**：能不能基于端内行为生成有质量的诊断？数据来源选哪种——①纯端内行为 ②家长问卷 ③孩子做几道题前测？报告形态选哪种——文字 / 结构化卡片 / 视频？
3. **学情测评作为创造数据的方式**：参考 §6.5 断课前测的 4.7 倍杠杆——对没有历史数据的 B/C 组，"测评+诊断"是不是最优组合？
4. **9 元课的角色**：是钩子本身，还是诊断完之后的承接动作？斑马有人工兜底，AI 主导下要不要先有诊断软钩子缓冲再到 9 元硬转？
5. **A 组"销售伤过我"风险**：A-1 断课用户相当比例已被 CC 销售跟进过。AI 是更糟（"AI 又来骚扰"）还是更好（不带攻击性）？
6. **不加微链路下的兑现物载体**：设想 2/3 不加微，诊断报告用什么承载——短信链接 / 小程序 / 跳回 APP？
7. **AI 角色重 vs 轻**：CC 是"轻 AI + 重人工"，v1 设想 1 是"重 AI + 轻人工"。能力门槛和成本同步上升——这种押注值不值？
8. **承接路径电话 vs 微信**：用户对"再接班主任电话"和"加微信"哪个抵触更低？
9. **阶段 1 样本量**：200-300 人/组够不够再分 2-3 个钩子做 A/B test？还是先验证主推钩子？
10. **斑马调研回填**：等 §3.2.2 的 4 个维度（用户分层 / 钩子话术 / 成本结构 / 购后承接）补齐后，本节需要再迭代一版

**【新增】基于 CC 真实 case 提炼的钩子操作红线（§3.4.2.4 引出）：**

11. **AI 追问 SOP 设计**：参考 case9 的"年级 → 学校 → 成绩 → 教材 → 下滑年级" 5 轮追问模板，AI 是否在所有钩子下都强制走完？还是按用户回复丰富度动态决定？追问失败的兜底是什么？
12. **占线重排机制**：AI 是否需要内建"占线自动延后 + 跨日重排"的硬规则？（CC 案例显示 5 通密集占线被算成"用户拒绝"）
13. **电话失败的微信语音兜底**：要不要把 case4 的"加微后用语音电话替代失败电话首通"设计成 §3.3 设想 1 的标配兜底？
14. **"专属规划师"承诺如何避免**：AI 销售如何在不承诺"1V1 专属规划"的前提下，又保持服务感？是用"班主任"等更低调的人设，还是用"AI 学习助手"明牌？
15. **5 分钟有效对话目标如何衡量**：用什么指标判断 AI 是否完成了"撑过 5 分钟"——是单纯通话时长，还是包含轮次/信息完整度？

**【新增】基于软硬钩子组合（§3.4.4 引出）：**

16. **软钩子→硬钩子的衔接转化率假设**：软钩子（诊断/规划/资料）做完后，到 9 元购买的转化率假设是多少？需要：
    - 内部参考：lubi 首诊→后续动作的转化数据
    - 行业对照：诊断报告类钩子后的转化率
    - 实验验证：阶段 1 直接测出来
17. **"用户质量"如何度量**：除了 9 元购买率，还应该看什么？9 元完课率、体验课后诊断完成率、正价转化率、LTV——哪些指标加进 §4.4 观测指标？
18. **软钩子的链路时长上限**：软硬组合可能让析出周期从"当天"变成"3-7 天"，§2 ROI 测算用的是周维度——是否需要把口径放宽到"30 天窗口析出"？
19. **"做完不买"的长期跟进**：软钩子做完用户不立即购买，AI 销售如何持续跟进？参考 lubi 已购催习机制？还是建立专门的"已诊断未购买"用户池？
20. **软钩子的成本控制**：诊断/规划这类软钩子单用户对话深度高、模型调用多，AI 运营成本可能突破 1 元/人红线（§2 假设）——如何在能力质量和成本之间取舍？



## 四、实验设计

### 4.1 阶段性目标

阶段目标先验证链路，再验证分层，最后验证 ROI。

| **阶段** | **用户范围（小范围→保守池→激进池）** | **目标** |
| - | - | - |
| **阶段 1：小流量验证** | 先用保守用户池小范围验证（200～300 人/组） | 跑通AI 析出的流程；验证这种模式是否能成交，以及后续转化情况 |
| **阶段 2：分层扩量** | 阶段 1 跑通后，加入完全冷启动组 | 找到 1-2 个可放量用户层，明确不同人群适合什么钩子 |
| **阶段 3：ROI 验证** | 扩到周维度可触达池 | 验证 AI 新增 leads 对 ROI 的结构性提升，并观察体验课后诊断对正价课承接的影响 |

### 4.2 阶段 1 详细范围（最先做什么）

阶段 1 是 MVP，只做三类人群验证效果（按照用户行为深度）：

- **已有产品认知组（有一定行为深度）**：断课限购有 app 活动行为的用户，新客 VIP 咨询、会员页浏览、有资料库学习数据的用户
- **少量 APP 行为组**：新客没有学习数据但是有计划页点击行为的用户
- 完全没有行为（仅下载的新客）

阶段 1 交付物只保留 4 个：

1. 用户圈选规则
2. AI 触达 + 轻沟通脚本
3. 体验课转交模板
4. 数据看板口径

阶段 1 过关标准：

- 链路能跑通
- 没有明显副作用：投诉/拉黑/误触达/过度承诺可控。
- 有最低转化信号：接通率、析出率是否符合认知

### 4.3 分组设计

分组重点是验证不同用户层的钩子

| **组别** | **用户范围** | **核心钩子** | **验证目标** |
| - | - | - | - |
| **实验组 A：已有认知组** | 断课非限购有 app 活动行为的用户，新客 VIP 咨询、会员页浏览、有资料库学习数据的用户 | - 有明确学习行为数据的用户：「看到您有学习行为，帮您开通/安排 9 元体验课，上完给学习诊断和建议」  - 其他用户：「帮您开通/安排 9 元体验课，上完给学习诊断和建议」 | 验证已有认知用户能否被再次的临门一脚打动 |
| **实验组 B：少量行为组** | 新客没有学习数据但是有计划页点击行为的用户 | 「看到少量行为痕迹，想跟您确认是否和平时情况对得上，我们可以 9 元体验课程，上完给诊断」 | 验证轻沟通能否建立相关性，并转化为 9 元体验课 |
| **实验组 C：基本没有行为组** | 仅下载的新客 | 「分到我的班上了， 9 元购买体验课帮孩子做一个全面的学习诊断」 | 给仅下载的用户一些服务，是否能够唤起用户的体验兴趣 |
| **对照组** | 同类用户不触达或维持现有触达 | — | 观察自然购买/现有链路转化基线 |

### 4.4 观测指标（根据模式调整）

| **层级** | **指标** | **说明** |
| - | - | - |
| **核心** | 端到端转化率（用户池→购买） | 各组整体效率对比 |
| **漏斗** | 触达率、加微率、轻沟通完成率、购买转化率 | 定位各环节差异 |
| **质量** | 有效沟通轮次、用户反感/拉黑/投诉 | 判断方案是否有副作用 |
| **承接** | 体验课出勤、体验课后诊断完成率、下游承接质量 | 判断 9 元学习采样是否能为后续转化蓄水 |
| **分层** | 按用户来源 + 行为特征的分环节转化率 | 识别高 ROI 用户群，沉淀分层规则 |

### 4.5 实验节奏

| **阶段** | **规模** | **目标** |
| - | - | - |
| 阶段 1：小流量真实验证 | 每组 200-500 用户 | 验证 MVP 链路可跑通、无明显副作用 |
| 阶段 2：分层扩量验证 | 每组 1,000-2,000 用户 | 找到可放量用户层，读出分层漏斗 |
| 阶段 3：放量与 ROI 验证 | 按周维度可触达池逐步放量 | 验证 AI 新增 leads 对 ROI 的结构性提升 |

置信量参考：若预期端到端转化率 diff 为 1pp，每组需约 3,000-5,000 用户曝光。阶段 1 不追求统计显著，重点看链路可用性、用户副作用和最低转化信号；阶段 2 开始追求可比较的分层读数。

## （参考）AI 运营能力盘点

按「触达→加微→首诊→引导购买→转交」拆解每个环节需要的能力、lubi 验证情况、就绪度。

### 6.1 触达与加微环节

| **能力** | **lubi 验证情况** | **就绪度** |
| - | - | - |
| AI 电话外呼 | 已跑通，加微率从 50% 提升到 80%（针对已购体验课用户） | ✅ 可复用，话术需重做（0 转体钩子和 lubi 不同） |
| 多渠道触达编排（电话 + Push + 短信） | lubi 没做过，各渠道独立 | ⚠️ 需建设 |

| 用户圈选与个性化数据获取 | lubi 用户是已有 leads，圈选逻辑不同 | ⚠️ 需适配（新客未析出 + 断课非限购的圈选规则） |
| 个性化钩子映射话术表 | lubi 有 SOP-1 三场景差异化经验 | ⚠️ 参考 lubi 模式，0 转体需重新设计映射表 |

### 6.5 断课前测实验数据参考

2026 年 3 月上线的断课用户前测实验（实验 3726），验证了「以量换质」策略的可行性：

| **指标** | **对照组（线上原有）** | **最优实验组（三题前测）** | **变化** |
| - | - | - | - |
| 析出率 | 9.73% | 45.54% | **↑ 4.7 倍** |
| 转化率 | 6.55% | 3.19% | ↓ 预期内 |
| **端到端** | **0.64%** | **1.45%** | **↑ 2.3 倍** |

**关键结论**：降低门槛后虽然单用户质量下降，但总量提升带来的端到端效率更高。AI 销售 0 转体的逻辑与此一致——用 AI 的低成本广覆盖，换取总量增长。
