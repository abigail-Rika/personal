      → 不过度投入，先轻量触达
    </td>
    <!-- ② -->
    <td style="background: #fffcf5;">
      <strong>"为什么要加你微信"</strong><br>
      <span class="risk-tag">信任为零</span><br>
      1. 背景顾虑：展示背书和师资背景<br>
      2. 无需求感：钩子要给价值（诊断+结果）而非推课<br>
      3. L1 加微率天然低——<strong>接受</strong>，不强推
    </td>
    <!-- ③ ★新增★ -->
    <td style="background: #fffcf5;">
      <strong>"你们怎么知道我家孩子有问题"</strong><br>
      <span class="warn-tag">家长不认可诊断结果</span><br>
      1. 数据不直观 → 用具体案例+可视化图表让家长"看懂"<br>
      2. 家长觉得孩子没问题 → 不强推，留下数据留待下次触发<br>
      3. 问题太抽象/太大 → 拆解成具体知识点级别的小问题
    </td>
    <!-- ④ ★新增★ -->
    <td style="background: #fffcf5;">
      <strong>"知道有问题，但不想现在处理"</strong><br>
      <span class="warn-tag">缺乏紧迫感</span><br>
      1. 想等期末/假期再说 → 强调"早发现早干预，效果差别很大"<br>
      2. 孩子时间不够 → "每天只要25分钟，不占课外时间"<br>
      3. 还在犹豫要不要投入精力 → "先试一节看看孩子反应，不合适随时停"
    </td>
    <!-- ⑤ -->
    <td style="background: #fffcf5;">
      <strong>"我还不了解这个课"</strong><br>
      <span class="warn-tag">产品认知为零</span><br>
      1. 过早推购买 → 用户流失。<strong>先诊断，后推课</strong><br>
      2. "9元也是钱" → 诊断结果本身要让家长觉得"值得花时间"<br>
      3. 竞品对比 → 不贬低竞品，用AI 1v1互动的独特性说话<br>
      4. <span class="risk-tag">L1最大漏斗</span> 转化率天然低，需要有耐心
    </td>
    <!-- ⑥ -->
    <td style="background: #fffcf5;">
      <strong>到课 / 完课风险</strong><br>
      1. <strong>忘了上课</strong>：多渠道多时间点提醒<br>
      2. <strong>技术问题</strong>：快速响应通道<br>
      3. <strong>孩子中途退出</strong>：即时关怀<br>
      4. <strong>体验不达预期</strong>：补救方案（重新安排）
    </td>
    <!-- ⑦ -->
    <td style="background: #fffcf5;">
      <strong>信任断裂</strong><br>
      AI→人工切换时用户可能不适应<br>
      → 人工首次沟通延续AI的服务调性<br>
      → 引用AI阶段的对话内容，不让用户觉得"又从头来"
    </td>
  </tr>
