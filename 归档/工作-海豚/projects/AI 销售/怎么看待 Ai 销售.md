**基于什么样的背景，去推这个事情：**

1. 春季课表现出了显著的转化优势，Q2优先解决产能，那Q3就到了扩量期
2. 以买量为主的获客方式，投放扩量是很快的，最大的卡点在承接上，招人的速度、人员的素质，以及高人效要求，AI销售的介入变成了杠杆最大的解决方案。
3. 过往在转化流失分析中，发现了很多用户需求因人力限制而无法被充分满足，AI的个性化产品力，是个终极方案。

<br />

**我们怎么去看和思考这件事：**

1. 以AI完全替代销售的最终目标去做全体系的AI服务，而不是做些工具给销售用来做工作提效，这两个目标带来的结果完全不同。
2. 基于1.的目标，我们在思考AI销售要做什么以及怎么做的时候，\*\*首先要突破传统模式，重新回到用户视角，\*\*包括不限于用户旅程设计，销售的sop流程等。

* 这个的原因很简单，过往的承接模式包含了两种逻辑，**用户体验逻辑、销售组织逻辑**，站在强大的AI能力上，那我们可以更纯粹的站在用户视角去思考和设计，探索最适合用户的体验-买课旅程是什么，以及用户与业务的关系如何建立。

\
**回到唯一的底层逻辑-用户体验逻辑，从两个维度去观察**

1. `用户信任成长链`：回答“这个用户对这套产品+服务，信到什么程度了”，指导推进方法
2. `用户生命周期`：回答“这个用户和业务的关系走到哪一段了”，指导业务推进

<br />

**用户信任成长链**-服务只有一个底层逻辑，就是建立用户信任

1. `唤起` 让用户意识到“这和我有关”
2. `理解` 让用户感到“你真的懂我的具体问题”
3. `指导` 让用户看到“下一步该怎么做”
4. `陪跑` 让用户在执行中不断被接住
5. `证成` 让用户看到“这套服务+课程确实对我有效”

<br />

**用户生命周期**-每个生命周期阶段里的用户特征

1. 激活：还只是潜在线索，没形成明确兴趣，从“无感”变成“愿意进入下一步”
2. 体验前：从明确兴趣，落实为学习计划的推动力，从“愿意看看”变成“愿意认真开始”
3. 在学：被陪住+被证明，
4. 正价课转化：被证明

<br />

**在不同用户生命周期，面向不同的用户特征，要建立什么信任，AI能做什么**

| **生命周期** |  **信任成长** | **AI能力能做什么**                                                                                                       |
| :------: | :-------: | :----------------------------------------------------------------------------------------------------------------- |
|   潜在用户   |   唤起并共鸣   | 【学情问题挖掘】基于需求、年级、教材版本、学习信息，挖掘用户的学习问题                                                                                |
|    体验前   |   指导+陪学   | 【个性化方针】快速把家长场景问题转成一份“你家当前学习问题解释”，告诉家长“为什么要先做这个动作、做完会得到什么”，把固定的流程节点变成有解释力的服务节点                                      |
|    在学    |  陪学+价值动作  | 【个性化学习节奏】根据孩子的实时表现即时调整讲解、节奏、反馈；根据过程信号给家长同步“现在发生了什么”；当孩子掉线、分心、卡住时，立刻变成服务动作，而不是事后补救；家长看到的不是一句“孩子学得不错”，而是持续更新的个性化进展解释 |
|   正价课转化  |   长期价值证明  | 【结业诊断+长期规划】自动生成这次体验对用户意味着什么，而不是只给标准报告；把“发生了什么”翻译成“为什么值得继续”；不只是说孩子表现好不好，而是说“如果继续学，路径应该怎么走”；给出下一阶段专属学习方案，而不是统一转化话术   |
|    购课后   | 持续陪住+持续证明 | 【把周的服务变成长期服务】把陪学变成持续存在，而不是等老师有空；每次学习后都形成个性化反馈、提醒、纠偏建议；不只是报结果，而是不断让家长知道“现在学到了哪、下一步怎么学”；对长期风险提前识别，而不是流失后才回捞          |
