# Lubi 现状梳理

## 线索全流程

一条线索从进入到最终成单/流失，完整经历以下阶段：

```
线索进入 → 触达(电话/短信) → 加微信 → 破冰(SOP-1) → 家长会(SOP-3.1/3.2)
→ 发学习计划(SOP-4) → 首日催习(SOP-5) → 日常催习(SOP-6)
→ 反馈沟通(SOP-8) → 转化关单(SOP-9) → 长期陪伴(SOP-100)
```

### 各阶段说明

| 阶段   | SOP     | 做什么                                | 渠道    | 执行方                             | 耗时       |
| :--- | :------ | :--------------------------------- | :---- | :------------------------------ | :------- |
| 触达   | —       | 电话外呼或短信引导加微                        | 电话/短信 | AI（电话教务老师Agent + 背景决策Agent判断时机） | 单次       |
| 加微信  | —       | 用户扫码添加微信                           | 小程序扫码 | 用户操作                            | 单次       |
| 破冰   | SOP-1   | 建立关系、收集基本信息（年级/科目/时间）、推动家长会        | 微信文字  | **AI**（按三场景差异化：电话加微/短信加微/App直投） | 1天内      |
| 家长会  | SOP-3.1 | 逐科学情诊断 + 信息探索 + 定制学习计划。当前信息密度最高的窗口 | 语音小程序 | **AI**（家长会Agent独立运行）            | 20-40min |
| 标准模式 | SOP-3.2 | 不参加家长会的用户走此路径，约学习版本和时间             | 微信文字  | **AI**                          | —        |
| 发计划  | SOP-4   | 发送定制学习计划 + 提醒                      | 微信文字  | **AI**                          | 单次       |

| 反馈沟通 | SOP-8   | PPT驱动学习反馈、学习报告解读                   | 语音小程序 | **AI**（反馈规划Agent）               | 15-30min |
| 转化关单 | SOP-9   | 异议处理、促成购买                          | 微信文字  | **人工**（以AI身份）                   | 持续数天     |
| 长期陪伴 | SOP-100 | 已购课用户的日常服务                         | 微信文字  | **AI**                          | 持续       |

## AI 自动化部分的产品演化

### 阶段一：2025年底 —— 双角色架构定型

王老师拆分为**小海**（微信端，客服风格）+ **路老师**（语音端，教研专家）。线性 SOP 流水线 10 个阶段，AI 自动覆盖 8 个（SOP-6/9 除外）。

### 阶段二：2026年3月 —— 电话外呼上线

电话教务老师 Agent 上线。加微率从 50%（纯短信）跳到 **80%**。

### 阶段三：2026年4月10日 —— v0，结构性重组

5 项改动一次落地：

* **角色合并**：小海→路老师，全流程统一角色，话术去卖萌/去饥饿营销

* **SOP 精简**：废弃 SOP-2、SOP-7（实际上 2 月份就没用了，人工处理时手动跳过的）

* **SOP-1 场景化**：按电话加微/短信加微/App直投三场景差异化

* **加微改扫码**：口播企微号→小程序扫码

* **家长会+孩子互动**：首次让孩子进入 AI 服务环节

## SOP-6 和 SOP-9 的人工演化

这两个阶段是体验周中持续时间最长、人工做工最重的环节。执行方式经历了三个阶段：

### 阶段一：2026年1月 —— 纯人工

第1、2期实验（各10条线索）。微信端AI角色是"小海老师"，后台没有任何AI辅助工具。

* SOP-6（日常催习）：**完全由人工在企微托管平台上操作**，以小海身份发消息，人工自己判断催习时机、话术和策略

* SOP-9（转化关单）：**完全由人工操作**，以小海身份谈单，人工自己判断策略、时机和话术

* 转人工机制：**直接转**——AI搞不定就把对话交给人工，人工接管

### 阶段二：2026年2-3月 —— 策略助手上线，辅助人工

第3、4期实验（各20条线索）。后台新增"策略助手"和"督学话术Agent"，但都是**人工咨询工具**，不是自主Agent。

* SOP-6：人工仍然亲自操作，但可以向策略助手咨询沟通策略，向督学话术Agent要催习文案

* SOP-9：人工仍然亲自操作，可以向策略助手咨询关单策略

* 人的角色没变（仍是执行者），但有了AI辅助出主意

第3期实验（转化率20%，大盘14%）的成功高度依赖人工的敏锐度和个性化跟进——AI辅助出策略，但关键判断仍靠人。

### 阶段三：2026年4月10日落地 —— 策略Agent自主运行，人从执行者变为审核者

策略助手从"人工咨询工具"升级为自主运行的**策略专家Agent**，能主动向微信端Agent发策略建议，搞不定时才向人咨询。

**SOP-6 现在的设计**：策略Agent主导催习节奏，主动给路老师发催习建议（时机、话术、策略），路老师据此向用户发消息。路老师不需要自己决定何时催、怎么催。

**SOP-9 现在的设计**：同样由策略Agent主导转化策略，路老师进入该阶段后立即向策略Agent报告，策略Agent制定沟通策略并持续指导路老师执行。

**转人工机制也同步改造——从"转人工"变为"AI向人咨询"**：

```
旧：AI搞不定 → 转人工 → 人直接接管对话
新：路老师遇问题 → 咨询策略Agent → 策略Agent尝试解决
    → 搞不定 → 向人咨询 → 人在咨询工作台与策略Agent讨论
    → 摘要回传 → 路老师继续服务
```

人不再直接面对用户，而是作为策略Agent的"顾问"——AI始终在主线上。

**但实际运行中人工仍深度参与**：

* **先审后发**：策略Agent给路老师的建议需要人工审核后才执行，相当于人仍在把关每条关键消息

* **向人咨询频率**：策略Agent在催习和关单中遇到的非标情况多，向人咨询的频率不低

* **散布的人工兜底**：FAQ溢出、非标场景、多模态消息等情况下人工仍需介入

**本质变化**：人的角色从"亲自上场发消息"变成了"审核+顾问"，工作形态变了，但工作量未必减少——甚至可能因为多了审核环节而增加。

### 小结

| <br />    | 1月（纯人工） | 2-3月（AI辅助人工）     | 4月10日至今（AI主导+人审核）        |
| :-------- | :------ | :--------------- | :----------------------- |
| SOP-6 执行方 | 人工直接操作  | 人工操作 + 策略助手出主意   | 策略Agent出建议 → 人审核 → 路老师执行 |
| SOP-9 执行方 | 人工直接操作  | 人工操作 + 策略助手出主意   | 策略Agent出建议 → 人审核 → 路老师执行 |
| 人的角色      | 执行者     | 执行者（有AI辅助）       | 审核者 + 顾问                 |
| 人的工作量     | 高（全靠自己） | 中-高（出策略省力，执行仍靠人） | 中-高（每条关键消息都过审）           |

## 规模化卡点

目标：暑期大规模上线，现在需要开始大批量实验。当前实验规模是每期20条线索，要放量到百/千级。

**放量的前提是减少人的做工。** 当前流程中人工参与的环节太多，20条线索靠人盯着能跑通，放量到200条就不可能了——不是质量问题，是物理上做不过来。

### 人在补什么？

人的做工本质上都是在补 AI 的能力缺口。按 AI 缺什么来分，分两类：

**第一类：AI 策略能力不足 → 人必须审核和补位**

这是做工量最大的部分，集中在 SOP-6（催习）和 SOP-9（关单）的"先审后发"流程中。策略Agent出的每条建议都要过人审，20条线索时能应付，200条时物理上做不过来。

人在审核中补两个缺口：

* **策略判断**：Agent可能误判时机（用户不耐烦了还在催习）、误读情绪（把敷衍当认可）、选错方向（该共情的时候在讲道理）、遗漏上下文线索。人审就是在纠正这些判断错误

* **信息深挖**：从往期实验数据看，**成单的关键杠杆是信息深度，不是话术**（详见 lubi 往期实验数据汇总）。成单案例的共同点是拿到了关键信息（情感连接/家庭真实背景），未成单线索跟了一周还停留在学习数据层面。人在审核时会发现 Agent 根本没意识到还缺什么信息——用户的真实顾虑、家庭背景、预算状况，这些 Agent 不会主动问，人凭直觉追问才拿到。第3期20%转化率（超大盘）就高度依赖人的这种敏锐度

这两个缺口叠加上**容错空间极小**（微信场景下每次用户回应都可能是最后一次互动机会，发错一条可能直接流失），导致先审后发短期内无法简单松绑。

**第二类：AI 场景覆盖不全 → 人必须兜底**

排课、FAQ溢出、非标场景（提前问价/退款/投诉）、多模态消息（图片/语音/视频）。单个频率不高，但种类多，放量后汇总起来就是持续不断的中断，占用大量注意力。

### AI 能不能替代？

| AI能力缺口 | 替代可能性      | 说明                                                                                              |
| :----- | :--------- | :---------------------------------------------------------------------------------------------- |
| 策略判断   | **可提升**    | 时机判断、情绪识别、策略选择、上下文理解可以通过更多数据和迭代持续优化。低风险场景（常规催习）可先行免审或抽审，逐步建立信心                                  |
| 信息深挖   | **最关键也最难** | 需要AI从"在已知信息里做最优决策"升级到"知道自己还缺什么信息并主动获取"。同时流程上要开口子——把话题引向家庭背景、预算、真实顾虑等方向。这个能力不补上，即使其他做工都省了，转化率也会掉 |
| 场景覆盖   | **逐项可解**   | 排课逻辑可优化、FAQ可扩充、非标场景可逐个覆盖、多模态（图片理解+语音ASR）是工程接入工作，需要逐项投入                                          |

### 小结

放量的前提是 AI 能力足够替代人的做工。当前两类缺口中：

* **策略能力**（判断 + 信息深挖）是核心——它既是做工量最大的来源，也直接决定转化率。尤其是信息深挖，如果 AI 接管后丢掉了这个能力，量上去了但转化率会掉，放量没意义

* **场景覆盖**需要逐项投入，降低对人注意力的消耗

两件事要并行推进。

## 个人体会（易乔）

自己全程跟过几个 leads（家长会之后的阶段，家长会之前基本不需要人参与），后面销转还都是产品主导的，我不太搞得定。以下是一些体会，不一定对：

1. **用户不太关心你是人还是AI**。甚至有两个用户买单是因为觉得老师很好——AI人设本身不是障碍，反而可能是卖点。

2. **比较认可"成单的关键杠杆是信息深度"**。整个流程中信息获取得不够，最后销转的时候不知道从哪里下手。

3. **家长会是获取信息、或为后续获取信息铺路的关键环节**。lubi 流程中只有家长会这个阶段是和家长有语音互动的（反馈阶段现在是讲 PPT，基本没互动，而且处于流程末期了）。家长会必须承担更多：

   * **诊断和排课要有针对性**——后续才能找到学习方面的突破口，不然体验周的学习内容和用户脱节

   * **和用户建立信任**——不然后面都是微信，家长基本无视你

   * **实时语音比微信更容易让家长给出信息**——语音对话中家长会自然多说，微信里打字成本高、回复意愿低
