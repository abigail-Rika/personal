# 项目复盘 - 数据回收规范

## 定位

PRD 数据闭环的最后一环。解决一个反复出现的问题：**项目做完了想复盘，发现数据不够用——没埋、埋错、口径对不上、没有对照组。**

两个使用时机：
- **PRD 阶段**：写完「数据需求」后，用本规范自检埋点是否够复盘用
- **复盘阶段**：项目/实验结束，用本规范梳理需要回收哪些数据，向商分提需求

| 环节 | 工具 | 衔接点 |

## 一、复盘需要什么数据

每个项目复盘都要回答以下问题，每个问题都需要对应的数据支撑：

| # | 复盘问题 | 需要的数据 | 常见踩坑 |
|---|---------|-----------|---------|
| 1 | **触达了吗？** | 目标人群数、实际曝光数、曝光率 | 只埋了点击没埋曝光，算不出触达率 |
| 2 | **参与了吗？** | 各环节参与人数、完成率、流失节点 | 只埋了入口和终点，中间环节黑盒 |
| 3 | **有效果吗？** | 实验组 vs 对照组核心指标对比 | 没设对照组，或对照组划分有污染 |
| 4 | **假设对了吗？** | 与 PRD 假设直接相关的行为数据 | PRD 假设写的是 A，埋点量的是 B |
| 5 | **有副作用吗？** | 防护指标（次留、投诉率、学习时长等） | 只盯目标指标，忽略防护指标 |
| 6 | **谁受益/不受益？** | 分人群的指标拆解 | 埋点没带关键用户属性维度 |
| 7 | **效果持续吗？** | 活动期 vs 结束后 1-2 周的趋势 | 活动一结束就不看了 |

## 二、埋点自检清单

PRD「数据需求」写完后，逐项检查：

### 基础层 — 没有这些就复盘不了

- [ ] **全链路埋点**：核心路径每一步都有曝光 + 行为事件（不只是首尾两端）
- [ ] **实验标识**：keyfrom / AB 实验标识能区分实验组和对照组
- [ ] **口径定义**：核心指标的计算口径写清楚了（分子分母是什么、时间窗口、去重逻辑）

### 归因层 — 没有这些只能看相关性，不能归因

- [ ] **对照组**：有对照组设计，或有可对比的历史基线
- [ ] **行为串联**：实验标识能关联到用户后续行为（如转化、留存），不只是当场的点击
- [ ] **时间窗口**：明确从什么时候开始观察、观察多久（特别是转化、留存类指标）

### 分析层 — 没有这些只能看总数，不能深挖

- [ ] **防护指标**：至少有 1 个防护指标有对应埋点（防止"指标提升但质量下降"）
- [ ] **维度可拆**：关键维度有字段可拆（用户类型、渠道、年级等，按业务需要）
- [ ] **过程指标**：中间环节有埋点，能定位"效果差是卡在哪一步了"

### 持续性 — 短期活动/实验额外检查

- [ ] **活动后可追踪**：活动结束后相关数据仍能继续采集（不会随活动下线而断）
- [ ] **观察期计划**：明确活动结束后看几周数据、看什么

## 三、数据可用性评估

上线前或复盘前，用这张表评估现有埋点和数据能不能撑住复盘：

| 评估维度 | ✅ 可以复盘 | ⚠️ 勉强复盘 | ❌ 复盘不了 |
|---------|-----------|------------|-----------|
| **触达与参与** | 全链路曝光+行为数据齐全 | 有部分环节数据，能估算 | 只知道"做了"，不知道多少人看到 |
| **效果归因** | 有对照组，可做因果推断 | 只有前后对比，混杂因素多 | 没有基线，无法判断是方案的效果还是自然变化 |
| **假设验证** | 埋点直接对应假设中的行为变量 | 能间接推断 | 假设和可用数据完全对不上 |
| **人群拆解** | 关键维度字段齐全 | 部分维度可拆 | 只有大盘数据，无法分人群看 |
| **持续性** | 有活动后观察期数据 | 可事后从数仓补拉 | 数据随活动下线断了 |

**评估结果的处理：**
- 全 ✅：可以正常复盘
- 有 ⚠️：复盘结论需注明局限性，标注"相关性≠因果性"
- 有 ❌：**上线前**发现 → 补埋点；**复盘时**发现 → 记录为经验教训，下次避免

export interface FileNode {
  name: string;
  path: string;
  type: 'file' | 'directory';
  children?: FileNode[];
}

function shouldExclude(name: string): boolean {
  return name.startsWith('.') || EXCLUDED_PATTERNS.includes(name) || name.endsWith('.log');
}

function scanDir(dirPath: string, relativeTo: string): FileNode[] {
  if (!fs.existsSync(dirPath)) return [];

  const entries = fs.readdirSync(dirPath, { withFileTypes: true });
  const nodes: FileNode[] = [];

  for (const entry of entries) {
    if (shouldExclude(entry.name)) continue;

    const fullPath = path.join(dirPath, entry.name);
    const relPath = path.relative(relativeTo, fullPath);

    if (entry.isDirectory()) {
      const children = scanDir(fullPath, relativeTo);
      if (children.length > 0) {
        nodes.push({ name: entry.name, path: relPath, type: 'directory', children });
      }
    } else if (entry.name.endsWith('.md')) {
      nodes.push({
        name: entry.name,
        path: relPath.replace(/\.md$/, ''),
        type: 'file',
      });
    }
  }

  nodes.sort((a, b) => {
    if (a.type !== b.type) return a.type === 'directory' ? -1 : 1;
    return b.name.localeCompare(a.name);
  });

  return nodes;
}

export function getContentTree(): { label: string; key: string; children: FileNode[] }[] {
  return CONTENT_DIRS
    .map((dir) => ({
      label: DIR_LABELS[dir] || dir,
      key: dir,
      children: scanDir(path.join(ROOT, dir), ROOT),
    }))
    .filter((section) => section.children.length > 0);
}

export function getAllMarkdownPaths(): string[] {
  const paths: string[] = [];

  function collect(nodes: FileNode[]) {
    for (const node of nodes) {
      if (node.type === 'file') paths.push(node.path);
      if (node.children) collect(node.children);
    }
  }

  for (const dir of CONTENT_DIRS) {
    collect(scanDir(path.join(ROOT, dir), ROOT));
  }

  return paths;
}

export function getMarkdownContent(filePath: string): {
  content: string;
  title: string;
  frontmatter: Record<string, unknown>;
} | null {
  const fullPath = path.join(ROOT, filePath + '.md');
  if (!fs.existsSync(fullPath)) return null;

  const raw = fs.readFileSync(fullPath, 'utf-8');
  const { data, content } = matter(raw);

  const titleMatch = content.match(/^#\s+(.+)$/m);
  const title = (data.name as string) || (titleMatch ? titleMatch[1] : path.basename(filePath));

  return { content, title, frontmatter: data };
}

const PUBLIC_PATHS = ['/login', '/api/login'];

export function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl;

  if (
    PUBLIC_PATHS.some((p) => pathname.startsWith(p)) ||
    pathname.startsWith('/_next') ||
    pathname.startsWith('/manifest') ||
    pathname.startsWith('/icon') ||
    pathname === '/favicon.ico'
  ) {
    return NextResponse.next();
  }

  const token = request.cookies.get('auth')?.value;
  if (token !== 'authenticated') {
    const loginUrl = new URL('/login', request.url);
    return NextResponse.redirect(loginUrl);
  }

  return NextResponse.next();
}

function LoginForm() {
  const [password, setPassword] = useState('');
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(false);
  const router = useRouter();

  async function handleSubmit(e: React.FormEvent) {
    e.preventDefault();
    setLoading(true);
    setError(false);

    const res = await fetch('/api/login', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ password }),
    });

    if (res.ok) {
      router.push('/');
      router.refresh();
    } else {
      setError(true);
      setLoading(false);
    }
  }

  return (
    <form onSubmit={handleSubmit} className="bg-white rounded-lg border border-slate-200 p-6">
      <label htmlFor="password" className="block text-sm font-medium text-slate-700 mb-2">
        输入密码
      </label>
      <input
        id="password"
        type="password"
        value={password}
        onChange={(e) => setPassword(e.target.value)}
        className="w-full px-3 py-2 border border-slate-300 rounded-md text-sm
          focus:outline-none focus:ring-2 focus:ring-blue-500 focus:border-transparent"
        placeholder="请输入访问密码"
        autoFocus
        required
      />
      {error && (
        <p className="text-red-500 text-sm mt-2">密码错误，请重试</p>
      )}
      <button
        type="submit"

          rounded-md hover:bg-blue-700 disabled:opacity-50 transition-colors"
      >
        {loading ? '验证中...' : '进入'}
      </button>
    </form>
  );
}

          headers: {
            'Content-Type': 'application/json',
            'Set-Cookie': `auth=authenticated; Path=/; HttpOnly; Secure; SameSite=Lax; Max-Age=${60 * 60 * 24 * 30}`,
          },
        });
      } catch {
        return new Response(JSON.stringify({ error: 'bad request' }), {
          status: 400,
          headers: { 'Content-Type': 'application/json' },
        });
      }
    }

    const publicPaths = ['/login', '/_next/', '/manifest', '/icon', '/favicon.ico'];

      return env.ASSETS.fetch(request);
    }

    const cookie = request.headers.get('Cookie') || '';
    if (!cookie.includes('auth=authenticated')) {
      return Response.redirect(new URL('/login', request.url).toString(), 302);
    }

    return env.ASSETS.fetch(request);
