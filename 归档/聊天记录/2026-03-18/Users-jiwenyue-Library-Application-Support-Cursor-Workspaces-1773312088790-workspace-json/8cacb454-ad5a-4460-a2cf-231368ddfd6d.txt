## 投放用户进入 App 全景图——梳理框架

要回答的核心问题：**不同渠道投放进来的用户，分别走了什么路径，流量在哪些环节被消耗/浪费了？**

### 一、先按渠道拆用户来源

根据现有的增长链路，投放用户至少有以下几类入口：

| 渠道类型 | 典型场景 | 用户进入 App 的方式 |
|---------|---------|-------------------|
| **信息流投放** | 抖音/微信等广告 | 点击广告 → 落地页 → 购买体验课 → 下载/打开 App |
| **直投（App 直投）** | 应用商店广告 | 广告 → 应用商店 → 下载安装 → 打开 App |
| **直播电商** | 抖音直播间 | 直播间下单 → 获取下载引导 → 下载/打开 App |
| **标单用户（再触达）** | 已有 leads 再次被投放命中 | 看到广告 → 打开已有 App / 重新下载 |

### 二、每个渠道的全旅程拆解

这里最关键的差异是：**用户第一次打开 App 后看到什么、做了什么、被引导去哪里**。

#### 渠道 1：信息流投放（落地页 → 购买 → 进 App）

```
广告曝光 → 点击 → 落地页
  ↓ 购买体验课（析出）
下载/打开 App
  ↓ 
首次进入 App → 看到什么？（首页/课程页/引导流程？）
  ↓
被分配给 销售/CC → 电话+加微
  ↓
约习 → D1 到习 → 学练补 → 完课
  ↓
回访转化 → 首单
```

**关键问题**：
- 用户购买体验课后到首次打开 App 之间，有多少人流失了？（漏斗断裂点）
- 首次打开 App 的承接体验是什么？和落地页的承诺是否一致？
- 未加微的用户在 App 内做了什么？（之前你做过「未加微用户端内访问分析」）

#### 渠道 2：直投（App Store → 安装 → 进 App）

```
应用商店广告 → 安装 App
  ↓
首次打开 → 注册 → 看到什么？
  ↓
端内析出（在 App 里看到体验课入口 → 购买）
  ↓ 或者
仅浏览/试用 → 流失
```

**关键问题**：
- 直投用户进 App 后的析出率是多少？（从注册到购买体验课的转化）
- 端内有哪些析出入口？各入口的转化贡献？
- 没有购买的用户在 App 里停留多久、看了什么、为什么走了？
- 直投用户 vs 信息流用户的质量差异（后续转化率、LTV）

#### 渠道 3：直播电商

```
直播间观看 → 下单购买
  ↓
短信/包裹卡引导下载 App
  ↓
打开 App → 激活 → 开始学习
```

**关键问题**：
- 电商下单到 App 激活的转化率？（这里有你之前跟的退款用户短信问题）
- 激活后的学习行为和信息流用户有无差异？

#### 渠道 4：标单/断课用户被再次投放命中

```
已有用户（体断/会断）看到广告
  ↓
已安装 → 直接打开 App / 未安装 → 重新下载
  ↓
端内看到什么？能否再次购买？（限购规则）
  ↓
非限购 → 可再次购买体验课
限购 → 只能走留资 → CC 召回
```

**关键问题**：
- 投放中有多少流量打到了已有用户身上？（浪费的成本）
- 这些用户回来后的行为和转化路径是什么？
- 限购用户被投放命中后的体验如何？（看到广告但买不了？）

### 三、流量利用效率的分析维度

| 分析维度 | 具体看什么 |
|---------|----------|
| **渠道→App 激活率** | 各渠道从曝光到首次打开 App 的转化率 |
| **App 内析出率** | 进入 App 后购买体验课的比例（尤其直投） |
| **首次进入→首次学习** | 打开 App 到实际开始学习之间的流失 |
| **重复流量占比** | 各渠道投放命中已有用户的比例 |
| **各环节流失归因** | 每个断裂点的原因：没下载？没打开？没注册？没购买？没到习？ |

### 四、建议的推进方式

1. **先画一张完整的用户状态流转图**：把所有渠道的用户从广告曝光到首单购买的路径画在一张图上，标注各节点的数据口径
2. **找数据支撑**：看 Tableau 上是否有各渠道从曝光→激活→析出→加微→到习→转化的完整漏斗数据，缺的找商分或 BI 确认
3. **重点看两个东西**：
   - 哪个环节流失最大（优先优化）
   - 不同渠道用户在 App 内的行为差异（定不同的承接策略）

## 直投渠道（销售）

> 直投 = 投流 App，用户下载后在端内购买 9 元体验课。当前增长分析的主要对象。

### 用户旅程

**体验期（D0）**：

```
投流 → 用户下载 App → 端内购买 9 元体验课
  → 全屏加微页（可关闭，42%转化率）
  → 计划页（学前准备：入门测 + 加微入口）
  → 【家长操作窗口结束，手机交给孩子】
  → 孩子完成入门测 → 课程解锁
```

**销售介入（D0 当天）**：购课后数小时，销售下午 13:00 上班后开始处理 → 电话首触 → 加微好友通过 → 首触沟通（基于入门测结果）

**学习期（D1-D3）**：课程以数学为主，英语和语文为辅。

**转化期（D2~D3 完习后逐步渗透）**：转化不是独立阶段，从 D2/D3 完习开始在反馈学习情况中自然引入。未成单用户不直接放弃——体验和服务深度已较深，销售做长线跟进。

### 销售核心动作

| 动作 | 说明 |
|------|------|
| **开班 = 首通** | 给用户打第一通电话。服务介绍 + 需求挖掘 + 课程匹配的完整沟通 |
| **催习** | 推动用户按时上课。直接打电话叫孩子，晚间每隔半小时一轮全覆盖 |
| **反馈** | 向家长反馈孩子学习情况，传递服务价值（轻量沟通） |
| **反馈关单** | 在反馈基础上推正价课转化（带转化目标的沟通） |
| **二跟** | 第二次跟进，针对首通后未成单的用户再次沟通 |
| **成单** | 完成正价课转化 |

**首通方法论**：分析当前问题 → 找到关键需求 → 给到用户参与体验课的期望（产介匹配需求）

**开班优先级**：新近用户 > 完习未首通 > 完测未首通 > 未首通

### 进量与分配

> 来源：`aries-leads-center` 代码库

**分配层级结构**：

```
分配类型（体验/正式/CC）
  → 分配规则（通过 keyfrom 匹配渠道来源）
    → 渠道（带容量限制和进量状态开关）
      → 分班任务（带策略：轮转/均衡）
        → 班级（绑定辅导老师 + 容量上限 + 新生进量计划）
```

**业务周**：周五 0:00 ~ 次周四 23:59:59（非自然周）。每周开始时系统重置各班级的进量计数。

> 注意：系统业务周和销售服务周期的起点不同。进量发生在周三/周四（系统业务周末尾），但销售从进量当天（或次日）开始服务。一批用户的完整服务周期横跨两个系统业务周。

**AB 组 = 班型（IssueType）**：两组共享同一个直投进量池，SOP 节奏错开以保证绩效公平。
- `APP直投专属2026春3` → A 组
- `APP直投专属-B组2026春3` → B 组

每周在班型下创建新的班期（Issue），系统通过动态配置 `appztIssueTypes`（直投班型 ID 列表）识别直投用户。

**进量模式**：

| 模式 | 触发方式 | 说明 |
|------|---------|------|
| 实时进量 | 用户购课后自动触发 | Redis + DB 双层库存扣减 |
| 屯量分配 | 运营手动或定时任务 | leads 先进屯量池，再批量分配 |

进量规模非全局固定，按「班级 × 业务周」粒度独立配置（`NewcomerAssignPlan.assignNum`）。

> 直投 = 投流 App，用户下载后在端内购买 9 元体验课。当前增长分析的主要对象。
> CC 业务详情见 `增长业务方.mdc`；核心增长框架见 `增长业务上下文.mdc`

## 渠道战略背景

> 来源：[直投渠道项目立项方案](https://shimo.zhenguanyu.com/docs/kGEyX7Nly9j1hxoy)

**为什么做直投**：体验课广告渠道获客成本高，竞争激烈，用户被竞品过度教育。App 直投获客成本显著更低，假设能触达未被其他渠道充分渗透的人群包，存在渠道红利（基于经验判断，待持续验证）。

**体验课定价选择**：ROI 受「前端获客成本」和「后端转化率」组合影响，二者通过体验课定价关联（定价越高 → 析出率越低/获客成本越高，但 leads 质量越高/转化率越高）。经建模分析，9 元标的获客成本和转化率挑战都相对适中，能算出多种可行方案。

> ROI 计算器：[石墨链接](https://shimo.zhenguanyu.com/sheets/qRep1rj4W5rEfe8V/MODOC/)

## 用户旅程

**体验期（D0）**：

```
投流 → 用户下载 App → 端内购买 9 元体验课
  → 全屏加微页（可关闭，42%转化率）
  → 计划页（学前准备：入门测 + 加微入口）
  → 【家长操作窗口结束，手机交给孩子】
  → 孩子完成入门测 → 课程解锁
```

**销售介入（D0 当天）**：购课后数小时，销售下午 13:00 上班后开始处理 → 电话首触 → 加微好友通过 → 首触沟通（基于入门测结果）

**学习期（D1-D3）**：课程以数学为主，英语和语文为辅。

**转化期（D2~D3 完习后逐步渗透）**：转化不是独立阶段，从 D2/D3 完习开始在反馈学习情况中自然引入。未成单用户不直接放弃——体验和服务深度已较深，销售做长线跟进。

## Leads 析出路径

> 来源：[梳理--直投用户的析出路径](https://shimo.zhenguanyu.com/docs/3NmpY8r4RxoLIYZX)；[直投头条用户认知整理](https://shimo.zhenguanyu.com/docs/qnvK1x6Br7PEFdNd)

### 当前析出漏斗

2026.1~3，Tableau 周维度，去除春节低谷周：

| 漏斗环节 | 指标 | 正常周范围 |
|---------|------|----------|
| 周活跃用户 | 量级 | 7,000~14,500（受投放量级波动） |
| 广告位曝光 | 曝光率 | 87~91% |
| 落地页曝光 | 曝光率 | 62~71%（**~30% 用户看到广告位但未进落地页**） |
| 落地页→购买 | 转化率 | 17~22% |
| 活跃→leads（端到端） | 析出率 | 11~16% |
| 周 leads 量级 | — | 930~2,147 |
| 销售:CC 分流 | — | ~82%:18% |

> 春节周（2/2、2/9）落地页曝光率跌至 14~25%，析出率跌至 1.8~3.8%，基本停摆。

**激活注册率**：83.6%，提升空间有限。强制注册+利益点文案实验对纯新用户析出率提升约 1pp。

### 析出阶段拆分

2025.10~11 七周平均：

| 阶段 | 析出率 | 用户特征 | 转化驱动 |
|------|--------|---------|---------|
| 前测环节析出 | ~17% | 高意向快速决策型 | "承诺和预期"驱动，属于"直接转化" |
| 前测后端内析出 | ~3% | 高意向但高犹豫型 | 仍靠"承诺和预期"，通过页面刻画体验预期（弃购挽回） |

> 前测析出率 ~17% 与当前落地页转化率 17~22% 基本吻合，口径均为落地页→购买。端到端析出率（11~16%）更低，因包含广告位→落地页的流失。

### 两类用户的析出策略

跳过前测售卖继续体验的用户占激活总数 ~50%，是高潜析出点位但缺少高效析出手段：

| 用户类型 | 占比 | 行为特征 | 适合的析出方式 |
|---------|------|---------|-------------|
| 前测直接购买 | ~50% | 快速决策，希望尽快浏览产品 | 简洁、直白、高性价比卖点，降低决策成本 |
| 跳过前测继续探索 | ~50% | 不易被营销打动，要自行判断需求匹配度 | 弱营销 + 满足探索诉求 + 唤醒体验需求 |

### 析出趋势

3 月起扩量，但 CPM/成本/PVR 持续下降（析出率从 23% 降至 16%）。推测媒体推了更"泛"的流量（量升但 CPM 反降）。获客成本已达 120 元目标，且扩量前后转化率无明显下降——更泛的流量经 9 元筛选后 leads 质量可能相对稳定。

### 析出提升思路——信任构建

析出率的提升空间取决于产品能"快速取得多少用户信任"。家长支付的 9 元，购买的是"确定性希望"和"零风险试错"的机会：

| 维度 | 核心命题 | 手段举例 |
|------|---------|---------|
| 安全与品牌信任 | "它是可靠的" | 品牌背书、服务规模、"零风险体验，未使用随时可退" |
| 专业与效果信任 | "它能解决学习问题" | 精准学情定位、同类学员效果展示、举一反三/错题本等教学手段 |
| 体验与价值信任 | "9 元值这个价" | 展示内容丰富度 |
| 情感与角色信任 | "它懂我的场景" | "家长更省心"、"家长圈都在用" |

**重点发力场景——前测后析出**：单纯增加析出点位密度提升不大（用户已做过拒绝决策），应增加内容体验深度重新建立信任。

### CC leads 中的直投用户

2025.10~11 数据：~1200/月，占 CC leads ~17%（与 2026 年初 ~18% 一致），人头转化率 ~1%（低于 CC 平均）。其中主动点击析出（计划页/会员页）~200/月，转化率 ~2%。

## 用户认知与配合度

> 来源：[直投头条用户认知整理](https://shimo.zhenguanyu.com/docs/qnvK1x6Br7PEFdNd)

### 加微配合度显著更低

| 指标 | 直投头条 | 大盘其他渠道 | 差异 |
|------|---------|-----------|------|
| 主动加微率（加微发起方是用户） | 41.5% | 47.8% | -6.3pp |
| 被动加微成功率 | 61.6% | 77.0% | -15.4pp |

**主动加微率低的原因**：
- **没有加微抓手**：其他渠道用户购课后不知道"课在哪、怎么学"，预期加微后有人解答；直投用户在 App 内购买，没有这个问题
- **用户不耐烦**：加微前经历很长流程，前测购买后急于体验产品

**被动加微成功率低的原因**：
- **首通接通率低**：直投 22%，低于大盘 26.75%，显著低于其他买量渠道 30.62%
- **开口挂更多**：接通后通时 >30s 的占比——直投 25% < 大盘 30.5% < 其他买量 40.8%
- **没有服务抓手**：用户购课后立即探索产品，自认为已了解产品，不想听销售介绍

### "工具型产品"认知问题

从首通录音分析，直投中有一类显著的用户群体：
- 买来"就是试试"，孩子有空看看，没空就不看
- 明确表示**不需要老师安排**，不理解 App 里都有了为什么还需要老师
- 排斥销售，担心被骚扰
- 把海豚当作灵活轻量的**内容工具**，而非有老师服务的课程产品

> 这类家长在其他渠道也存在，但直投的投放方式和用户流程导致用户更容易形成"工具型产品"认知，问题更突出。

**投放素材强化了工具认知**：直投和 29 元体验课广告素材基本一样，关键词集中在"趣味动画"、"智能推题"、"诊断+定制计划"、"内容库"——都是功能向，强化了"工具型产品"印象。

### 首通录音典型 Case

**直投用户**：
- "购买体验只是想先看看是什么东西，孩子比较忙也有线下班，觉得会员制不适合自己"
- "买来就是想让孩子先试下，孩子最近忙没时间看，等有空再加微信"
- "就是体验下，明确表示不用老师、不用规划。产品上不是有视频吗，我就是看一看"

**其他渠道也有类似**："一开始以为自己看看视频就好，以为产品就是提供视频内容的资料库型产品"

## 直投 vs 自然流量转化差异

> 来源：[直投头条用户认知整理](https://shimo.zhenguanyu.com/docs/qnvK1x6Br7PEFdNd)，数据口径 2025.1.6~6.23 标准单周

**核心矛盾**：直投头条过程数据（服务配合度）更高，但最终转化率低于自然流量（diff ~2.2pp）。

### 归因分析

| 假设 | 验证方式 | diff 变化 | 结论 |
|------|---------|----------|------|
| 获客结构差异（直投更下沉） | 调整直投结构与自然流量一致 | 2.2pp → 2.08pp | **不是主因** |
| 用户画像差异 | 调整同层级转化率与自然流量一致 | 2.2pp → 0.35pp | **是主因** |

**关键结论**：即使同城市线级、同设备价格区间，直投用户转化率也低于自然流量。差异来自画像本身，而非结构。

### 两个渠道的画像差异（推测）

| 维度 | 直投头条 | 自然流量 |
|------|---------|---------|
| 用户结构 | 整体更下沉（T分层、城市线级、设备价格） | 相对上线 |
| 过程配合度 | 更高 | 更低 |
| 最终转化率 | 更低 | 更高 |
| 推测来源 | 媒体定向触达 | 电商直播 + 体验课广告溢出用户，更排斥营销形式所以自行下载 |
| 推测画像 | — | 消费能力高、认知高，产品选择更谨慎，一旦认定就很好转化 |

> 以上画像差异为团队推测，佐证：全渠道都表现出高线城市过程数据低但转化率高的现象，符合"高认知用户配合度低但转化好"的假设。

### 销售做功差异

销售会优先做功转化 T0/T1 用户（部分小组甚至针对 T0/T1 转化率定标），直投 T0/T1 占比少，在标单大盘混接时做功量更少——这也导致直投转化率更低。

## 进量与分配

> 来源：`aries-leads-center` 代码库

**分配层级结构**：

```
分配类型（体验/正式/CC）
  → 分配规则（通过 keyfrom 匹配渠道来源）
    → 渠道（带容量限制和进量状态开关）
      → 分班任务（带策略：轮转/均衡）
        → 班级（绑定辅导老师 + 容量上限 + 新生进量计划）
```

**业务周**：周五 0:00 ~ 次周四 23:59:59（非自然周）。每周开始时系统重置各班级的进量计数。

> 注意：系统业务周和销售服务周期的起点不同。进量发生在周三/周四（系统业务周末尾），但销售从进量当天（或次日）开始服务。一批用户的完整服务周期横跨两个系统业务周。

**AB 组 = 班型（IssueType）**：两组共享同一个直投进量池，SOP 节奏错开以保证绩效公平。
- `APP直投专属2026春3` → A 组
- `APP直投专属-B组2026春3` → B 组

每周在班型下创建新的班期（Issue），系统通过动态配置 `appztIssueTypes`（直投班型 ID 列表）识别直投用户。

**进量模式**：

| 模式 | 触发方式 | 说明 |
|------|---------|------|
| 实时进量 | 用户购课后自动触发 | Redis + DB 双层库存扣减 |
| 屯量分配 | 运营手动或定时任务 | leads 先进屯量池，再批量分配 |

进量规模非全局固定，按「班级 × 业务周」粒度独立配置（`NewcomerAssignPlan.assignNum`）。

## 销售 SOP 工作流（春季）

> 来源：[AB组sop工作流对比](https://shimo.zhenguanyu.com/sheets/aZtd6RrpxUpDadIu/wKjsg)（彭舒羽，2026-02-28）

### 销售核心动作

| 动作 | 说明 |
|------|------|
| **开班 = 首通** | 给用户打第一通电话。服务介绍 + 需求挖掘 + 课程匹配的完整沟通 |
| **催习** | 推动用户按时上课。直接打电话叫孩子，晚间每隔半小时一轮全覆盖 |
| **反馈** | 向家长反馈孩子学习情况，传递服务价值（轻量沟通） |
| **反馈关单** | 在反馈基础上推正价课转化（带转化目标的沟通） |
| **二跟** | 第二次跟进，针对首通后未成单的用户再次沟通 |
| **成单** | 完成正价课转化 |

**首通方法论**：分析当前问题 → 找到关键需求 → 给到用户参与体验课的期望（产介匹配需求）

**开班优先级**：新近用户 > 完习未首通 > 完测未首通 > 未首通

### 工作节奏

按「进量日 / 非进量日」区分工作重心。

**进量节奏**：

| | A 组 | B 组 |
|---|------|------|
| 周三 | 不进量，正常工作 | 进量，**休息** |
| 周四 | 进量，正常工作 | 新一期开始服务 |

**一批用户的服务周期**：

| 阶段 | 时段 | 工作重心 | 逻辑 |
|------|------|---------|------|
| 开班期 | 周三~周四 | 首通 + 加微铺垫 | 工作日家长忙孩子上学，首通接通率有限 |
| 黄金执行期 | 周五~周日 | 催习 + 反馈关单 + 成单 | 孩子放假有时间做课程，家长空闲接电话。**主力产出时段** |
| 收尾准备期 | 周一~周二 | 扫尾跟进 + 长线转化 | 孩子上学催习效率下降。未成单个例继续保持沟通 |

**核心约束**：学习需要孩子的时间，沟通需要家长的时间，周末两者都充裕。

### AB 组差异

| 维度 | A 组（分散式） | B 组（集中式） |
|------|---------------|---------------|
| 进量日工作 | 正常上班，新老并行 | 休息 |
| 服务启动 | 进量当天即服务 | 进量第二天集中服务 |
| 工作分布 | 两天分摊 | 集中一天 |

**目标对比**：

| 指标 | A 组非进量日 | A 组进量日 | B 组服务启动日 |
|------|------------|----------|--------------|
| 开班率 | 65% | 70% | **80%** |
| D1 完习率 | 50% | 50% | 40% |
| 成单 | 3 | 2 | 2 |

B 组开班目标最高（80%）但完习目标较低（40%），策略是优先开班覆盖，完习次优先。

## 对产品侧的启示

**从 SOP 看**：
1. **催习是高频动作**：晚间每隔半小时一轮，完习率是销售核心关注指标
2. **进量日销售压力最大**（A 组模式），产品端的加微通过、入门测引导若能提前自动完成，可减轻当日负担
3. **B 组进量日休息**意味着用户购课后到首次被服务之间可能有一天空窗期，产品端的"预期建立"更关键

**从用户认知看**：
4. **"工具型产品"认知是核心障碍**：投放素材功能向 + 用户流程先体验后服务，导致用户不理解为什么需要老师
5. **需要在用户流程中渗透服务价值**：当前抓手是"诊断+规划"，但产品中没有实际体现，用户感知弱。需要在学习流程里为销售服务留"气口儿"
6. **画像差异基本无解**：媒体定向黑盒，但可通过 9 元筛选保证 leads 质量

## 直投渠道（销售）

> 直投 = 投流 App，用户下载后在端内购买 9 元体验课。当前增长分析的主要对象。

### 渠道战略背景

> 来源：[直投渠道项目立项方案](https://shimo.zhenguanyu.com/docs/kGEyX7Nly9j1hxoy)

**为什么做直投**：体验课广告渠道获客成本高，竞争激烈，用户被竞品过度教育。App 直投获客成本显著更低，假设能触达未被其他渠道充分渗透的人群包，存在渠道红利（基于经验判断，待持续验证）。

**体验课定价选择**：ROI 受「前端获客成本」和「后端转化率」组合影响，二者通过体验课定价关联（定价越高 → 析出率越低/获客成本越高，但 leads 质量越高/转化率越高）。经建模分析，9 元标的获客成本和转化率挑战都相对适中，能算出多种可行方案。


### Leads 析出路径

> 来源：[梳理--直投用户的析出路径](https://shimo.zhenguanyu.com/docs/3NmpY8r4RxoLIYZX)，数据时间 2025.10.13~11.30 七周平均

**当前析出漏斗数据**（2026.1~3，Tableau 周维度，去除春节低谷周）：

| 漏斗环节 | 指标 | 正常周范围 |
|---------|------|----------|
| 周活跃用户 | 量级 | 7,000~14,500（受投放量级波动） |
| 广告位曝光 | 曝光率 | 87~91% |
| 落地页曝光 | 曝光率 | 62~71%（**~30% 用户看到广告位但未进落地页**） |
| 落地页→购买 | 转化率 | 17~22% |
| 活跃→leads（端到端） | 析出率 | 11~16% |
| 周 leads 量级 | — | 930~2,147 |
| 销售:CC 分流 | — | ~82%:18% |

> 春节周（2/2、2/9）落地页曝光率跌至 14~25%，析出率跌至 1.8~3.8%，基本停摆。

**析出阶段拆分**（2025.10~11 七周平均，来源：[析出路径梳理文档](https://shimo.zhenguanyu.com/docs/3NmpY8r4RxoLIYZX)）：

| 阶段 | 析出率 | 用户特征 | 转化驱动 |
|------|--------|---------|---------|
| 前测环节析出 | ~17% | 高意向快速决策型 | "承诺和预期"驱动，属于"直接转化" |
| 前测后端内析出 | ~3% | 高意向但高犹豫型 | 仍靠"承诺和预期"，通过页面刻画体验预期（弃购挽回） |

> 上表中的前测析出率 ~17% 与当前落地页转化率 17~22% 基本吻合，口径均为落地页→购买。端到端析出率（11~16%）更低，因为包含了广告位→落地页的流失。

**CC leads 中的直投用户**（2025.10~11 数据）：~1200/月，占 CC leads ~17%（与 2026 年初的 ~18% 一致），人头转化率 ~1%（低于 CC 平均）。其中主动点击析出（计划页/会员页）~200/月，转化率 ~2%。

**析出提升的核心思路——信任构建**：

析出率的提升空间取决于产品能"快速取得多少用户信任"。家长支付的 9 元，购买的是"确定性希望"和"零风险试错"的机会。信任构建拆解为四个维度：

| 维度 | 核心命题 | 手段举例 |
|------|---------|---------|
| 安全与品牌信任 | "它是可靠的" | 品牌背书、服务规模、"零风险体验，未使用随时可退" |
| 专业与效果信任 | "它能解决学习问题" | 精准学情定位、同类学员效果展示、举一反三/错题本等教学手段 |
| 体验与价值信任 | "9 元值这个价" | 展示内容丰富度 |
| 情感与角色信任 | "它懂我的场景" | "家长更省心"、"家长圈都在用" |

**重点发力场景——前测后析出**：

- 单纯增加析出点位密度提升不大，用户已做过拒绝决策
- 应增加内容体验深度，重新建立信任（如引导至家长测/诊断服务 → 生成定向报告 → 承接转化页）
- 计划页优化方向：课程增加举一反三、增加"xx 人正在学习"、半弹窗增加退款承诺

**加微现状**：98% 用户为主动加微（即加微发起方是用户），不到 2% 由销售主动发起。加微环节高度自动化，销售介入对加微贡献极小。

### 用户旅程

**体验期（D0）**：

```
投流 → 用户下载 App → 端内购买 9 元体验课
  → 全屏加微页（可关闭，42%转化率）
  → 计划页（学前准备：入门测 + 加微入口）
  → 【家长操作窗口结束，手机交给孩子】
  → 孩子完成入门测 → 课程解锁
```

**销售介入（D0 当天）**：购课后数小时，销售下午 13:00 上班后开始处理 → 电话首触 → 加微好友通过 → 首触沟通（基于入门测结果）

**学习期（D1-D3）**：课程以数学为主，英语和语文为辅。

**转化期（D2~D3 完习后逐步渗透）**：转化不是独立阶段，从 D2/D3 完习开始在反馈学习情况中自然引入。未成单用户不直接放弃——体验和服务深度已较深，销售做长线跟进。

### 销售核心动作

| 动作 | 说明 |
|------|------|
| **开班 = 首通** | 给用户打第一通电话。服务介绍 + 需求挖掘 + 课程匹配的完整沟通 |
| **催习** | 推动用户按时上课。直接打电话叫孩子，晚间每隔半小时一轮全覆盖 |
| **反馈** | 向家长反馈孩子学习情况，传递服务价值（轻量沟通） |
| **反馈关单** | 在反馈基础上推正价课转化（带转化目标的沟通） |
| **二跟** | 第二次跟进，针对首通后未成单的用户再次沟通 |
| **成单** | 完成正价课转化 |

**首通方法论**：分析当前问题 → 找到关键需求 → 给到用户参与体验课的期望（产介匹配需求）

**开班优先级**：新近用户 > 完习未首通 > 完测未首通 > 未首通

### 进量与分配

> 来源：`aries-leads-center` 代码库

**分配层级结构**：

```
分配类型（体验/正式/CC）
  → 分配规则（通过 keyfrom 匹配渠道来源）
    → 渠道（带容量限制和进量状态开关）
      → 分班任务（带策略：轮转/均衡）
        → 班级（绑定辅导老师 + 容量上限 + 新生进量计划）
```

**业务周**：周五 0:00 ~ 次周四 23:59:59（非自然周）。每周开始时系统重置各班级的进量计数。

> 注意：系统业务周和销售服务周期的起点不同。进量发生在周三/周四（系统业务周末尾），但销售从进量当天（或次日）开始服务。一批用户的完整服务周期横跨两个系统业务周。

**AB 组 = 班型（IssueType）**：两组共享同一个直投进量池，SOP 节奏错开以保证绩效公平。
- `APP直投专属2026春3` → A 组
- `APP直投专属-B组2026春3` → B 组

每周在班型下创建新的班期（Issue），系统通过动态配置 `appztIssueTypes`（直投班型 ID 列表）识别直投用户。

**进量模式**：

| 模式 | 触发方式 | 说明 |
|------|---------|------|
| 实时进量 | 用户购课后自动触发 | Redis + DB 双层库存扣减 |
| 屯量分配 | 运营手动或定时任务 | leads 先进屯量池，再批量分配 |

进量规模非全局固定，按「班级 × 业务周」粒度独立配置（`NewcomerAssignPlan.assignNum`）。

### 销售 SOP 工作流（春季）

> 来源：[AB组sop工作流对比](https://shimo.zhenguanyu.com/sheets/aZtd6RrpxUpDadIu/wKjsg)（彭舒羽，2026-02-28）

按「进量日 / 非进量日」区分工作重心。

**进量节奏**：

| | A 组 | B 组 |
|---|------|------|
| 周三 | 不进量，正常工作 | 进量，**休息** |
| 周四 | 进量，正常工作 | 新一期开始服务 |

**一批用户的服务周期**：

| 阶段 | 时段 | 工作重心 | 逻辑 |
|------|------|---------|------|
| 开班期 | 周三~周四 | 首通 + 加微铺垫 | 工作日家长忙孩子上学，首通接通率有限 |
| 黄金执行期 | 周五~周日 | 催习 + 反馈关单 + 成单 | 孩子放假有时间做课程，家长空闲接电话。**主力产出时段** |
| 收尾准备期 | 周一~周二 | 扫尾跟进 + 长线转化 | 孩子上学催习效率下降。未成单个例继续保持沟通 |

**核心约束**：学习需要孩子的时间，沟通需要家长的时间，周末两者都充裕。

**AB 组关键差异**：

| 维度 | A 组（分散式） | B 组（集中式） |
|------|---------------|---------------|
| 进量日工作 | 正常上班，新老并行 | 休息 |
| 服务启动 | 进量当天即服务 | 进量第二天集中服务 |
| 工作分布 | 两天分摊 | 集中一天 |

**目标对比**：

| 指标 | A 组非进量日 | A 组进量日 | B 组服务启动日 |
|------|------------|----------|--------------|
| 开班率 | 65% | 70% | **80%** |
| D1 完习率 | 50% | 50% | 40% |
| 成单 | 3 | 2 | 2 |

B 组开班目标最高（80%）但完习目标较低（40%），策略是优先开班覆盖，完习次优先。

### 对产品侧的启示

1. **催习是高频动作**：晚间每隔半小时一轮，完习率是销售核心关注指标
2. **进量日销售压力最大**（A 组模式），产品端的加微通过、入门测引导若能提前自动完成，可减轻当日负担
3. **B 组进量日休息**意味着用户购课后到首次被服务之间可能有一天空窗期，产品端的"预期建立"更关键
4. **进量日催习更精细化**（按优先级），非进量日催习更粗放（全覆盖直接叫孩子）
